திருக்குறள் 1104

அதிகாரம் 111: புணர்ச்சி மகிழ்தல் (Rejoicing in the Embrace) · காமத்துப்பால் · களவியல்

குறள் 1104
நீங்கின் தெறூஉம் குறுகுங்கால் தண்ணென்னும்
தீயாண்டுப் பெற்றாள் இவள்?

Neengin Theruum Kurukungaal Thannennum / Theeyaantup Petraal Ival?

பொருள்: விலகினால் சுடும், நெருங்கினால் குளிரும் இந்த நெருப்பை இவள் எங்கே பெற்றாள்?
Withdraw, it burns; approach, it soothes the pain; Whence did the maid this wondrous fire obtain

2. விடுபட்ட சொல்லை நிரப்புக: நீங்கின் தெறூஉம் குறுகுங்கால் தண்ணென்னும் / தீயாண்டுப் பெற்றாள் ______?

3. இந்தக் குறள் எந்த அதிகாரத்தைச் சேர்ந்தது? நீங்கின் தெறூஉம் குறுகுங்கால் தண்ணென்னும் / தீயாண்டுப் பெற்றாள் இவள்?

4. Which kural does this English translation (G.U. Pope) belong to? "Withdraw, it burns; approach, it soothes the pain; Whence did the maid this wondrous fire obtain"
