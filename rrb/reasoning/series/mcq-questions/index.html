26. Find the missing number in the series: 17, 28, 39, 50, 61, ?

  1. 61
  2. 72
  3. 83
  4. 94

Answer: 72

Explanation: The series is an Arithmetic Progression (AP) with a common difference of +11:
17 + 11 = 28
28 + 11 = 39
39 + 11 = 50
50 + 11 = 61
Therefore, the missing number is 61 + 11 = 72.
