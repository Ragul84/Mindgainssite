Coding MCQs with answers

Use these 25 worked Coding questions to revise the Railway Reasoning syllabus. Each answer includes an explanation; the full practice set contains 109 questions.

1. In a code, BOOK is written as CPPL. How is DOOR written?

  1. EPPS
  2. EPPQ
  3. EQPS
  4. EQPR

Answer: EPPS

Explanation: Each letter is shifted by +1: B→C, O→P, O→P, K→L. So D→E, O→P, O→P, R→S. DOOR = EPPS.

2. Ravi is the son of Arun's father's sister. How is Arun related to Ravi?

  1. Uncle
  2. Cousin
  3. Brother
  4. Nephew

Answer: Cousin

Explanation: Arun's father's sister = Arun's aunt. Ravi is the son of Arun's aunt. So Ravi and Arun are cousins.

3. All roses are flowers. All flowers have fragrance. Conclusion:

  1. Some roses have fragrance
  2. All roses have fragrance
  3. No roses have fragrance
  4. Some flowers are roses

Answer: All roses have fragrance

Explanation: All roses are flowers (given) + All flowers have fragrance (given) → All roses have fragrance. (Universal affirmative syllogism)

4. Find the odd one out: Apple, Mango, Banana, Carrot, Grape

  1. Apple
  2. Mango
  3. Carrot
  4. Banana

Answer: Carrot

Explanation: Apple, Mango, Banana, and Grape are all fruits. Carrot is a vegetable — the odd one out.

5. In a row, Rahul is 15th from left and 10th from right. How many people are in the row?

  1. 24
  2. 25
  3. 26
  4. 27

Answer: 24

Explanation: Total = Position from left + Position from right - 1 = 15 + 10 - 1 = 24.

6. Choose the analogous pair: Doctor : Hospital :: Teacher : ?

  1. Student
  2. School
  3. Books
  4. Chalk

Answer: School

Explanation: A Doctor works at a Hospital. Similarly, a Teacher works at a School.

7. Find the next number: 1, 1, 2, 3, 5, 8, 13, ?

  1. 19
  2. 20
  3. 21
  4. 22

Answer: 21

Explanation: Fibonacci sequence: each number is the sum of the previous two. 8+13 = 21.

8. In a class, girls are 40% of students. If there are 24 boys, how many students are there in total?

  1. 36
  2. 40
  3. 48
  4. 60

Answer: 40

Explanation: Boys = 60% of total (since girls = 40%). 60% of total = 24. Total = 24×100/60 = 40.

9. Find the missing term: ACE, BDF, CEG, ?

  1. DFH
  2. EGI
  3. DGH
  4. DEG

Answer: DFH

Explanation: Pattern: each set takes consecutive letters starting at positions 1-3, 2-4, 3-5, 4-6. So next = D(4), F(6), H(8) = DFH.

10. If 6 men can complete a work in 8 days, how many men are needed to complete the same work in 12 days?

  1. 3
  2. 4
  3. 5
  4. 6

Answer: 4

Explanation: Total work = 6×8 = 48 man-days. Men needed for 12 days = 48/12 = 4 men.

11. If A=1, B=2, C=3... then FACE = ?

  1. 6+1+3+5=15
  2. 6+1+3+5=15
  3. 6+1+3+5=15
  4. All of the above

Answer: All of the above

Explanation: F=6, A=1, C=3, E=5. FACE = 6+1+3+5 = 15.

12. If ZEBRA is coded as '2652181' in a certain language, how will COBRA be coded?

  1. 241225926
  2. 3152181
  3. 3152182
  4. 4163192

Answer: 3152181

Explanation: In this coding scheme, each letter is replaced by its 1-based alphabetical position (A=1, B=2, ..., Z=26) and the position numbers are concatenated directly as a single string:
C = 3
O = 15
B = 2
R = 18
A = 1
Therefore, COBRA is coded as 3152181.
