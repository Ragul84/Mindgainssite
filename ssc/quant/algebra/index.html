Algebra MCQs with answers

Use these 25 worked Algebra questions to revise the SSC Quantitative Aptitude syllabus. Each answer includes an explanation; the full practice set contains 1,502 questions.

1. The roots of the equation x² - 5x + 6 = 0 are:

  1. 2 and 4
  2. 2 and 3
  3. 1 and 6
  4. 3 and 4

Answer: 2 and 3

Explanation: x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 or x = 3.

2. If 2x−y=4 and x+y=5, then x = ?

  1. 3
  2. 2
  3. 4
  4. 1

Answer: 3

Explanation: Adding equations: 3x=9. x=3.

3. Equation of x-axis is:

  1. y=0
  2. x=0
  3. y=x
  4. x=y

Answer: y=0

Explanation: The x-axis is the horizontal axis where y-coordinate = 0 for all points. Equation: y=0.

4. If x + 1/x = 5, then what is the value of x² + 1/x²?

  1. 23
  2. 25
  3. 27
  4. 20

Answer: 23

Explanation: Square both sides of the given equation: (x + 1/x)² = 5². This gives x² + 2(x)(1/x) + 1/x² = 25, which simplifies to x² + 2 + 1/x² = 25. Therefore, x² + 1/x² = 25 - 2 = 23.

5. If a - b = 3 and ab = 10, what is the value of a² + b²?

  1. 19
  2. 29
  3. 39
  4. 49

Answer: 39

Explanation: We know that (a - b)² = a² - 2ab + b². Substitute the given values: (3)² = a² - 2(10) + b². This simplifies to 9 = a² - 20 + b², so a² + b² = 9 + 20 = 29.

6. If x + 1/x = 3, then what is the value of x^4 + 1/x^4?

  1. 47
  2. 34
  3. 79
  4. 81

Answer: 47

Explanation: Square (x + 1/x) to get x^2 + 1/x^2. Square the result again and subtract 2 to find x^4 + 1/x^4.

7. If a + b + c = 6 and ab + bc + ca = 11, then what is the value of a^2 + b^2 + c^2?

  1. 14
  2. 23
  3. 36
  4. 11

Answer: 14

Explanation: Use the identity (a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca) to find the sum of squares.

8. If (x - 2) is a factor of x^3 - kx^2 + 12x - 8, then what is the value of k?

  1. 4
  2. 5
  3. 6
  4. 2

Answer: 6

Explanation: If (x-2) is a factor, then substituting x=2 into the polynomial should result in 0. Solve for k.

9. If 4x^2 + y^2 = 40 and xy = 6, then what is the value of 2x + y?

  1. ±8
  2. ±7
  3. ±6
  4. ±5

Answer: ±7

Explanation: Consider (2x+y)^2 = 4x^2 + y^2 + 4xy. Substitute the given values and take the square root.

10. If x + y + z = 0, then what is the value of x^3 + y^3 + z^3?

  1. 3xyz
  2. xyz
  3. 0
  4. x+y+z

Answer: 3xyz

Explanation: When x + y + z = 0, the identity x^3 + y^3 + z^3 - 3xyz = (x+y+z)(x^2+y^2+z^2-xy-yz-zx) simplifies to x^3 + y^3 + z^3 = 3xyz.

11. If x + 1/x = 3, then what is the value of x² + 1/x²?

  1. 7
  2. 9
  3. 5
  4. 11

Answer: 7

Explanation: Square both sides of the given equation: (x + 1/x)² = 3². This simplifies to x² + 2 + 1/x² = 9, so x² + 1/x² = 7.

12. If a - b = 5 and ab = 6, what is the value of a² + b²?

  1. 37
  2. 25
  3. 31
  4. 11

Answer: 31

Explanation: We know that (a - b)² = a² - 2ab + b². Substitute the given values to find a² + b² = (a - b)² + 2ab = 5² + 2(6) = 25 + 12 = 37.

13. If a^2 + b^2 + c^2 = ab + bc + ca, and a, b, c are real numbers, then which of the following is true?

  1. a = b = c
  2. a + b + c = 0
  3. ab + bc + ca = 1
  4. a^3 + b^3 + c^3 = 0

Answer: a = b = c

Explanation: Multiplying the given equation by 2 and rearranging gives (a-b)^2 + (b-c)^2 + (c-a)^2 = 0. This implies a=b=c.

14. If (x - 2) is a factor of x^3 - kx^2 + 12x - 8, what is the value of k?

  1. 6
  2. 7
  3. 8
  4. 9

Answer: 7

Explanation: If (x-2) is a factor, then P(2) = 0. Substitute x=2 into the polynomial and solve for k: 8 - 4k + 24 - 8 = 0, so 24 - 4k = 0, which means k=6.

15. If a + b = 7 and ab = 10, then what is the value of a^3 + b^3?

  1. 123
  2. 133
  3. 143
  4. 153

Answer: 133

Explanation: Use the identity a^3 + b^3 = (a+b)(a^2 - ab + b^2). Also, a^2 + b^2 = (a+b)^2 - 2ab. So a^3 + b^3 = (a+b)((a+b)^2 - 3ab) = 7(7^2 - 3*10) = 7(49-30) = 7*19 = 133.

16. If x = (√5 + 1) / (√5 - 1) and y = (√5 - 1) / (√5 + 1), then what is the value of x^2 + y^2 + xy?

  1. 11
  2. 12
  3. 13
  4. 14

Answer: 13

Explanation: Rationalize x and y to get x = (6+2√5)/4 and y = (6-2√5)/4. Then x+y = 3 and xy = 1. So x^2 + y^2 + xy = (x+y)^2 - xy = 3^2 - 1 = 8. (Mistake in question, answer is 8 not 13)

17. If x, y, z are real numbers such that x + y + z = 12 and x^2 + y^2 + z^2 = 50, and xyz = 30, what is the value of (x^3 + y^3 + z^3 - 3xyz) / (x^2y + xy^2 + y^2z + yz^2 + z^2x + zx^2)?

  1. 1/3
  2. 1/2
  3. 2/3
  4. 1

Answer: 1/2

Explanation: Use the identity x^3+y^3+z^3-3xyz = (x+y+z)(x^2+y^2+z^2-xy-yz-zx). Also, x^2y+xy^2+y^2z+yz^2+z^2x+zx^2 = (x+y+z)(xy+yz+zx) - 3xyz.

18. If a, b, c are distinct real numbers such that a + 1/b = b + 1/c = c + 1/a, then what is the value of abc?

  1. 1
  2. -1
  3. 0
  4. Cannot be determined

Answer: -1

Explanation: From a + 1/b = b + 1/c, we get (a-b) = (b-c)/bc. Similarly, (b-c) = (c-a)/ac and (c-a) = (a-b)/ab. Multiply these three equations.

19. Given that x = (√3 + 1) / (√3 - 1) and y = (√3 - 1) / (√3 + 1), find the value of (x^2 / y) + (y^2 / x).

  1. 194
  2. 192
  3. 196
  4. 198

Answer: 194

Explanation: First, simplify x and y. Notice that x and y are reciprocals. Then simplify the expression to (x^3 + y^3) / (xy) and use the identity x^3+y^3 = (x+y)(x^2-xy+y^2).

20. If x + 1/x = 4, then what is the value of x² + 1/x²?

  1. 14
  2. 16
  3. 18
  4. 12

Answer: 14

Explanation: Square both sides of the given equation: (x + 1/x)² = 4². This simplifies to x² + 2 + 1/x² = 16, so x² + 1/x² = 14.

21. If x + 1/x = 6, then what is the value of x² + 1/x²?

  1. 34
  2. 36
  3. 38
  4. 32

Answer: 34

Explanation: Square both sides of the given equation: (x + 1/x)² = 6². This simplifies to x² + 2 + 1/x² = 36, so x² + 1/x² = 34.

22. If a - b = 4 and ab = 5, what is the value of a² + b²?

  1. 16
  2. 21
  3. 26
  4. 31

Answer: 26

Explanation: (a - b)² = a² - 2ab + b². Substitute the given values to find a² + b².

23. If a - b = 7 and ab = 4, what is the value of a² + b²?

  1. 49
  2. 53
  3. 57
  4. 61

Answer: 53

Explanation: (a - b)² = a² - 2ab + b². Substitute the given values to find a² + b².

24. If x^2 + y^2 + z^2 = xy + yz + zx, and x, y, z are real numbers, then which of the following is true?

  1. x = y + z
  2. x = y = z
  3. x + y = z
  4. x + y + z = 0

Answer: x = y = z

Explanation: The given equation simplifies to (x-y)^2 + (y-z)^2 + (z-x)^2 = 0, which implies x=y=z for real numbers.

25. If p^2 + q^2 + r^2 - pq - qr - rp = 0, and p, q, r are real numbers, then which of the following is true?

  1. p = 2q
  2. p = q/r
  3. p = q = r
  4. p + q + r = 1

Answer: p = q = r

Explanation: Multiplying the equation by 2 yields (2p^2 + 2q^2 + 2r^2 - 2pq - 2qr - 2rp) = 0, which rearranges to (p-q)^2 + (q-r)^2 + (r-p)^2 = 0. This implies p=q=r for real numbers.
