26. If m^2 + n^2 + k^2 - mn - nk - km = 0, where m, n, k are real numbers, then what must be true about m, n, and k?

  1. m = n - k
  2. m = n + k
  3. m = n = k
  4. m * n * k = 1

Answer: m = n = k

Explanation: The given equation can be rewritten as 0.5 * [(m-n)^2 + (n-k)^2 + (k-m)^2] = 0. For real numbers, this requires each term in the sum to be zero, meaning m=n=k.

27. If (x - 3) is a factor of x^3 - kx^2 + 15x - 9, what is the value of k?

  1. 7
  2. 8
  3. 9
  4. 10

Answer: 7

Explanation: By the Factor Theorem, if (x-3) is a factor, then the polynomial equals 0 when x=3. Substituting x=3 and solving for k gives k=7.
