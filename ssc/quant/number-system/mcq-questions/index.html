26. What is the remainder when 6^66 is divided by 5?

  1. 1
  2. 2
  3. 3
  4. 4

Answer: 1

Explanation: The pattern of remainders for powers of 6 divided by 5 is always 1. So, the remainder is 1.

27. If a number is divisible by both 7 and 11, then it must be divisible by:

  1. 77
  2. 11
  3. 7
  4. 18

Answer: 77

Explanation: If a number is divisible by two coprime numbers, it must be divisible by their product. 7 and 11 are coprime, so the number must be divisible by 7 * 11 = 77.

30. How many factors does the number 2^4 * 3^3 * 5^2 have?

  4. 75

  2. 5040
  3. 1260
  4. 720

40. If 'a' is a natural number such that 6a + 5 is divisible by 3, then which of the following statements must be true?

  1. a is an even number
  2. a is an odd number
  3. a is divisible by 3
  4. None of the above

Answer: None of the above

Explanation: Since 6a is always divisible by 3, for 6a+5 to be divisible by 3, 5 must be divisible by 3, which is false. Therefore, 6a+5 is never divisible by 3 for any integer 'a'.

41. The sum of the digits of a two-digit number is 9. If 27 is subtracted from the number, the digits are reversed. What is the number?

  1. 63
  2. 54
  3. 72
  4. 45

Answer: 72

Explanation: Let the number be 10x + y. Given x + y = 9 and 10x + y - 27 = 10y + x. Solving these equations gives x=7 and y=2, so the number is 72.
