Trigonometry MCQs with answers

Use these 5 worked Trigonometry questions to revise the SSC Quantitative Aptitude syllabus. Each answer includes an explanation; the full practice set contains 1,319 questions.

1. The value of sin 30° × cos 60° + cos 30° × sin 60° is:

  1. 1
  2. 0
  3. ½
  4. √3/2

Answer: 1

Explanation: sin30°×cos60° + cos30°×sin60° = sin(30°+60°) = sin90° = 1.

2. If cos θ = 5/13, then sin θ = ?

  1. 12/13
  2. 13/12
  3. 5/12
  4. 8/13

Answer: 12/13

Explanation: sin²θ+cos²θ=1. sin²θ=1−25/169=144/169. sinθ=12/13.

3. The value of tan 60° is:

  1. √3
  2. 1/√3
  3. 1
  4. √2

Answer: √3

Explanation: tan 60° = √3 ≈ 1.732. Standard values: tan 30°=1/√3, tan 45°=1, tan 60°=√3, tan 90°=undefined.

4. If sin A = cos A, then A = ?

  1. 45°
  2. 30°
  3. 60°
  4. 90°

Answer: 45°

Explanation: sin A = cos A → tan A = 1 → A = 45°.

5. A ladder 10 m long leans against a wall making 60° with ground. Height reached by ladder:

  1. 5√3 m
  2. 5 m
  3. 10 m
  4. 5√2 m

Answer: 5√3 m

Explanation: sin 60° = height/10. √3/2 = h/10. h = 5√3 m.
