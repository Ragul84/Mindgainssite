1. The value of sin 30° × cos 60° + cos 30° × sin 60° is:

  1. 1
  2. 0
  3. ½
  4. √3/2

Answer: 1

Explanation: sin30°×cos60° + cos30°×sin60° = sin(30°+60°) = sin90° = 1.

2. If cos θ = 5/13, then sin θ = ?

  1. 12/13
  2. 13/12
  3. 5/12
  4. 8/13

Answer: 12/13

Explanation: sin²θ+cos²θ=1. sin²θ=1−25/169=144/169. sinθ=12/13.

3. The value of tan 60° is:

  1. √3
  2. 1/√3
  3. 1
  4. √2

Answer: √3

Explanation: tan 60° = √3 ≈ 1.732. Standard values: tan 30°=1/√3, tan 45°=1, tan 60°=√3, tan 90°=undefined.

4. If sin A = cos A, then A = ?

  1. 45°
  2. 30°
  3. 60°
  4. 90°

Answer: 45°

Explanation: sin A = cos A → tan A = 1 → A = 45°.

5. A ladder 10 m long leans against a wall making 60° with ground. Height reached by ladder:

  1. 5√3 m
  2. 5 m
  3. 10 m
  4. 5√2 m

Answer: 5√3 m

Explanation: sin 60° = height/10. √3/2 = h/10. h = 5√3 m.

6. If sin θ = 3/5, what is the value of cosec θ?

  1. 5/3
  2. 4/5
  3. 3/4
  4. 5/4

Answer: 5/3

Explanation: cosec θ is the reciprocal of sin θ. So, cosec θ = 1 / sin θ = 1 / (3/5) = 5/3.

7. What is the value of tan 45°?

  1. 0
  2. 1
  3. √3
  4. 1/√3

Answer: 1

Explanation: The value of tan 45° is a standard trigonometric ratio which is equal to 1.

9. If $x = a\sin^3 \theta$ and $y = b\cos^3 \theta$, then what is the value of $(x/a)^{2/3} + (y/b)^{2/3}$?

  1. 1
  2. a/b
  3. b/a
  4. $a^2/b^2$

Answer: 1

Explanation: From the given equations, $(x/a)^{1/3} = \sin \theta$ and $(y/b)^{1/3} = \cos \theta$. Squaring and adding these gives $\sin^2 \theta + \cos^2 \theta = 1$, which is $(x/a)^{2/3} + (y/b)^{2/3} = 1$.

10. If $12 \sin \theta - 9 \cos \theta = 15$, then find the value of $\sin \theta + \cos \theta$.

  1. 1/5
  2. 7/5
  3. 1/3
  4. 4/3

Answer: 7/5

Explanation: Divide the equation by $\sqrt{12^2 + (-9)^2} = \sqrt{144+81} = \sqrt{225} = 15$. This gives $(12/15)\sin \theta - (9/15)\cos \theta = 1$, so $(4/5)\sin \theta - (3/5)\cos \theta = 1$. Comparing this with $\cos \alpha \sin \theta - \sin \alpha \cos \theta = \sin(\theta - \alpha) = 1$, we have $\sin \theta = 4/5$ and $\cos \theta = 3/5$. Thus $\sin \theta + \cos \theta = 4/5 + 3/5 = 7/5$.

11. If sin(A + B) = 1 and cos(A - B) = √3/2, where 0° < A, B < 90°, then what is the value of 2A + 3B?

  1. 180°
  2. 210°
  3. 225°
  4. 240°

Answer: 210°

Explanation: From sin(A+B)=1, A+B=90°. From cos(A-B)=√3/2, A-B=30°. Solving these gives A=60°, B=30°. Then 2A+3B=2(60)+3(30)=120+90=210°.

12. If 7sin²θ + 3cos²θ = 4, then the value of tanθ (where θ is acute) is:

  1. 1/√3
  2. 1
  3. √3
  4. Cannot be determined

Answer: 1/√3

Explanation: Substitute cos²θ = 1 - sin²θ into the equation: 7sin²θ + 3(1 - sin²θ) = 4. This simplifies to 4sin²θ = 1, so sin²θ = 1/4. Thus, sinθ = 1/2, which means θ = 30° and tanθ = 1/√3.

13. If x = a secθ and y = b tanθ, then what is the value of (x²/a²) - (y²/b²)?

  1. 0
  2. 1
  3. 2
  4. -1

Answer: 1

Explanation: Substitute x/a = secθ and y/b = tanθ. The expression becomes sec²θ - tan²θ, which is a fundamental trigonometric identity equal to 1.

15. If sinθ - cosθ = 0, where 0° < θ < 90°, then the value of sin⁴θ + cos⁴θ is:

  1. 1/4
  2. 1/2
  3. 3/4
  4. 1

Answer: 1/2

Explanation: From sinθ - cosθ = 0, we get sinθ = cosθ, which implies tanθ = 1. Since θ is acute, θ = 45°. Therefore, sin⁴45° + cos⁴45° = (1/√2)⁴ + (1/√2)⁴ = 1/4 + 1/4 = 1/2.

16. If sin(A + B) = 1 and cos(A - B) = √3/2, where 0° < A, B < 90°, what is the value of tan(2A - B)?

  1. √3
  2. 1/√3
  3. 1
  4. Undefined

Answer: √3

Explanation: From the given conditions, A+B=90° and A-B=30°. Solving these gives A=60° and B=30°. Then calculate tan(2A-B).

17. If (cosθ + sinθ) / (cosθ - sinθ) = √3, then the value of (1 - sin²θ) / (1 - cos²θ) is:

  1. 3
  2. 1/3
  3. √3
  4. 1/√3

Answer: 1/3

Explanation: Divide numerator and denominator by cosθ to find tanθ. Then substitute tanθ into the given expression, which simplifies to cot²θ.

18. Given that 2sin²θ + 3cosθ = 3, where 0° ≤ θ ≤ 90°, what is the value of (secθ + tanθ)?

  1. √3 + 1
  2. 2√3
  3. 1/√3 + 1
  4. 2 + √3

Answer: 2 + √3

Explanation: Substitute sin²θ = 1 - cos²θ to form a quadratic in cosθ. Solve for cosθ and find θ, then calculate secθ + tanθ.
