SSC Reasoning practice

Analogy MCQs with answers

Use these 25 worked Analogy questions to revise the SSC Reasoning syllabus. Each answer includes an explanation; the full practice set contains 539 questions.

1. Choose the analogous pair: Doctor : Hospital :: Teacher : ?

  1. Student
  2. School
  3. Books
  4. Chalk

Answer: School

Explanation: A Doctor works at a Hospital. Similarly, a Teacher works at a School.

2. 'Doctor' is to 'Hospital' as 'Teacher' is to:

  1. Student
  2. Books
  3. School
  4. Education

Answer: School

Explanation: A Doctor works in a Hospital (workplace relationship). Similarly, a Teacher works in a School. Student is who the teacher teaches; Books are tools; Education is the field — but School is the workplace, matching the analogy.

3. 'Herbivore' is to 'Grass' as 'Carnivore' is to:

  1. Plants
  2. Meat
  3. Vegetables
  4. Fruits

Answer: Meat

Explanation: A Herbivore eats Grass (type of animal : what it eats). A Carnivore eats Meat. This is a simple classification analogy about diet types in animals.

4. If NORTH is to SOUTH, then EAST is to:

  1. North
  2. West
  3. Northeast
  4. Southeast

Answer: West

Explanation: North and South are opposite directions on a compass. Similarly, East and West are opposite directions. The analogy is: direction : its opposite direction.

5. Choose the correct analogy: 'Soldier' is to 'Army' as 'Sailor' is to:

  1. Ship
  2. Navy
  3. Sea
  4. Uniform

Answer: Navy

Explanation: A Soldier belongs to an Army (member : group). A Sailor belongs to a Navy. Ship is the vehicle a sailor uses; Sea is where a sailor works; Uniform is what both soldiers and sailors wear.

6. Select the pair that has the same relationship as: Odometer : Speed :: Odometer measures distance, so this analogy is actually: Speedometer : Speed :: Odometer : ___

  1. Time
  2. Distance
  3. Fuel
  4. Direction

Answer: Distance

Explanation: Speedometer measures Speed. Odometer measures Distance travelled. The analogy is: measuring instrument : what it measures. Odometer measures Distance (total distance travelled by a vehicle).

7. Complete the analogy: 'Marathon : Running :: Regatta : ___'

  1. Swimming
  2. Rowing/Sailing
  3. Horse Racing
  4. Cycling

Answer: Rowing/Sailing

Explanation: A Marathon is a competition in Running. A Regatta is a competition involving rowing or sailing races (boat races). The analogy: type of race : sport/activity.

8. Complete the analogy: 'Stethoscope : Doctor :: Gavel : ___'

  1. Carpenter
  2. Judge
  3. Politician
  4. Auctioneer

Answer: Judge

Explanation: A Stethoscope is the signature tool of a Doctor. A Gavel (small mallet) is the signature tool of a Judge (used to call order in court). Also used by auctioneers, but 'Judge' is the most commonly tested answer for this analogy.

9. Complete the analogy: 'Ophthalmology : Eyes :: Cardiology : ___'

  1. Brain
  2. Heart
  3. Lungs
  4. Kidney

Answer: Heart

Explanation: Ophthalmology is the branch of medicine dealing with Eyes. Cardiology is the branch dealing with the Heart. Other: Neurology=Brain, Pulmonology=Lungs, Nephrology=Kidneys, Dermatology=Skin, Orthopedics=Bones.

10. 'Cup' is to 'Saucer' as 'Sword' is to:

  1. Weapon
  2. Battle
  3. Scabbard
  4. Shield

Answer: Scabbard

Explanation: A Cup is kept in/on a Saucer (container : holder/holder). A Sword is kept in a Scabbard (a sheath for a sword). The analogy is: object : the container/holder designed for it.

11. 'Scissors : Tailor :: Scalpel : ___'

  1. Nurse
  2. Doctor/Surgeon
  3. Patient
  4. Hospital

Answer: Doctor/Surgeon

Explanation: Scissors is the main cutting tool used by a Tailor. Scalpel is the main cutting instrument used by a Doctor/Surgeon. The analogy is: tool : professional who uses it.

12. 'Kilometre : Distance :: Kilogram : ___'

  1. Weight
  2. Speed
  3. Volume
  4. Time

Answer: Weight

Explanation: Kilometre is a unit of measurement for Distance. Kilogram is a unit of measurement for Weight (mass). The analogy is: unit : what it measures.

13. 'Moon : Satellite :: Earth : ___'

  1. Star
  2. Sun
  3. Planet
  4. Galaxy

Answer: Planet

Explanation: The Moon is a Satellite (it orbits a planet). Earth is a Planet (it orbits the Sun). The analogy is: smaller celestial body : what type of celestial object it is.

14. Complete the analogy: 'Volcano : Lava :: Cloud : ___'

  1. Sky
  2. Rain
  3. Thunder
  4. Wind

Answer: Rain

Explanation: A Volcano erupts and produces Lava. A Cloud produces Rain (when water vapor condenses and falls as precipitation). The analogy is: source/origin : what it produces/releases.

15. 'India : New Delhi :: Japan : ___'

  1. Osaka
  2. Kyoto
  3. Tokyo
  4. Hiroshima

Answer: Tokyo

Explanation: New Delhi is the capital of India. Tokyo is the capital of Japan. The analogy is: country : its capital city.

16. 'Coal : Carbon :: Diamond : ___'

  1. Nitrogen
  2. Carbon
  3. Silicon
  4. Aluminium

Answer: Carbon

Explanation: Coal is composed primarily of Carbon. Diamond is also composed entirely of Carbon (pure carbon in a crystalline form). Both are allotropes of carbon. The analogy shows that both have the same elemental composition.

17. Select the related pair: 'Eye : See :: Ear : ___'

  1. Smell
  2. Hear
  3. Touch
  4. Taste

Answer: Hear

Explanation: Eye is the sense organ for See (sight). Similarly, Ear is the sense organ for Hear (hearing). Smell = nose; Touch = skin; Taste = tongue. The analogy is: sense organ : its function/sense.

18. Complete the analogy: 'Illiteracy : Education :: Disease : ___'

  1. Hospital
  2. Doctor
  3. Medicine/Treatment
  4. Patient

Answer: Medicine/Treatment

Explanation: Illiteracy is cured/solved by Education. Disease is cured/solved by Medicine or Treatment. The analogy is: problem : its solution/cure.

19. Complete the analogy: 'Paw : Cat :: Hoof : ___'

  1. Snake
  2. Horse
  3. Fish
  4. Eagle

Answer: Horse

Explanation: Paw is the foot of a Cat. Hoof is the foot of a Horse (and other ungulates like cows, deer). The analogy is: type of foot/limb : animal that has it.

20. Complete the analogy: 'Microscope : Small :: Telescope : ___'

  1. Stars
  2. Distant
  3. Large
  4. Near

Answer: Distant

Explanation: A Microscope is used to see Small/tiny objects. A Telescope is used to see Distant objects (far away). The analogy is: instrument : what it helps observe (characteristic of the objects).

21. 'Egg : Bird :: Seed : ___'

  1. Flower
  2. Fruit
  3. Plant
  4. Soil

Answer: Plant

Explanation: A Bird hatches from an Egg (egg → bird). A Plant grows from a Seed (seed → plant). The analogy is: starting stage : what develops from it.

22. 'Painting : Canvas :: Sculpture : ___'

  1. Museum
  2. Artist
  3. Marble/Clay
  4. Colour

Answer: Marble/Clay

Explanation: A Painting is made on Canvas (art form : the material/medium it is made with/on). A Sculpture is made from Marble or Clay. The analogy is: type of art : material used to create it.

23. Complete: Sun is to Day as Moon is to ___

  1. Night
  2. Sky
  3. Star
  4. Planet

Answer: Night

Explanation: The Sun is the dominant celestial body visible during the Day. The Moon is the dominant celestial body visible during the Night. The analogy is: celestial body : time of day it is associated with.

24. Dog : Bark :: Cat : ?

  1. Meow
  2. Roar
  3. Hiss
  4. Chirp

Answer: Meow

Explanation: This analogy relates an animal to the sound it makes. A dog barks, and a cat meows.

25. Sun : Day :: Moon : ?

  1. Night
  2. Star
  3. Light
  4. Sky

Answer: Night

Explanation: This analogy shows an object and the time of day it is primarily associated with. The sun is seen during the day, and the moon is seen at night.
