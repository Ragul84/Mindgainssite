26. FIN : FISH :: LEG : ?

  1. BIRD
  2. CAT
  3. HUMAN
  4. TABLE

Answer: HUMAN

Explanation: A FIN is a part of a FISH used for movement. Similarly, a LEG is a part of a HUMAN used for movement.

27. COWARDICE : BRAVERY :: GLOOM : ?

  1. SADNESS
  2. MELANCHOLY
  3. JOY
  4. DARKNESS

Answer: JOY

Explanation: COWARDICE is the antonym of BRAVERY. Similarly, GLOOM is the antonym of JOY.

28. EDITOR : NEWSPAPER :: CHEF : ?

  1. FOOD
  2. RESTAURANT
  3. KITCHEN
  4. MENU

Answer: RESTAURANT

Explanation: An EDITOR works for a NEWSPAPER. A CHEF works for a RESTAURANT.

29. VOLUME : LITER :: WEIGHT : ?

  1. KILOGRAM
  2. METER
  3. POUND
  4. GRAMS

Answer: KILOGRAM

Explanation: LITER is a unit of measurement for VOLUME. KILOGRAM is a standard unit of measurement for WEIGHT.

30. ARCHIPELAGO : ISLAND :: GALAXY : ?

  1. STAR
  2. PLANET
  3. UNIVERSE
  4. CONSTELLATION

Answer: STAR

Explanation: An ARCHIPELAGO is a group of ISLANDS. A GALAXY is a group of STARS.

31. FLOURISH : PROSPER :: ABNEGATE : ?

  1. RENOUNCE
  2. ADOPT
  3. ELEVATE
  4. ENDORSE

Answer: RENOUNCE

Explanation: FLOURISH is a synonym for PROSPER. Similarly, ABNEGATE is a synonym for RENOUNCE.

32. 12 : 1440 :: 15 : ?

  1. 2250
  2. 3375
  3. 3600
  4. 3000

Answer: 3000

Explanation: The pattern is n : n^2 * 10. So, 12: 12^2 * 10 = 144 * 10 = 1440. Thus, 15: 15^2 * 10 = 225 * 10 = 2250.

33. Odometer : Distance :: Seismograph : ?

  1. Humidity
  2. Temperature
  3. Earthquake
  4. Wind Speed

Answer: Earthquake

Explanation: An Odometer measures Distance. Similarly, a Seismograph measures Earthquake activity.

34. Book : Page :: House : ?

  1. Room
  2. Tree
  3. Car
  4. Sky

Answer: Room

Explanation: A book is made up of pages, just as a house is made up of rooms. The analogy describes a whole and its constituent parts.

35. CARPENTER : WOOD :: SCULPTOR : ?

  1. CHISEL
  2. STATUE
  3. MARBLE
  4. ARTIST

Answer: MARBLE

Explanation: A carpenter works with wood as their primary material. Similarly, a sculptor works with marble as a primary material.

36. FRAGILE : BREAK :: ELASTIC : ?

  1. BEND
  2. STRETCH
  3. TIGHT
  4. SNAP

Answer: STRETCH

Explanation: Something fragile is prone to break. Similarly, something elastic is prone to stretch.

37. EDITOR : JOURNAL :: DIRECTOR : ?

  1. ACTOR
  2. MOVIE
  3. SCRIPT
  4. THEATRE

Answer: MOVIE

Explanation: An editor is responsible for a journal. Similarly, a director is responsible for a movie.

38. SOW : PIG :: MARE : ?

  1. HORSE
  2. STALLION
  3. FOAL
  4. PONY

Answer: HORSE

Explanation: A sow is an adult female pig. A mare is an adult female horse.

39. CONSTELLATION : STARS :: ARCHIPELAGO : ?

  1. OCEAN
  2. ISLANDS
  3. PENINSULA
  4. CONTINENT

Answer: ISLANDS

Explanation: A constellation is a group of stars. An archipelago is a group of islands.

40. PERSPICACIOUS : DISCERN :: OBSTREPEROUS : ?

  1. TRANQUIL
  2. CONCILIATE
  3. SUBMISSIVE
  4. QUIESCENT

Answer: CONCILIATE

Explanation: Perspicacious means having a ready insight into and understanding of things, leading to the ability to discern. Obstreperous means noisy and difficult to control, thus requiring one to conciliate (make peace).

41. ANARCHY : GOVERNMENT :: AMNESIA : ?

  1. MEMORY
  2. OBLIVION
  3. FORGETFULNESS
  4. RECOLLECTION

Answer: MEMORY

Explanation: Anarchy is the absence of government. Amnesia is the absence of memory.

42. CHRONOMETER : TIME :: ODOMETER : DISTANCE :: THERMOMETER : ?

  1. HEAT
  2. TEMPERATURE
  3. FEVER
  4. COLD

Answer: TEMPERATURE

Explanation: A chronometer measures time, and an odometer measures distance. A thermometer measures temperature.

43. Book : Author :: Food : ?

  1. Cook
  2. Chef
  3. Recipe
  4. Hunger

Answer: Cook

Explanation: An author creates a book, and a cook prepares food.

44. Bird : Nest :: Dog : ?

  1. Kennel
  2. House
  3. Tree
  4. Cat

Answer: Kennel

Explanation: A bird lives in a nest, and a dog lives in a kennel.

45. Odometer : Mileage :: Compasses : ?

  1. Speed
  2. Direction
  3. Needle
  4. Journey

Answer: Direction

Explanation: An Odometer measures Mileage. Similarly, Compasses indicate Direction.

46. Architect : Building :: Sculptor : ?

  1. Chisel
  2. Statue
  3. Marble
  4. Artist

Answer: Statue

Explanation: An Architect designs a Building. A Sculptor creates a Statue.

47. Pen : Write :: Knife : ?

  1. Cut
  2. Sharp
  3. Blade
  4. Food

Answer: Cut

Explanation: A Pen is used to Write. A Knife is used to Cut.

48. Water : Thirst :: Food : ?

  1. Hunger
  2. Taste
  3. Eat
  4. Energy

Answer: Hunger

Explanation: Water quenches Thirst. Food satisfies Hunger.

49. Gloves : Hands :: Socks : ?

  1. Shoes
  2. Feet
  3. Warmth
  4. Cloth

Answer: Feet

Explanation: Gloves are worn on Hands. Socks are worn on Feet.

50. FINCH : NEST :: BEAVER : LODGE :: SPIDER : ?

  1. WEB
  2. DEN
  3. BURROW
  4. CAVE

Answer: WEB

Explanation: The first pairs show an animal and its natural dwelling. A spider's natural dwelling is a web.
