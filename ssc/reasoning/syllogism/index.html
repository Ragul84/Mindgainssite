Syllogism MCQs with answers

Use these 25 worked Syllogism questions to revise the SSC Reasoning syllabus. Each answer includes an explanation; the full practice set contains 500 questions.

1. All roses are flowers. All flowers have fragrance. Conclusion:

  1. Some roses have fragrance
  2. All roses have fragrance
  3. No roses have fragrance
  4. Some flowers are roses

Answer: All roses have fragrance

Explanation: All roses are flowers (given) + All flowers have fragrance (given) → All roses have fragrance. (Universal affirmative syllogism)

2. Statement: All politicians are honest. No honest person is poor. Conclusion: No politician is poor.

  1. Conclusion follows
  2. Conclusion does not follow
  3. Conclusion partially follows
  4. Insufficient data

Answer: Conclusion follows

Explanation: All politicians are honest (given) + No honest person is poor (given) → No politician is poor (valid by universal negative syllogism).

3. All roses are flowers. Some flowers fade quickly. Which conclusion is definitely true?

  1. All flowers are roses
  2. Some roses fade quickly
  3. All roses fade quickly
  4. No conclusion can be definitively drawn about roses and fading

Answer: No conclusion can be definitively drawn about roses and fading

Explanation: Syllogism: 'All roses are flowers' and 'Some flowers fade quickly.' We cannot conclude that the flowers that fade quickly are roses. The overlapping set (flowers that fade quickly) may or may not include roses. Therefore, no definite conclusion about roses fading can be drawn.

4. All cats are animals. All animals have hearts. Which conclusion follows?

  1. All animals are cats
  2. Some hearts are cats
  3. All cats have hearts
  4. Some cats are not animals

Answer: All cats have hearts

Explanation: Syllogism: All cats are animals (cats ⊆ animals). All animals have hearts (animals ⊆ hearts). By transitivity: All cats have hearts (cats ⊆ animals ⊆ hearts). This is a valid deductive conclusion.

5. Choose the correct statement: All mangoes are fruits. All fruits are nutritious. Conclusion: All mangoes are nutritious.

  1. The conclusion is valid
  2. The conclusion is invalid
  3. Cannot be determined
  4. Partially valid

Answer: The conclusion is valid

Explanation: Syllogism: All mangoes are fruits (mangoes ⊆ fruits). All fruits are nutritious (fruits ⊆ nutritious). By transitivity: All mangoes are nutritious (mangoes ⊆ fruits ⊆ nutritious). This is a valid deductive conclusion.

6. All birds can fly. Ostrich is a bird. Can ostrich fly?

  1. Yes, because all birds can fly
  2. No, ostrich cannot fly — the premise is false
  3. The syllogism is valid but the premise is incorrect
  4. Cannot determine

Answer: The syllogism is valid but the premise is incorrect

Explanation: In logic: if the premises are true, the conclusion must be true. Here: 'All birds can fly' is a false premise (ostriches, penguins, etc., are birds that can't fly). The logical form is valid (valid syllogism), but the argument is unsound because the premise is factually wrong.

7. Statements: All pens are pencils. Some pencils are erasers. Conclusions: I. Some pens are erasers. II. Some erasers are pencils.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusion I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Only conclusion II follows.

Explanation: From the statements, we know some pencils are erasers, making conclusion II directly follow. There is no definite link between pens and erasers.

8. Statements: No dog is a cat. All cats are animals. Conclusions: I. Some animals are cats. II. No dog is an animal.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusion I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Only conclusion I follows.

Explanation: Since all cats are animals, it directly implies that some animals are cats, so conclusion I follows. Conclusion II is not necessarily true as dogs can be animals.

9. Statements: I. Some pens are pencils. II. All pencils are erasers. III. No eraser is a scale. IV. All scales are rulers. Conclusions: 1. Some pens are erasers. 2. No pencil is a scale. 3. Some erasers are rulers. 4. All rulers are scales. Which of the following conclusions logically follow from the given statements?

  1. Only 1 and 2 follow
  2. Only 1, 2 and 3 follow
  3. Only 1, 2 and 4 follow
  4. All 1, 2, 3 and 4 follow

Answer: Only 1, 2 and 3 follow

Explanation: From I and II, Some pens are erasers. From II and III, No pencil is a scale. From III and IV, No eraser is a scale, but some rulers are scales, so Some erasers are not rulers is definite, but Some erasers are rulers is possible (hence not definite). All rulers are scales is a restatement of IV, which is not a conclusion but a given statement itself. Therefore, only 1 and 2 definitely follow. For 3, it's possible but not definite given the 'No eraser is a scale' and 'All scales are rulers' (some rulers could be erasers indirectly). Re-evaluating 3: Since 'All scales are rulers' and 'No eraser is a scale', it means no eraser is a scale, so if an eraser is a ruler, that ruler cannot be a scale. This is possible. Hence, 3 is not a definite conclusion. Let's re-examine 3. From 'No eraser is a scale' and 'All scales are rulers', it implies that rulers which are scales are not erasers. However, there can be rulers which are not scales, and those rulers could be erasers. So, some rulers are erasers is possible, but 'Some erasers are rulers' is not a definite conclusion. Let's reconsider. From No eraser is a scale (III) and All scales are rulers (IV), it means that any scale is a ruler, and no eraser is a scale. This means that rulers which are scales cannot be erasers. However, it does not preclude some rulers (which are not scales) from being erasers. So, 'Some erasers are rulers' is not a definite conclusion. Therefore, only 1 and 2 follow.

10. Statements: I. All chairs are tables. II. Some tables are desks. III. No desk is a bench. Conclusions: 1. Some chairs are desks. 2. No table is a bench. 3. Some tables are not benches. Which of the following conclusions logically follows?

  1. Only 3 follows
  2. Only 1 and 3 follow
  3. Only 2 follows
  4. None of these

Answer: Only 3 follows

Explanation: From Statements II and III, 'Some tables are desks' and 'No desk is a bench'. This clearly implies that the 'some tables' which are desks cannot be benches. Therefore, 'Some tables are not benches' (Conclusion 3) definitely follows. Conclusions 1 and 2 do not necessarily follow.

11. Statements: I. All flowers are plants. II. All plants are trees. III. Some trees are fruits. IV. No fruit is a vegetable. Conclusions: 1. Some flowers are trees. 2. No plant is a vegetable. 3. Some trees are not vegetables. 4. All fruits are trees. Which of the following conclusions logically follow?

  1. Only 1 and 3 follow
  2. Only 1, 2 and 3 follow
  3. Only 1 and 4 follow
  4. Only 1, 3 and 4 follow

Answer: Only 1 and 3 follow

Explanation: From I and II, 'All flowers are trees' (so 'Some flowers are trees' definitely follows). From III and IV, 'Some trees are fruits' and 'No fruit is a vegetable', which means those 'some trees' that are fruits cannot be vegetables, so 'Some trees are not vegetables' definitely follows. 'No plant is a vegetable' is not definite. 'All fruits are trees' is not definite.

12. Statements: Some books are pens. All pens are pencils. Conclusions: I. Some books are pencils. II. Some pencils are pens.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusion I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Both conclusion I and II follow.

Explanation: From 'Some books are pens' and 'All pens are pencils', it follows that 'Some books are pencils'. From 'All pens are pencils', it directly follows that 'Some pencils are pens'.

13. Statements: All cats are dogs. No dog is a cow. Conclusions: I. No cat is a cow. II. Some dogs are cats.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusion I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Both conclusion I and II follow.

Explanation: Since all cats are dogs and no dog is a cow, it implies that no cat is a cow. From 'All cats are dogs', it follows that 'Some dogs are cats'.

14. Statements: I. Some pens are pencils. II. All pencils are erasers. III. No eraser is a scale. Conclusions: I. Some pens are erasers. II. No pencil is a scale. III. Some erasers are pens.

  1. Only I and II follow
  2. Only II and III follow
  3. Only I and III follow
  4. All I, II and III follow

Answer: All I, II and III follow

Explanation: From the Venn diagram, all three conclusions are directly derivable. The relationships established allow for all stated conclusions to be true.

15. Statements: I. All cars are buses. II. Some buses are trucks. III. No truck is a bike. Conclusions: I. Some buses are not bikes. II. Some cars are trucks. III. No car is a bike.

  1. Only I follows
  2. Only I and II follow
  3. Only II and III follow
  4. None follows

Answer: Only I follows

Explanation: Conclusion I is true as some buses are trucks and no truck is a bike. Conclusions II and III are not necessarily true as there's no direct relation between cars and trucks/bikes.

16. Statements: I. All flowers are plants. II. Some plants are trees. III. All trees are leaves. Conclusions: I. Some leaves are plants. II. Some flowers are trees. III. Some leaves are flowers.

  1. Only I follows
  2. Only II follows
  3. Only I and III follow
  4. None of these

Answer: Only I follows

Explanation: Conclusion I is true because all trees are leaves and some plants are trees. Conclusions II and III are not definite as there's no direct or transitive link established.

17. Statements: I. Some books are papers. II. All papers are notes. III. No note is a copy. Conclusions: I. Some books are notes. II. No paper is a copy. III. Some notes are books.

  1. Only I and II follow
  2. Only II and III follow
  3. Only I and III follow
  4. All I, II and III follow

Answer: All I, II and III follow

Explanation: From the statements, I is true because some books are papers and all papers are notes. II is true as all papers are notes and no note is a copy. III is the converse of I, hence also true.

18. Statements: I. All chairs are tables. II. Some tables are desks. III. All desks are benches. Conclusions: I. Some benches are tables. II. Some chairs are desks. III. Some tables are chairs.

  1. Only I and II follow
  2. Only II and III follow
  3. Only I and III follow
  4. All I, II and III follow

Answer: Only I and III follow

Explanation: Conclusion I is true (from II & III). Conclusion III is true (converse of I). Conclusion II is not necessarily true as there's no direct link between chairs and desks.

19. Statements: 1. Some A are B. 2. All B are C. 3. No C is D. Conclusions: I. Some A are not D. II. All B can be A. III. No D is B. Which of the following conclusions logically follows?

  1. Only I and II follow
  2. Only II and III follow
  3. Only I and III follow
  4. All I, II and III follow

Answer: Only I and III follow

Explanation: From statements, A-B-C-NoD. I follows because some A are B, and no B are D (since no C is D). II is not definite. III follows directly from 'No C is D' and 'All B are C'.

20. Statements: 1. All P are Q. 2. Some Q are R. 3. No R is S. Conclusions: I. Some Q are not S. II. All S can be P. III. No P is S. Which of the following conclusions is/are definitely true?

  1. Only I follows
  2. Only II follows
  3. Only I and II follow
  4. None follows

Answer: Only I follows

Explanation: From statements, P-Q-R-NoS. I follows because some Q are R and no R is S. II is possible, not definite. III is possible, not definite.

21. Statements: 1. Only a few X are Y. 2. Some Y are Z. 3. No Z is W. Conclusions: I. Some X are not Y. II. All Y can be W. III. Some X are Z. Which of the following conclusions logically follows?

  1. Only I follows
  2. Only II follows
  3. Only I and III follow
  4. Only I and II follow

Answer: Only I follows

Explanation: 'Only a few X are Y' implies 'Some X are Y' and 'Some X are not Y'. So I follows. II is false as some Y are Z and no Z is W. III is a possibility, not a definite conclusion.

22. Statements: All pens are pencils. All pencils are erasers. Conclusions: I. All pens are erasers. II. Some erasers are pens.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusions I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Both conclusions I and II follow.

Explanation: From the statements, if all pens are pencils and all pencils are erasers, then all pens must be erasers. This makes conclusion I true, and consequently, conclusion II (Some erasers are pens) is also true.

23. Statements: Some cats are dogs. No dog is a cow. Conclusions: I. No cat is a cow. II. Some cats are not cows.

  1. Only conclusion I follows.
  2. Only conclusion II follows.
  3. Both conclusions I and II follow.
  4. Neither conclusion I nor II follows.

Answer: Only conclusion II follows.

Explanation: Since some cats are dogs and no dog is a cow, it means the portion of cats that are dogs cannot be cows. Therefore, some cats are not cows (Conclusion II follows). We cannot conclude that no cat at all is a cow (Conclusion I does not follow) as there might be cats that are not dogs and could be cows.

24. Statements: I. Some pens are pencils. II. All pencils are erasers. III. No eraser is a scale. Conclusions: I. Some pens are erasers. II. No pencil is a scale. III. All erasers are pencils.

  1. Only I and II follow.
  2. Only I and III follow.
  3. Only II and III follow.
  4. All I, II and III follow.

Answer: Only I and II follow.

Explanation: Conclusion I follows from I and II. Conclusion II follows from II and III. Conclusion III is a converse error.

25. Statements: I. All cars are buses. II. Some buses are trucks. III. No truck is a bike. Conclusions: I. Some buses are cars. II. Some cars are trucks. III. No bus is a bike.

  1. Only I follows.
  2. Only II follows.
  3. Only I and III follow.
  4. Only I and II follow.

Answer: Only I follows.

Explanation: Conclusion I is a direct inference from statement I. Conclusion II is not necessarily true. Conclusion III is not necessarily true.
