26. Statements: I. No fruit is a vegetable. II. All vegetables are roots. III. Some roots are leaves. Conclusions: I. Some roots are vegetables. II. No fruit is a root. III. Some leaves are vegetables.

  1. Only I follows.
  2. Only I and II follow.
  3. Only I and III follow.
  4. None follow.

Answer: Only I follows.

Explanation: Conclusion I is a direct inference from statement II. Conclusion II is not necessarily true. Conclusion III is not necessarily true.

27. Statements: I. All birds are animals. II. All animals are mammals. III. Some mammals are carnivores. Conclusions: I. All birds are mammals. II. Some carnivores are animals. III. No bird is a carnivore.

  1. Only I follows.
  2. Only I and II follow.
  3. Only II and III follow.
  4. All follow.

Answer: Only I follows.

Explanation: Conclusion I follows from I and II. Conclusion II and III are not necessarily true. There's no definite link between birds and carnivores.

28. Statements: I. Some chairs are tables. II. All tables are desks. III. All desks are furniture. Conclusions: I. Some chairs are desks. II. All tables are furniture. III. Some furniture are chairs.

  1. Only I and II follow.
  2. Only II and III follow.
  3. Only I and III follow.
  4. All I, II and III follow.

Answer: All I, II and III follow.

Explanation: Conclusion I follows from I and II. Conclusion II follows from II and III. Conclusion III follows from I, II, and III.

29. Statements: I. All A are B. II. Some B are C. III. No C is D. Conclusions: 1. Some D are not B. 2. All A being C is a possibility. 3. No B is D. Which of the following conclusions logically follows?

  1. Only 2 follows.
  2. Only 1 and 3 follow.
  3. Only 2 and 3 follow.
  4. None of the above.

Answer: Only 2 follows.

Explanation: Conclusion 1 is a possibility, not definite. Conclusion 3 is also a possibility, not definite. Only conclusion 2 is a definite possibility according to the statements.

30. Statements: I. All Pens are Pencils. II. Some Pencils are Erasers. III. No Eraser is a Sharpener. IV. Some Sharpeners are Books. Conclusions: 1. Some Pencils are not Sharpeners. 2. All Books can be Pens. 3. No Pen is an Eraser. Which of the given conclusions logically follows?

  1. Only 1 and 2 follow.
  2. Only 2 and 3 follow.
  3. Only 1 follows.
  4. None of the conclusions follow.

Answer: Only 1 and 2 follow.

Explanation: Conclusion 1 is true because some pencils are Erasers and no Eraser is a Sharpener. Conclusion 2 is a possibility as there's no direct contradiction. Conclusion 3 is not definite.

31. Statements: I. All R are S. II. Some S are T. III. Only a few T are U. IV. No U is V. Conclusions: 1. Some S are not U. 2. All T being V is a possibility. 3. All R can be T. Which of the following conclusions logically follows?

  1. Only 1 and 3 follow.
  2. Only 2 follows.
  3. Only 1 follows.
  4. None of the conclusions follow.

Answer: Only 1 follows.

Explanation: Conclusion 1 follows from 'Only a few T are U', implying 'Some T are not U', and since S includes T, 'Some S are not U'. Conclusion 2 is false because 'No U is V' restricts T from being entirely V. Conclusion 3 is a possibility, but not a definite conclusion.

32. All cats are animals. All dogs are animals. Therefore, all cats are dogs. What is the nature of this conclusion?

  1. Valid
  2. Invalid
  3. Tautology
  4. Paradox

Answer: Invalid

Explanation: The conclusion is invalid because being animals does not imply cats are dogs.

33. Some men are wise. Some men are rich. Therefore, some wise men are rich. What type of argument is this?

  1. Categorical
  2. Conditional
  3. Disjunctive
  4. Inductive

Answer: Categorical

Explanation: This argument is categorical as it deals with categories of men.

36. Which of the following is an example of a syllogism?

  1. All humans are mortal. Socrates is human. Socrates is mortal.
  2. All cats are black. Dogs are cats. Dogs are black.
  3. All cars are red. Buses are cars. Buses are blue.
  4. All birds can fly. Fish are birds. Fish can fly.

Answer: All humans are mortal. Socrates is human. Socrates is mortal.

Explanation: The first option is a classic example of a syllogism.

37. What is the term for an argument that has a false conclusion based on false premises?

  1. Valid

Answer: Invalid

Explanation: An argument with a false conclusion based on false premises is considered invalid.

41. Which of the following arguments is an example of a logical fallacy?

  1. All men are mortal. Socrates is a man. Socrates is mortal.
  2. All cats are animals. Dogs are cats. Dogs are animals.
  3. All cars are red. This car is red. Therefore, this car is a car.
  4. All birds can fly. This bird can fly. Therefore, this bird is a bird.

Answer: All cars are red. This car is red. Therefore, this car is a car.

Explanation: The third option presents a fallacy because it assumes being red is exclusive to cars.
