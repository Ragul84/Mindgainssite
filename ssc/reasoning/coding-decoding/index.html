Coding Decoding MCQs with answers

Use these 25 worked Coding Decoding questions to revise the SSC Reasoning syllabus. Each answer includes an explanation; the full practice set contains 640 questions.

1. In a certain code language, if 'CAT' is coded as 'DDV', then how will 'DOG' be coded in the same language?

  1. EPJ
  2. EPI
  3. FPI
  4. FPH

Answer: EPI

Explanation: Each letter is shifted forward by a progressively increasing number (C+1=D, A+3=D, T+2=V). Applying the same logic to DOG: D+1=E, O+3=R, G+2=I.

2. If 'APPLE' is written as 'BQQMF' in a certain code, how would 'ORANGE' be written in that code?

  1. PSBOFH
  2. PSASFH
  3. PSBSFH
  4. PSBSGH

Answer: PSBSFH

Explanation: Each letter in the word is shifted forward by one position in the alphabet. Applying this to ORANGE gives PSBSFH.

3. In a certain code language, 'CRICKET' is written as 'EUJMGGU'. How will 'FOOTBALL' be written in that language?

  1. GPQUCBNN
  2. HQQVCBNN
  3. HPPVDBMM
  4. IPPVCBNN

Answer: HQQVCBNN

Explanation: Each letter in 'CRICKET' is shifted by +2, +3, +4, +5, +6, +7, +8 respectively. Applying the same pattern to 'FOOTBALL' gives 'HQQVCBNN'.

4. If 'PARK' is coded as '1611811' and 'ROAD' is coded as '1815144', then how will 'LANE' be coded?

  1. 121145
  2. 1211405
  3. 12114005
  4. 121405

Answer: 121145

Explanation: Each letter is replaced by its positional value in the alphabet. For single-digit values (e.g., A=1, E=5), they are written as is. For two-digit values (e.g., P=16, R=18), they are written as is. So, L=12, A=1, N=14, E=5, forming '121145'.

5. In a certain code, 'APPLE' is written as 'ELLPA' and 'GRAPE' is written as 'EPARG'. How will 'MANGO' be written in that code?

  1. OGNAM
  2. OMNAG
  3. OAGNM
  4. ONGAM

Answer: OGNAM

Explanation: The word is reversed, and then the first two letters are swapped with the last two letters. For 'APPLE', reversed is 'ELPPA', then 'ELLPA'. For 'MANGO', reversed is 'OGNAM'.

6. If 'TABLE' is coded as '20125' and 'CHAIR' is coded as '381918', then how will 'BENCH' be coded?

  1. 251438
  2. 251435
  3. 2514308
  4. 2514305

Answer: 251438

Explanation: Each letter is represented by its positional value in the alphabet. A=1, B=2, C=3... Z=26. So, B=2, E=5, N=14, C=3, H=8, which gives '251438'.

7. In a peculiar code, 'BRIGHT' is written as 'ITGHBR' and 'NUMBER' is written as 'ERBUMN'. How will 'STREAM' be written?

  1. AMERTS
  2. MAERTS
  3. TSMAER
  4. AMETRS

Answer: MAERTS

Explanation: The word is split into two halves, and then the second half is written before the first half, both in reverse order. 'STREAM' -> 'STR' and 'EAM'. Reversed halves are 'RTS' and 'MAE'. Then 'MAERTS'.

8. In a certain code language, if 'OPTIMAL' is coded as 'JNYLFNJ' and 'SURGEON' is coded as 'PNQFDHM', then how will 'REFRESH' be coded in the same language?

  1. QBCQDGN
  2. QBCQDFG
  3. QCBPDFG
  4. QBCQDFN

Answer: QBCQDFG

Explanation: Each letter is shifted by a varying prime number, first backwards then forwards. The pattern for shifts is -5, +7, -11, +13, -17, +19, -23 for OPTIMAL and SURGEON. Applying this to REFRESH gives QBCQDFG.

9. If 'CALCULATE' is coded as 'XFOYPFWHW' and 'EQUATION' is coded as 'JVZBPQJU', then how would 'PROBLEM' be coded?

  1. KILNYHG
  2. KILNVHG
  3. KILNWHG
  4. KILNWGH

Answer: KILNWHG

Explanation: The coding involves two simultaneous operations: 1) Each letter is replaced by its opposite letter in the alphabet (A=Z, B=Y, etc.). 2) The resulting letter's position is then shifted by +3, -2, +3, -2... alternating pattern. Applying this to PROBLEM yields KILNWHG.

10. In a peculiar code, 'JOURNEY' is written as 'PQVOWFK' and 'EXPLORE' is written as 'WCSQPNZ'. How would 'MYSTERY' be written in this code?

  1. HZXGPNY
  2. HZXGPND
  3. HZWGPNY
  4. HZWGPMY

Answer: HZXGPNY

Explanation: Each letter is replaced by its reverse alphabetical order (A=Z, B=Y, etc.). Then, the letters at odd positions are shifted +3, and letters at even positions are shifted -2. Applying this to MYSTERY yields HZXGPNY.

11. If 'apple' is coded as '12345', 'banana' as '67890', and 'orange' as '11111', what is the code for 'mango' if 'mango' is between 'apple' and 'banana'?

  1. 22222
  2. 33333
  3. 44444
  4. 55555

Answer: 44444

Explanation: The code for 'mango' should be between '12345' and '67890', so '44444' is a logical choice.

12. In a certain code, 'A' is represented by '1', 'B' by '2', and so on. What is the code for 'CODE'?

  1. 414215
  2. 415214
  3. 415215
  4. 414214

Answer: 414215

Explanation: Using the standard ordering of the alphabet, 'C' is the 3rd letter, 'O' the 15th, 'D' the 4th, and 'E' the 5th.

13. If 'book' is coded as 'dope', what is the code for 'pen'?

  1. qfs
  2. qft
  3. qfu
  4. qfw

Answer: qfs

Explanation: Each letter in 'book' is shifted 3 positions forward to get 'dope', so apply the same shift to 'pen'.

14. A code language uses the pattern of reversing the word and adding '1' to get the code. What is the code for 'hello'?

  1. olleh1
  2. hello1
  3. olleh2
  4. hello2

Answer: olleh1

Explanation: The word 'hello' spelled backwards is 'olleh', then add '1'.

15. In a certain code, 'above' is written as 'ediboa'. What is the code for 'cloud'?

  1. duolc
  2. duoic
  3. duolb
  4. duoba

Answer: duolc

Explanation: The code 'ediboa' for 'above' indicates a reversal of letters, so apply this to 'cloud'.

16. If 'east' is coded as 'tsea', what is the code for 'west'?

  1. tsew
  2. tswE
  3. tswe
  4. tseW

Answer: tswe

Explanation: The word 'east' is reversed to get 'tsea', so reverse 'west' to get 'tsew'.

17. A coding system uses the alphabetical positions of the letters, where 'a' is 1, 'b' is 2, etc. What is the code for 'tiger'?

  1. 20182051819
  2. 2018191815
  3. 2018201815
  4. 2018192015

Answer: 2018201815

Explanation: Using the alphabetical positions, 't' is 20, 'i' is 9, 'g' is 7, 'e' is 5, and 'r' is 18.

18. If 'red' is coded as '3-5-4', what is the code for 'pen'?

  1. 16-5-14
  2. 15-5-14
  3. 16-14-5
  4. 16-5-19

Answer: 16-5-14

Explanation: The code '3-5-4' for 'red' uses the alphabetical positions of the letters, so apply this to 'pen'.

19. In a coding system, 'house' is represented by '25156121'. What is the code for 'table'?

  1. 20111612
  2. 20111620
  3. 20112016
  4. 20111620

Answer: 20111612

Explanation: Using the alphabetical positions, 't' is 20, 'a' is 1, 'b' is 2, 'l' is 12, and 'e' is 5.

20. A certain code uses the pattern of shifting each letter one position forward in the alphabet. What is the code for 'code'?

  1. dpef
  2. dpfg
  3. dqef
  4. dqfg

Answer: dpef

Explanation: Applying the shift, 'c' becomes 'd', 'o' becomes 'p', 'd' becomes 'e', and 'e' becomes 'f'.

21. If 'apple' is coded as '1234' and 'banana' is coded as '5678', what is the code for 'appbanana'?

  1. 12345678
  2. 1357
  3. 2468
  4. 9012

Answer: 12345678

Explanation: The code for 'appbanana' is a combination of 'apple' and 'banana' codes, resulting in '12345678'.

22. In a certain code, 'A' is represented by '1', 'B' by '2', and so on. What is the code for 'CDE'?

  1. 345
  2. 456
  3. 567
  4. 678

Answer: 345

Explanation: Using the given pattern, 'C' is represented by '3', 'D' by '4', and 'E' by '5', resulting in '345'.

23. If 'x' is coded as '2', 'y' as '3', and 'z' as '4', what is the code for 'xyz'?

  1. 234
  2. 246
  3. 258
  4. 270

Answer: 234

Explanation: The code for 'xyz' is a combination of 'x', 'y', and 'z' codes, resulting in '234'.

24. A certain code represents 'red' as '12', 'blue' as '34', and 'green' as '56'. What is the code for 'bluegreen'?

  1. 3456
  2. 1234
  3. 5678
  4. 3412

Answer: 3456

Explanation: The code for 'bluegreen' is a combination of 'blue' and 'green' codes, resulting in '3456'.

25. In a certain code, 'north' is represented by '4211' and 'south' by '4343'. What is the code for 'northsouth'?

  1. 42114343
  2. 1234
  3. 5678
  4. 9012

Answer: 42114343

Explanation: The code for 'northsouth' is a combination of 'north' and 'south' codes, resulting in '42114343'.
