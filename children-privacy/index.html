Children's Privacy Notice

Last updated: 22 November 2026

This notice explains the child-specific safeguards in the Cut-Off Run web game. It should be read with the main Privacy Policy and Terms of Service.

1. Who this notice covers

This notice covers players who select “I am under 18” during Cut-Off Run setup. A parent or guardian should read it with the player.

2. Local practice mode

Under-18 players can use Cut-Off Run in local practice mode. Their selected exam, state, settings, progress, answers, cards and streak are stored in the browser on that device so the game can work.

In an under-18 web session, Cut-Off Run does not send game data to the MindGains game API. The following features stay off:

  • live all-India, state, group and creator boards;
  • remote or account-synchronised game progress;
  • optional gameplay analytics and behavioural measurement;
  • Daily Paper and All-India Mock submissions; and
  • personalised or targeted advertising.

3. What a player can share

A player can choose to use the phone or browser share function. Sharing is optional and happens only after the player taps a share button. The receiving app or service has its own privacy terms.

4. Deleting local game data

Open Cut-Off Run → More → Settings → Delete my data on this device and confirm. A parent can also clear site data for mindgains.ai in the browser settings. Local game data never sent to us cannot be deleted remotely by email because MindGains does not possess that browser copy.

5. Other MindGains services

This local-only design applies to the Cut-Off Run web game. If a child uses another MindGains feature, signs in, contacts us, purchases a plan or submits information elsewhere, the main Privacy Policy and the notice shown in that feature apply.

6. Parent and guardian contact

A parent or guardian can ask a question or request deletion of information held by MindGains by emailing contact@mindgains.ai with the subject “Child privacy request”.
