Computer Basics MCQs with answers

Use these 25 worked Computer Basics questions to revise the TNPSC Science syllabus. Each answer includes an explanation; the full practice set contains 60 questions.

26. What is the primary function of an operating system?

  1. Manage hardware and software resources
  2. Perform complex calculations
  3. Store data permanently
  4. Display graphics on screen

Answer: Manage hardware and software resources

Explanation: An operating system acts as an interface between user and hardware, managing all resources and providing services for application programs.

27. Which of the following is an input device?

  1. Monitor
  2. Printer
  3. Keyboard
  4. Speaker

Answer: Keyboard

Explanation: A keyboard is an input device used to enter data and commands into a computer.

28. What does the acronym 'LAN' stand for?

  1. Local Area Network
  2. Large Area Network
  3. Logical Access Node
  4. Longitudinal Array Network

Answer: Local Area Network

Explanation: LAN stands for Local Area Network, which connects computers within a limited geographical area such as an office or building.

29. Which unit is used to measure the speed of a computer's processor?

  1. Hertz
  2. Byte
  3. Bit
  4. Watt

Answer: Hertz

Explanation: Processor speed is measured in Hertz (Hz), typically in gigahertz (GHz), representing the number of cycles per second.

30. Which of the following is an example of system software?

  1. Microsoft Word
  2. Windows 10
  3. Adobe Photoshop
  4. Google Chrome

Answer: Windows 10

Explanation: Windows 10 is an operating system, a type of system software that manages computer hardware and software resources.

31. What is the full form of 'URL'?

  1. Uniform Resource Locator
  2. Universal Reference Link
  3. Unified Resource Locator
  4. Universal Resource Locator

Answer: Uniform Resource Locator

Explanation: URL stands for Uniform Resource Locator, the address used to access resources on the internet.

32. Which memory type is used as a cache between the CPU and main memory to improve processing speed?

  1. ROM
  2. RAM
  3. SRAM
  4. DRAM

Answer: SRAM

Explanation: SRAM (Static RAM) is faster and used as cache memory because it does not need periodic refreshing, unlike DRAM.

33. Which of the following is a volatile memory that loses its data when the power is turned off?

  1. RAM
  2. ROM
  3. Hard Disk
  4. Flash Drive

Answer: RAM

Explanation: RAM (Random Access Memory) is volatile and requires power to retain data.

34. Which generation of computers used integrated circuits (ICs) as their main electronic component?

  1. First generation
  2. Second generation
  3. Third generation
  4. Fourth generation

Answer: Third generation

Explanation: Third generation computers (1964-1971) used integrated circuits, replacing transistors.

35. Which of the following is an example of an output device?

  1. Keyboard
  2. Mouse
  3. Scanner
  4. Monitor

Answer: Monitor

Explanation: A monitor displays output; keyboard, mouse, and scanner are input devices.

36. What does the acronym 'CPU' stand for?

  1. Central Processing Unit
  2. Computer Personal Unit
  3. Core Processing Unit
  4. Central Program Unit

Answer: Central Processing Unit

Explanation: CPU stands for Central Processing Unit, the brain of the computer.

37. Which type of software is designed to control and manage computer hardware?

  1. Application software
  2. System software
  3. Utility software
  4. Programming software

Answer: System software

Explanation: System software, like operating systems, manages hardware and provides a platform for applications.

38. Which of the following is a primary storage device that stores data permanently even without power?

  1. Cache memory
  2. RAM
  3. ROM
  4. Register

Answer: ROM

Explanation: ROM (Read-Only Memory) is non-volatile and retains data when power is off.

39. In the context of computer networks, what does 'LAN' stand for?

  1. Large Area Network
  2. Local Area Network
  3. Long Access Network
  4. Logical Area Network

Answer: Local Area Network

Explanation: LAN (Local Area Network) connects computers within a limited area like a building.

40. Which of the following is a type of malware that replicates itself and spreads to other computers?

  1. Virus
  2. Spyware
  3. Adware
  4. Trojan horse

Answer: Virus

Explanation: A virus is a self-replicating program that spreads by attaching to files or programs.

41. What is the base of the binary number system used in computers?

  1. 2
  2. 8
  3. 10
  4. 16

Answer: 2

Explanation: Binary system uses base 2, with digits 0 and 1, fundamental to digital electronics.

42. Which of the following is an example of an open-source operating system?

  1. Windows 10
  2. macOS
  3. Linux
  4. iOS

Answer: Linux

Explanation: Linux is open-source, meaning its source code is freely available for modification.

43. Which of the following statements about the von Neumann architecture is correct?

  1. It uses separate memory for data and instructions
  2. It stores both data and instructions in the same memory
  3. It uses a single bus for both data and instructions
  4. It is used only in supercomputers

Answer: It stores both data and instructions in the same memory

Explanation: The von Neumann architecture is characterized by the stored-program concept, where both data and instructions reside in the same memory space.

44. Consider the following statements about computer memory: 1. RAM is volatile. 2. ROM is non-volatile. 3. Cache memory is faster than RAM. Which are correct?

  1. 1 and 2 only
  2. 2 and 3 only
  3. 1 and 3 only
  4. All 1, 2, and 3

Answer: All 1, 2, and 3

Explanation: RAM loses data when power is off (volatile), ROM retains data (non-volatile), and cache is faster than RAM due to its proximity to the CPU.

45. Which generation of computers introduced the use of microprocessors?

  1. First
  2. Second
  3. Third
  4. Fourth

Answer: Fourth

Explanation: Microprocessors were introduced in the fourth generation of computers (1970s–1990s), enabling single-chip CPUs.

46. Which of the following is a characteristic of a distributed operating system?

  1. It runs on a single computer
  2. It manages multiple computers as a single system
  3. It uses only one processor
  4. It is designed for real-time applications

Answer: It manages multiple computers as a single system

Explanation: A distributed OS manages a group of independent computers and makes them appear as a single system to users.

47. In the context of computer networks, which protocol is used to convert IP addresses to MAC addresses?

  1. DNS
  2. ARP
  3. DHCP
  4. HTTP

Answer: ARP

Explanation: Address Resolution Protocol (ARP) resolves IP addresses to MAC addresses within a local network.

48. Which of the following correctly describes the function of a compiler?

  1. It translates high-level language to machine code all at once
  2. It translates and executes line by line
  3. It converts assembly language to machine code
  4. It manages memory allocation

Answer: It translates high-level language to machine code all at once

Explanation: A compiler translates entire high-level source code into machine code before execution, unlike an interpreter which translates line by line.

49. Consider the following statements about computer viruses: 1. A worm replicates itself without requiring a host file. 2. A Trojan horse appears legitimate but contains malicious code. 3. Antivirus software can detect all viruses. Which are correct?

  1. 1 and 2 only
  2. 1 and 3 only
  3. 2 and 3 only
  4. All 1, 2, and 3

Answer: 1 and 2 only

Explanation: Worms are self-replicating without a host; Trojans disguise as legitimate software. Statement 3 is false as no antivirus can detect all viruses.

50. Which of the following is NOT an output device?

  1. Monitor
  2. Printer
  3. Keyboard
  4. Speaker

Answer: Keyboard

Explanation: A keyboard is an input device; monitors, printers, and speakers are output devices that display or produce data.
