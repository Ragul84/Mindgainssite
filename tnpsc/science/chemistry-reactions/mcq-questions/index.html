Chemistry Reactions MCQs with answers

26. In the reaction between hydrochloric acid and sodium hydroxide, which type of reaction occurs?

  1. Combination reaction
  2. Displacement reaction
  3. Neutralization reaction
  4. Decomposition reaction

Answer: Neutralization reaction

Explanation: HCl (acid) and NaOH (base) react to form salt and water, which is a neutralization reaction.

27. Which of the following is an example of a double displacement reaction?

  1. 2H2 + O2 → 2H2O
  2. Zn + CuSO4 → ZnSO4 + Cu
  3. AgNO3 + NaCl → AgCl + NaNO3
  4. CaCO3 → CaO + CO2

Answer: AgNO3 + NaCl → AgCl + NaNO3

Explanation: In double displacement, ions exchange between two compounds; AgNO3 and NaCl exchange ions to form AgCl and NaNO3.

28. The reaction in which a more reactive metal displaces a less reactive metal from its salt solution is called?

  1. Combination reaction
  2. Single displacement reaction
  3. Decomposition reaction
  4. Redox reaction

Answer: Single displacement reaction

Explanation: A single displacement reaction involves one element replacing another in a compound, e.g., Zn displacing Cu from CuSO4.

29. Which of the following is a characteristic of an exothermic reaction?

  1. Absorption of heat
  2. Release of heat
  3. Decrease in temperature
  4. Formation of precipitate

Answer: Release of heat

Explanation: Exothermic reactions release heat energy to the surroundings, causing a temperature increase.

30. In the reaction 2Mg + O2 → 2MgO, the substance that gets oxidized is?

  1. Oxygen
  2. Magnesium oxide
  3. Magnesium
  4. Both magnesium and oxygen

Answer: Magnesium

Explanation: Magnesium gains oxygen to form MgO, so it is oxidized; oxidation is gain of oxygen.

31. Which of the following is a decomposition reaction?

  1. 2H2 + O2 → 2H2O
  2. 2KClO3 → 2KCl + 3O2
  3. Fe + S → FeS
  4. NaOH + HCl → NaCl + H2O

Answer: 2KClO3 → 2KCl + 3O2

Explanation: Decomposition reactions break a single compound into simpler products; KClO3 decomposes into KCl and O2.

32. The pH of a solution formed by mixing equal volumes of 0.1 M HCl and 0.1 M NaOH is?

  1. 1
  2. 7
  3. 14
  4. 0

Answer: 7

Explanation: HCl and NaOH neutralize each other completely, forming a neutral salt solution with pH 7.

33. Which of the following metals does NOT react with dilute hydrochloric acid to produce hydrogen gas?

  1. Zinc
  2. Iron
  3. Copper
  4. Magnesium

Answer: Copper

Explanation: Copper is less reactive than hydrogen and does not displace hydrogen from dilute acids.

34. In the reaction 2H2O2 → 2H2O + O2, the catalyst commonly used is?

  1. MnO2
  2. Fe2O3
  3. CuO
  4. Al2O3

Answer: MnO2

Explanation: Manganese dioxide (MnO2) acts as a catalyst to speed up the decomposition of hydrogen peroxide.

35. Which of the following is a redox reaction?

  1. NaCl + AgNO3 → AgCl + NaNO3
  2. CuO + H2 → Cu + H2O
  3. CaCO3 → CaO + CO2
  4. 2H2O → 2H2 + O2

Answer: CuO + H2 → Cu + H2O

Explanation: In CuO + H2, copper is reduced (loss of oxygen) and hydrogen is oxidized (gain of oxygen), making it a redox reaction.

36. Which of the following reactions is an example of a combination reaction?

  1. CaCO3 → CaO + CO2
  2. 2Mg + O2 → 2MgO
  3. Zn + CuSO4 → ZnSO4 + Cu
  4. AgNO3 + NaCl → AgCl + NaNO3

Answer: 2Mg + O2 → 2MgO

Explanation: In a combination reaction, two or more reactants combine to form a single product. Here, magnesium and oxygen combine to form magnesium oxide.

37. The pH of a solution of a strong acid is likely to be:

  1. 7
  2. 2
  3. 10
  4. 14

Answer: 2

Explanation: Strong acids have low pH values, typically between 0 and 3. pH 2 indicates a strongly acidic solution.

38. Which gas is liberated when dilute hydrochloric acid reacts with sodium carbonate?

  1. Hydrogen
  2. Oxygen
  3. Carbon dioxide
  4. Chlorine

Answer: Carbon dioxide

Explanation: Sodium carbonate reacts with acid to produce carbon dioxide gas, which turns lime water milky.

39. Neutralization reaction involves:

  1. Acid + Metal → Salt + Hydrogen
  2. Acid + Base → Salt + Water
  3. Acid + Carbonate → Salt + Water + CO2
  4. Base + Non-metal oxide → Salt + Water

Answer: Acid + Base → Salt + Water

Explanation: Neutralization is the reaction between an acid and a base to form salt and water.

40. Which of the following represents a double displacement reaction?

  1. 2H2 + O2 → 2H2O
  2. Mg + 2HCl → MgCl2 + H2
  3. BaCl2 + Na2SO4 → BaSO4 + 2NaCl
  4. 2KClO3 → 2KCl + 3O2

Answer: BaCl2 + Na2SO4 → BaSO4 + 2NaCl

Explanation: Double displacement involves exchange of ions between two compounds, forming two new compounds. Barium chloride and sodium sulfate exchange ions here.

41. The process of rusting of iron requires:

  1. Only oxygen
  2. Only water
  3. Both oxygen and water
  4. Only carbon dioxide

Answer: Both oxygen and water

Explanation: Rusting is a redox reaction where iron reacts with both oxygen and water to form hydrated iron(III) oxide.

42. Which of the following is an example of a redox reaction?

  1. NaCl + AgNO3 → AgCl + NaNO3
  2. CuO + H2 → Cu + H2O
  3. NaOH + HCl → NaCl + H2O
  4. CaCO3 → CaO + CO2

Answer: CuO + H2 → Cu + H2O

Explanation: In a redox reaction, oxidation and reduction occur simultaneously. Here, hydrogen reduces copper oxide to copper and is itself oxidized to water.

43. Which acid is used in car batteries?

  1. Hydrochloric acid
  2. Sulphuric acid
  3. Nitric acid
  4. Acetic acid

Answer: Sulphuric acid

Explanation: Lead-acid batteries use dilute sulphuric acid as the electrolyte.

44. Consider the following statements about the reaction: 2H₂O₂ (aq) → 2H₂O (l) + O₂ (g). I. It is a disproportionation reaction. II. The oxidation state of oxygen changes from -1 to -2 and 0. III. Hydrogen peroxide acts as both oxidizing and reducing agent. Which of the statements is/are correct?

  1. I and II only
  2. II and III only
  3. I, II, and III
  4. I only

Answer: I and II only

Explanation: In H₂O₂, oxygen is -1; it disproportionates to -2 (H₂O) and 0 (O₂), so all three statements are correct.

45. When a copper rod is dipped into an aqueous solution of silver nitrate, a blue colour appears after some time. This reaction is an example of:

  1. Double displacement reaction
  2. Displacement reaction
  3. Redox reaction
  4. Both displacement and redox

Answer: Both displacement and redox

Explanation: Cu displaces Ag⁺ (displacement) and Cu is oxidized while Ag⁺ is reduced, so it is both displacement and redox.

46. Which of the following pairs of substances on reaction with water will produce hydrogen gas?

  1. Sodium and calcium oxide
  2. Potassium and sulphur dioxide
  3. Magnesium and carbon dioxide
  4. Sodium and calcium hydride

Answer: Sodium and calcium hydride

Explanation: Sodium reacts with water to give H₂, and calcium hydride (CaH₂) also reacts with water to produce H₂.

47. Assertion (A): In the reaction between potassium permanganate and hydrogen peroxide in acidic medium, the colour of KMnO₄ disappears. Reason (R): KMnO₄ acts as an oxidizing agent and is reduced to colourless Mn²⁺ ions.

  1. Both A and R are true and R is the correct explanation of A
  2. Both A and R are true but R is not the correct explanation of A
  3. A is true but R is false
  4. A is false but R is true

Answer: Both A and R are true and R is the correct explanation of A

Explanation: The purple KMnO₄ is reduced to Mn²⁺ (colourless) by H₂O₂, so both are true and R correctly explains A.

48. Consider the following reactions: I. 2KI + H₂O₂ → 2KOH + I₂. II. 2KMnO₄ + 16HCl → 2KCl + 2MnCl₂ + 8H₂O + 5Cl₂. In which of these reactions is hydrogen peroxide acting as an oxidizing agent?

  1. Only I
  2. Only II
  3. Both I and II
  4. Neither I nor II

Answer: Only I

Explanation: In reaction I, H₂O₂ oxidizes I⁻ to I₂ (itself reduced to H₂O), so it acts as an oxidizer. In II, H₂O₂ is not involved.

49. A white precipitate is formed when an aqueous solution of barium chloride is added to an aqueous solution of sodium sulphate. Which type of reaction is this?

  1. Precipitation and double displacement
  2. Precipitation and redox
  3. Double displacement only
  4. Neutralization

Answer: Precipitation and double displacement

Explanation: BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl; it is a double displacement leading to a precipitate.

50. Consider the following chemical equations: (i) 3Fe + 4H₂O → Fe₃O₄ + 4H₂ (ii) C + H₂O → CO + H₂ (iii) Zn + HNO₃(dil) → Zn(NO₃)₂ + N₂O + H₂O (unbalanced). In which of these reactions is water acting as an oxidizing agent?

  1. (i) and (ii)
  2. (ii) only
  3. (i) only
  4. (i), (ii), and (iii)

Answer: (i) and (ii)

Explanation: In (i) and (ii), H₂O provides oxygen (oxidizes Fe and C), while in (iii) HNO₃ is the oxidizer, not H₂O.
