1. தமிழின் தலைமை இலக்கண நூல் எது?

  1. தொல்காப்பியம்
  2. நன்னூல்
  3. வீரசோழியம்
  4. இலக்கண விளக்கம்

Answer: தொல்காப்பியம்

Explanation: தொல்காப்பியம் தமிழின் மிகப் பழமையான இலக்கண நூல். இதை தொல்காப்பியர் இயற்றினார். இது எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்களை கொண்டது.

2. தமிழ் இலக்கணத்தில் 'எழுத்து, சொல், பொருள், யாப்பு, அணி' என்ற ஐந்து இலக்கணங்களை கூறும் நூல் எது?

  1. தொல்காப்பியம்
  2. நன்னூல்
  3. இலக்கண விளக்கம்
  4. வீரசோழியம்

Answer: தொல்காப்பியம்

Explanation: தொல்காப்பியம் எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்களை கொண்டது. நன்னூல் பிற்கால இலக்கண நூல்.

3. தொல்காப்பியர் எந்த சங்கத்தை சேர்ந்தவர்?

  1. முதல் சங்கம்
  2. இரண்டாம் சங்கம்
  3. மூன்றாம் சங்கம்
  4. நான்காம் சங்கம்

Answer: இரண்டாம் சங்கம்

Explanation: தொல்காப்பியர் இரண்டாம் சங்கத்தை சேர்ந்தவர் என கருதப்படுகிறது. மூன்று தமிழ் சங்கங்கள் முறையே முதல் சங்கம் (மதுரை), இரண்டாம் சங்கம் (கபாடபுரம்), மூன்றாம் சங்கம் (மதுரை) என கூறப்படுகிறது.

4. தொல்காப்பியத்தில் 'கற்பும் காமமும் அன்பும்' என்று கூறப்படும் அதிகாரம் எது?

  1. எழுத்தியல்
  2. பொருளியல்
  3. மரபியல்
  4. அகத்திணையியல்

Answer: அகத்திணையியல்

Explanation: தொல்காப்பியம் பொருளதிகாரத்தில் அகத்திணையியல் காதல் வாழ்க்கை பற்றி விரிவாக கூறுகிறது. கற்பு (திருமண வாழ்க்கை), காமம் (காதல்), அன்பு என்று அக வாழ்க்கையை விளக்குகிறது.

5. தொல்காப்பியம் என்பது என்ன?

  1. ஒரு காப்பியம்
  2. தமிழின் மிகப் பழமையான இலக்கண நூல் — எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்கள் கொண்டது
  3. ஒரு சங்கப் புலவர் பாடல்
  4. ஒரு வரலாற்று நூல்

Answer: தமிழின் மிகப் பழமையான இலக்கண நூல் — எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்கள் கொண்டது

Explanation: தொல்காப்பியம் — தொல்காப்பியர் இயற்றிய தமிழின் மிகப் பழமையான இலக்கண நூல். எழுத்ததிகாரம், சொல்லதிகாரம், பொருளதிகாரம் என மூன்று அதிகாரங்கள்; ஒவ்வொன்றிலும் 9 இயல்கள் = 27 இயல்கள்.

6. தமிழின் மிகப் பழமையான இலக்கிய நூல் எது?

  1. திருக்குறள்
  2. தொல்காப்பியம்
  3. சிலப்பதிகாரம்
  4. புறநானூறு

Answer: தொல்காப்பியம்

Explanation: தொல்காப்பியம் தமிழின் மிகப் பழமையான இலக்கண நூல் மற்றும் இலக்கிய நூல். இது சுமார் கி.மு. 3ஆம் நூற்றாண்டில் எழுதப்பட்டதாக அறிஞர்கள் கூறுகின்றனர். இதன் மூலம் சங்ககால தமிழ் வாழ்க்கை பற்றிய தகவல்கள் கிடைக்கின்றன.

7. தொல்காப்பியம் எத்தனை அதிகாரங்களை கொண்டுள்ளது?

  1. 2
  2. 3
  3. 4
  4. 5

Answer: 3

Explanation: தொல்காப்பியம் மூன்று அதிகாரங்களை கொண்டது: எழுத்ததிகாரம், சொல்லதிகாரம், பொருளதிகாரம்.

8. தொல்காப்பியத்தின் ஆசிரியர் யார்?

  1. தொல்காப்பியர்
  2. அவ்வையார்
  3. இளங்கோ அடிகள்
  4. பாரதியார்

Answer: தொல்காப்பியர்

Explanation: தொல்காப்பியத்தை இயற்றியவர் தொல்காப்பியர் ஆவார்.

9. 'எழுத்து' பற்றிய விளக்கம் தொல்காப்பியத்தின் எந்த அதிகாரத்தில் உள்ளது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. யாப்பதிகாரம்

Answer: எழுத்ததிகாரம்

Explanation: எழுத்து பற்றிய இலக்கணம் எழுத்ததிகாரத்தில் விளக்கப்பட்டுள்ளது.

10. தொல்காப்பியம் எத்தனை வகை இலக்கணங்களை உள்ளடக்கியது?

  1. 1
  2. 2
  3. 3
  4. 4

Answer: 3

Explanation: எழுத்து, சொல், பொருள் என மூன்று இலக்கணங்களை உள்ளடக்கியது.

11. தொல்காப்பியத்தில் பொருளதிகாரம் எத்தனை இயல்களை கொண்டுள்ளது?

  1. 7
  2. 8
  3. 9
  4. 10

Answer: 9

Explanation: பொருளதிகாரம் ஒன்பது இயல்களை கொண்டுள்ளது.

12. 'இறையனார் களவியல்' எந்த நூலின் பகுதியாகும்?

  1. தொல்காப்பியம்
  2. சங்க இலக்கியம்
  3. குறுந்தொகை
  4. பதிற்றுப்பத்து

Answer: தொல்காப்பியம்

Explanation: இறையனார் களவியல் தொல்காப்பியப் பொருளதிகாரத்தின் களவியல் எனும் இயலாகும்.

13. தொல்காப்பியத்தில் 'மெய்' எந்த எழுத்து வகையைச் சேர்ந்தது?

  1. உயிரெழுத்து
  2. மெய்யெழுத்து
  3. உயிர்மெய்
  4. ஆய்தம்

Answer: மெய்யெழுத்து

Explanation: மெய்யெழுத்து வகையைச் சேர்ந்தது.

14. "தொல்காப்பியர் தமிழ் இலக்கணத்தை மூன்று அதிகாரங்களாகப் பிரித்தார்" - இக்கூற்று சரியா?

  1. சரி
  2. தவறு
  3. பகுதியளவு சரி
  4. கூற்று முழுமையற்றது

Answer: சரி

Explanation: தொல்காப்பியர் எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்களாகப் பிரித்தார்.

15. தொல்காப்பியத்தின் காலம் ஏறத்தாழ எது?

  1. கி.மு. 3ம் நூற்றாண்டு
  2. கி.மு. 5ம் நூற்றாண்டு
  3. கி.மு. 2ம் நூற்றாண்டு
  4. கி.பி. 1ம் நூற்றாண்டு

Answer: கி.மு. 5ம் நூற்றாண்டு

Explanation: தொல்காப்பியம் ஏறத்தாழ கி.மு. 5ம் நூற்றாண்டில் எழுதப்பட்டதாக கருதப்படுகிறது.

16. 'செய்யுளியல்' தொல்காப்பியத்தின் எந்த அதிகாரத்தில் உள்ளது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. இவை அனைத்திலும்

Answer: பொருளதிகாரம்

Explanation: செய்யுளியல் பொருளதிகாரத்தின் ஒரு இயலாகும்.

17. தொல்காப்பியம் எத்தனை அதிகாரங்களைக் கொண்டது?

  1. எழுத்து, சொல், பொருள் என மூன்று
  2. இயல், பாட்டு, உரை என மூன்று
  3. எழுத்து, சொல், யாப்பு என மூன்று
  4. அகம், புறம், கலிப்பா என மூன்று

Answer: எழுத்து, சொல், பொருள் என மூன்று

Explanation: தொல்காப்பியம் எழுத்ததிகாரம், சொல்லதிகாரம், பொருளதிகாரம் என மூன்று அதிகாரங்களை உள்ளடக்கியது.

18. தொல்காப்பியத்தில் 'இடைச்சொல்' பற்றி விளக்கும் இயல் எது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. யாப்பதிகாரம்

Answer: சொல்லதிகாரம்

Explanation: இடைச்சொல் வேற்றுமை, உருபுகள் பற்றிய விளக்கம் சொல்லதிகாரத்தில் இடம்பெறுகிறது.

19. தொல்காப்பியத்தில் 'இடைநிலை' என்பது எந்த உறுப்பைக் குறிக்கும்?

  1. பெயர்ச்சொல்
  2. வினைச்சொல்
  3. இடைச்சொல்
  4. உரிச்சொல்

Answer: இடைச்சொல்

Explanation: தொல்காப்பியம் இடைச்சொல்லை 'இடைநிலை' எனக் குறிப்பிடுகிறது.

20. தொல்காப்பியர் கூறும் 'மெய்யெழுத்து' எத்தனை வகைப்படும்?

  1. 18
  2. 16
  3. 12
  4. 10

Answer: 18

Explanation: தொல்காப்பியர் மெய்யெழுத்துக்களை 18 என வகைப்படுத்துகிறார்.

21. 'அகத்திணை' பற்றிய விளக்கம் தொல்காப்பியத்தின் எந்த அதிகாரத்தில் இடம்பெறுகிறது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. யாப்பதிகாரம்

Answer: பொருளதிகாரம்

Explanation: அகத்திணை பற்றிய விளக்கம் பொருளதிகாரத்தில் உள்ளது.

22. தொல்காப்பியத்தில் 'உயிர்மெய்' எழுத்துகள் எவ்வாறு உருவாக்கப்படுகின்றன?

  1. உயிரும் மெய்யும் சேர்ந்து
  2. உயிரும் உயிரும் சேர்ந்து
  3. மெய்யும் மெய்யும் சேர்ந்து
  4. உயிரும் ஆய்தமும் சேர்ந்து

Answer: உயிரும் மெய்யும் சேர்ந்து

Explanation: உயிரெழுத்தும் மெய்யெழுத்தும் சேர்ந்து உயிர்மெய் எழுத்துகள் உருவாகின்றன.

23. தொல்காப்பியம் கூறும் 'புறத்திணை' எத்தனை வகைப்படும்?

  1. ஏழு
  2. ஐந்து
  3. மூன்று
  4. ஒன்பது

Answer: ஏழு

Explanation: தொல்காப்பியம் புறத்திணையை ஏழு வகையாகப் பகுத்துள்ளது.

24. 'எழுத்து' என்பதற்கு தொல்காப்பியர் தரும் விளக்கம் என்ன?

  1. ஒலியின் குறியீடு
  2. சொல்லின் அடிப்படை
  3. பொருளின் வடிவம்
  4. யாப்பின் உறுப்பு

Answer: ஒலியின் குறியீடு

Explanation: தொல்காப்பியர் எழுத்தை ஒலியின் குறியீடாக விளக்குகிறார்.

25. தொல்காப்பியத்தில் 'வேற்றுமை' பற்றிய விளக்கம் எந்த அதிகாரத்தில் உள்ளது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. மெய்ப்பாட்டியல்

Answer: சொல்லதிகாரம்

Explanation: வேற்றுமை பற்றிய விளக்கம் சொல்லதிகாரத்தில் இடம்பெறுகிறது.
