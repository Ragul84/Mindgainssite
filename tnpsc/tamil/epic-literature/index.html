1. மணிமேகலையை இயற்றியவர் யார்?

  1. இளங்கோவடிகள்
  2. சீத்தலைச் சாத்தனார்
  3. திருவள்ளுவர்
  4. நக்கீரர்

Answer: சீத்தலைச் சாத்தனார்

Explanation: மணிமேகலையை இயற்றியவர் சீத்தலைச் சாத்தனார். இது சிலப்பதிகாரத்தின் தொடர்ச்சியாக கருதப்படுகிறது.

2. சிலப்பதிகாரத்தில் ஊர்க்காண் காதை எந்த ஊரை பற்றியது?

  1. புகார்
  2. மதுரை
  3. வஞ்சி
  4. காஞ்சி

Answer: மதுரை

Explanation: சிலப்பதிகாரம் மூன்று காண்டங்களை கொண்டது: புகார்க்காண்டம் (காவிரிப்பூம்பட்டினம்), மதுரைக்காண்டம் (மதுரை), வஞ்சிக்காண்டம் (வஞ்சி).

3. சிலப்பதிகாரம் 'முத்தமிழ்க் காப்பியம்' என்று அழைக்கப்படுவதற்கான காரணம்?

  1. மூன்று கதாபாத்திரங்கள் இருப்பதால்
  2. இயல், இசை, நாடகம் என்ற முத்தமிழையும் கொண்டதால்
  3. மூன்று ஆசிரியர்கள் எழுதியதால்
  4. மூன்று காண்டங்கள் இருப்பதால்

Answer: இயல், இசை, நாடகம் என்ற முத்தமிழையும் கொண்டதால்

Explanation: சிலப்பதிகாரம் முத்தமிழ்க் காப்பியம் என்று அழைக்கப்படுவது ஏனென்றால், இது இயல் (இலக்கியம்), இசை (இசை), நாடகம் (நாட்டியம்) என்ற மூன்றையும் தன்னகத்தே கொண்டுள்ளது.

4. மணிமேகலை எந்த மதத்தை போதிக்கிறது?

  1. சைவ மதம்
  2. வைணவ மதம்
  3. புத்த மதம்
  4. சமண மதம்

Answer: புத்த மதம்

Explanation: மணிமேகலை புத்த மதத்தை போதிக்கிறது. மணிமேகலை என்ற நாயகி கோவலன்-மாதவி மகள். அவள் புத்த மதத்தை ஏற்று சமூக சேவை செய்கிறாள்.

5. தமிழில் 'ஐம்பெருங்காப்பியங்கள்' என்று கூறப்படுவன எவை?

  1. சிலப்பதிகாரம், மணிமேகலை, சீவகசிந்தாமணி, வளையாபதி, குண்டலகேசி
  2. திருக்குறள், கம்பராமாயணம், பெரிய புராணம், சிலப்பதிகாரம், மணிமேகலை
  3. ஐந்து தேவாரங்கள்
  4. சங்க இலக்கியங்கள்

Answer: சிலப்பதிகாரம், மணிமேகலை, சீவகசிந்தாமணி, வளையாபதி, குண்டலகேசி

Explanation: ஐம்பெருங்காப்பியங்கள்: சிலப்பதிகாரம் (இளங்கோவடிகள்), மணிமேகலை (சீத்தலைச்சாத்தனார்), சீவகசிந்தாமணி (திருத்தக்கதேவர்), வளையாபதி, குண்டலகேசி.

6. தமிழின் ஐம்பெருங்காப்பியங்கள் எவை?

  1. சிலப்பதிகாரம், மணிமேகலை, சீவகசிந்தாமணி, வளையாபதி, குண்டலகேசி
  2. திருக்குறள், சிலப்பதிகாரம், மணிமேகலை, கம்பராமாயணம், பெரியபுராணம்
  3. நாலடியார், திருக்குறள், சிலப்பதிகாரம், தேவாரம், திருவாசகம்
  4. கலித்தொகை, புறநானூறு, அகநானூறு, நற்றிணை, குறுந்தொகை

Answer: சிலப்பதிகாரம், மணிமேகலை, சீவகசிந்தாமணி, வளையாபதி, குண்டலகேசி

Explanation: ஐம்பெருங்காப்பியங்கள்: சிலப்பதிகாரம் (இளங்கோவடிகள்), மணிமேகலை (சீத்தலைச் சாத்தனார்), சீவகசிந்தாமணி (திருத்தக்கதேவர்), வளையாபதி, குண்டலகேசி. சிலம்பும் மணிமேகலையும் மிகவும் புகழ்பெற்றவை.

7. 'சிலப்பதிகாரம்' யாரால் இயற்றப்பட்டது?

  1. சீத்தலைச் சாத்தனார்
  2. திருத்தக்கதேவர்
  3. இளங்கோவடிகள்
  4. கம்பர்

Answer: இளங்கோவடிகள்

Explanation: சிலப்பதிகாரம் — சேரன் இளங்கோவடிகளால் இயற்றப்பட்டது. இது கண்ணகியின் கதையை கூறும். 'முப்பால்' — புகார்க்காண்டம், மதுரைக்காண்டம், வஞ்சிக்காண்டம் என மூன்று காண்டங்கள் கொண்டது.

8. 'மணிமேகலை' யாரால் இயற்றப்பட்டது?

  1. இளங்கோவடிகள்
  2. சீத்தலைச் சாத்தனார்
  3. கம்பர்
  4. திருவள்ளுவர்

Answer: சீத்தலைச் சாத்தனார்

Explanation: மணிமேகலை — சீத்தலைச் சாத்தனார் இயற்றியது. கோவலன் மற்றும் மாதவியின் மகளான மணிமேகலையின் கதையை கூறுகிறது. இது சிலப்பதிகாரத்தின் தொடர்நூல். பௌத்த தத்துவங்களை விளக்குகிறது.

9. 'சீவகசிந்தாமணி' என்ற காப்பியம் எந்த மதக் கொள்கைகளை அடிப்படையாகக் கொண்டது?

  1. பௌத்தம்
  2. இந்துமதம்
  3. சமணம்
  4. இஸ்லாம்

Answer: சமணம்

Explanation: சீவகசிந்தாமணி — திருத்தக்கதேவர் இயற்றிய சமண சமயக் காப்பியம். சீவகன் என்ற மன்னனின் கதையை கூறுகிறது. 'நூலின் நயம்' (செய்யுள் அழகு) மிக்கது எனப் புகழ்பெற்றது.

10. சிலப்பதிகாரம் என்னும் காப்பியத்தை இயற்றியவர் யார்?

  1. இளங்கோவடிகள்
  2. சாத்தனார்
  3. சீத்தலைச் சாத்தனார்
  4. கம்பர்

Answer: இளங்கோவடிகள்

Explanation: சிலப்பதிகாரம் இளங்கோவடிகளால் இயற்றப்பட்ட காப்பியம் ஆகும்.

11. திருக்குறளில் எத்தனை அதிகாரங்கள் உள்ளன?

  1. 133
  2. 108
  3. 380
  4. 100

Answer: 108

Explanation: திருக்குறளில் 133 அதிகாரங்கள் உள்ளன, ஒவ்வொன்றும் 10 குறள்களைக் கொண்டது.

12. கம்பராமாயணத்தை இயற்றியவர் யார்?

  1. கம்பர்
  2. இளங்கோவடிகள்
  3. சேக்கிழார்
  4. திருமூலர்

Answer: கம்பர்

Explanation: கம்பராமாயணத்தை கம்பர் இயற்றினார்; இது தமிழ் காப்பியங்களில் ஒன்று.

13. பட்டினப்பாலை மற்றும் மலைபடுகடாம் ஆகியவை எந்தத் தொகை நூல்களில் அடங்கும்?

  1. பத்துப்பாட்டு
  2. எட்டுத்தொகை
  3. தொல்காப்பியம்
  4. சங்க இலக்கியம்

Answer: பத்துப்பாட்டு

Explanation: பத்துப்பாட்டு தொகுப்பில் பத்து நீண்ட பாடல்கள் உள்ளன; பட்டினப்பாலை, மலைபடுகடாம் ஆகியவை இதில் அடங்கும்.

14. சிலப்பதிகாரத்தின் கதாநாயகியின் பெயர் என்ன?

  1. கண்ணகி
  2. மாதவி
  3. கோவலன்
  4. நெடுஞ்செழியன்

Answer: கண்ணகி

Explanation: சிலப்பதிகாரத்தின் கதாநாயகி கண்ணகி ஆவார்.

15. திருக்குறளின் முதல் அதிகாரம் எது?

  1. கடவுள் வாழ்த்து
  2. வான்சிறப்பு
  3. அறன் வலியுறுத்தல்
  4. நீத்தார் பெருமை

Answer: கடவுள் வாழ்த்து

Explanation: திருக்குறளின் முதல் அதிகாரம் 'கடவுள் வாழ்த்து' ஆகும்.

16. தேவாரம் என்பது எதைக் குறிக்கும்?

  1. சைவ சமயப் பதிகங்கள்
  2. வைணவ பாசுரங்கள்
  3. சங்கப் பாடல்கள்
  4. அகநானூற்றுப் பாடல்கள்

Answer: சைவ சமயப் பதிகங்கள்

Explanation: தேவாரம் சைவ சமயத்தின் மூவர் (சம்பந்தர், அப்பர், சுந்தரர்) பாடிய பதிகங்களைக் குறிக்கும்.

17. ஐங்குறுநூறு எத்தனை பாடல்களைக் கொண்டது?

  1. 500
  2. 400
  3. 300
  4. 200

Answer: 500

Explanation: ஐங்குறுநூறு 500 பாடல்களைக் கொண்ட சங்க இலக்கிய நூல்.

18. தமிழ் இலக்கண நூலான தொல்காப்பியத்தை இயற்றியவர் யார்?

  1. தொல்காப்பியர்
  2. அகத்தியர்
  3. பட்டினத்தார்
  4. நக்கீரர்

Answer: தொல்காப்பியர்

Explanation: தொல்காப்பியம் என்னும் இலக்கண நூலை தொல்காப்பியர் இயற்றினார்.

19. சிலப்பதிகாரத்தில் இடம்பெறும் 'அரங்கேற்று காதை' எந்த நகரத்தைப் பற்றி கூறுகிறது?

  1. மதுரை
  2. காவிரிப்பூம்பட்டினம்
  3. வஞ்சி
  4. காஞ்சி

Answer: காவிரிப்பூம்பட்டினம்

Explanation: அரங்கேற்று காதை காவிரிப்பூம்பட்டினத்தில் நடைபெறும் நிகழ்வுகளை விவரிக்கிறது.

20. சிலப்பதிகாரத்தின் காலம் எது?

  1. கி.பி. 2-ஆம் நூற்றாண்டு
  2. கி.பி. 5-ஆம் நூற்றாண்டு
  3. கி.மு. 3-ஆம் நூற்றாண்டு
  4. கி.பி. 12-ஆம் நூற்றாண்டு

Answer: கி.பி. 5-ஆம் நூற்றாண்டு

Explanation: சிலப்பதிகாரம் கி.பி. 5-ஆம் நூற்றாண்டில் இளங்கோவடிகளால் இயற்றப்பட்ட காப்பியமாகும்.

21. சங்க இலக்கியத்தில் 'குறுந்தொகை' எந்தத் தொகுப்பைச் சேர்ந்தது?

  1. பத்துப்பாட்டு
  2. எட்டுத்தொகை
  3. பதினெண்கீழ்க்கணக்கு
  4. பதினெண்மேல்க்கணக்கு

Answer: எட்டுத்தொகை

Explanation: குறுந்தொகை எட்டுத்தொகை நூல்களில் ஒன்றாகும்.

22. திருக்குறளில் 'அறத்துப்பால்' எத்தனை அதிகாரங்களைக் கொண்டுள்ளது?

  1. 13
  2. 25
  3. 38
  4. 70

Answer: 38

Explanation: அறத்துப்பால் 38 அதிகாரங்களையும், பொருட்பால் 70, இன்பத்துப்பால் 25 அதிகாரங்களையும் கொண்டது.

23. 'நாலடியார்' எந்த இலக்கிய வகையைச் சேர்ந்தது?

  1. சங்க இலக்கியம்
  2. பதினெண்கீழ்க்கணக்கு
  3. பக்தி இலக்கியம்
  4. காப்பியம்

Answer: பதினெண்கீழ்க்கணக்கு

Explanation: நாலடியார் பதினெண்கீழ்க்கணக்கு நூல்களில் ஒன்றாகும்.

24. 'தேவாரம்' இயற்றிய மூவர் யாவர்?

  1. அப்பர், சுந்தரர், மாணிக்கவாசகர்
  2. திருஞானசம்பந்தர், அப்பர், சுந்தரர்
  3. திருஞானசம்பந்தர், அப்பர், மாணிக்கவாசகர்
  4. நாயன்மார்கள் மூவர்

Answer: திருஞானசம்பந்தர், அப்பர், சுந்தரர்

Explanation: தேவாரம் திருஞானசம்பந்தர், அப்பர், சுந்தரர் ஆகிய மூவரால் இயற்றப்பட்டது. மாணிக்கவாசகர் திருவாசகம் இயற்றினார்.

25. எழுத்து, சொல், பொருள் என்பன எந்த இலக்கண நூலில் விளக்கப்பட்டுள்ளன?

  1. தொல்காப்பியம்
  2. நன்னூல்
  3. வீரசோழியம்
  4. இலக்கண விளக்கம்

Answer: தொல்காப்பியம்

Explanation: தொல்காப்பியம் எழுத்ததிகாரம், சொல்லதிகாரம், பொருளதிகாரம் என மூன்று பிரிவுகளைக் கொண்டது.
