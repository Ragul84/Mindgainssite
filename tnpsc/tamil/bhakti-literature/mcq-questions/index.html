26. 'திருக்குறள்' நூலில் 'அறத்துப்பால்' எத்தனை அதிகாரங்களைக் கொண்டது?

  1. 38
  2. 25
  3. 40
  4. 35

Answer: 38

Explanation: திருக்குறளில் அறத்துப்பால் 38 அதிகாரங்களையும், 380 குறள்களையும் கொண்டது.

27. தமிழ் இலக்கணத்தில் 'எழுத்து' பற்றி விளக்கும் நூல் எது?

  1. தொல்காப்பியம் எழுத்ததிகாரம்
  2. தொல்காப்பியம் சொல்லதிகாரம்
  3. தொல்காப்பியம் பொருளதிகாரம்
  4. நன்னூல்

Answer: தொல்காப்பியம் எழுத்ததிகாரம்

Explanation: தொல்காப்பியத்தின் எழுத்ததிகாரம் தமிழ் எழுத்துகளின் இயல்புகளை விளக்குகிறது.

28. பக்தி இலக்கியத்தில் 'காரைக்கால் அம்மையார்' இயற்றிய நூல் எது?

  1. திருவாலங்காட்டு மூத்த திருப்பதிகம்
  2. திருவாசகம்
  3. தேவாரம்
  4. திருப்பாவை

Answer: திருவாலங்காட்டு மூத்த திருப்பதிகம்

Explanation: காரைக்கால் அம்மையார் சிவபெருமான் மீது 'திருவாலங்காட்டு மூத்த திருப்பதிகம்' என்னும் நூலை இயற்றினார்.

29. பன்னிரு திருமுறைகளில் முதல் ஏழு திருமுறைகள் எந்த நூலின் பகுதியாகும்?

  1. திருவாசகம்
  2. திவ்வியப் பிரபந்தம்
  3. தேவாரம்
  4. பெரிய புராணம்

Answer: தேவாரம்

Explanation: முதல் ஏழு திருமுறைகள் தேவாரம் எனப்படும். இது சம்பந்தர், நாவுக்கரசர், சுந்தரர் ஆகியோரின் பாடல்களைக் கொண்டுள்ளது.

30. திருவாசகம் எந்த திருமுறையில் அடங்கும்?

  1. எட்டாம் திருமுறை
  2. ஏழாம் திருமுறை
  3. ஒன்பதாம் திருமுறை
  4. பதினொன்றாம் திருமுறை

Answer: எட்டாம் திருமுறை

Explanation: திருவாசகம் எட்டாம் திருமுறையாகும். இது மாணிக்கவாசகரால் இயற்றப்பட்டது.

31. ஆழ்வார்களின் பாடல்கள் அடங்கிய தொகுப்பு எவ்வாறு அழைக்கப்படுகிறது?

  1. நாலாயிர திவ்வியப் பிரபந்தம்
  2. பன்னிரு திருமுறை
  3. திருப்பாவை
  4. பெரியாழ்வார் திருமொழி

Answer: நாலாயிர திவ்வியப் பிரபந்தம்

Explanation: ஆழ்வார்களின் 4000 பாடல்கள் நாலாயிர திவ்வியப் பிரபந்தம் எனப்படும்.

32. பெரிய புராணத்தை இயற்றியவர் யார்?

  1. சேக்கிழார்
  2. கம்பர்
  3. நம்பியாண்டார் நம்பி
  4. மாணிக்கவாசகர்

Answer: சேக்கிழார்

Explanation: சேக்கிழார் பெரிய புராணத்தை இயற்றினார். இது 63 நாயன்மார்களின் வரலாற்றைக் கூறுகிறது.

33. திருஞானசம்பந்தர், திருநாவுக்கரசர், சுந்தரர் ஆகிய மூவரும் எந்தப் பகுப்பில் அடங்குவர்?

  1. நாயன்மார்கள்
  2. ஆழ்வார்கள்
  3. சமண முனிவர்கள்
  4. பௌத்தத் துறவிகள்

Answer: நாயன்மார்கள்

Explanation: இம்மூவரும் சைவ சமயத்தின் நாயன்மார்கள் ஆவர். இவர்கள் தேவாரம் இயற்றியவர்கள்.

34. தேவாரத்தின் முதல் திருமுறையை இயற்றியவர் யார்?

  1. திருஞானசம்பந்தர்
  2. திருநாவுக்கரசர்
  3. சுந்தரர்
  4. மாணிக்கவாசகர்

Answer: திருஞானசம்பந்தர்

Explanation: முதல் திருமுறை திருஞானசம்பந்தர் இயற்றிய தேவாரப் பாடல்களைக் கொண்டுள்ளது.

35. சைவத் திருமுறைகள் மொத்தம் எத்தனை?

  1. 12
  2. 18
  3. 9
  4. 63

Answer: 12

Explanation: சைவ சமயத்தில் பன்னிரு திருமுறைகள் உள்ளன. இவை தேவாரம், திருவாசகம் முதலியவற்றை உள்ளடக்கியது.

36. நாலாயிர திவ்வியப் பிரபந்தத்தில் எத்தனை பாடல்கள் உள்ளன?

  1. 4000
  2. 1000
  3. 400
  4. 3000

Answer: 4000

Explanation: நாலாயிர திவ்வியப் பிரபந்தம் 4000 பாடல்களைக் கொண்டுள்ளது. இது 12 ஆழ்வார்களின் பாடல்களின் தொகுப்பு.

37. திருப்பாவை எழுதியவர் யார்?

  1. ஆண்டாள்
  2. பெரியாழ்வார்
  3. திருமழிசையாழ்வார்
  4. நம்மாழ்வார்

Answer: ஆண்டாள்

Explanation: ஆண்டாள் திருப்பாவையை இயற்றினார். இது நாலாயிர திவ்வியப் பிரபந்தத்தின் ஒரு பகுதி.

38. திருவெம்பாவை எந்த நூலின் பகுதி?

  1. தேவாரம்
  2. திருவாசகம்
  3. திருப்பாவை
  4. பெரிய புராணம்

Answer: திருவாசகம்

Explanation: திருவெம்பாவை திருவாசகத்தில் உள்ள பாடல்கள். இது மாணிக்கவாசகரால் இயற்றப்பட்டது.

39. நாலாயிர திவ்ய பிரபந்தத்தில் முதல் ஆயிரம் பாடல்களை இயற்றியவர் யார்?

  1. ஆண்டாள்
  2. திருமழிசையாழ்வார்
  3. பெரியாழ்வார்
  4. நம்மாழ்வார்

Answer: பெரியாழ்வார்

Explanation: பெரியாழ்வார் நாலாயிர திவ்ய பிரபந்தத்தில் முதல் ஆயிரம் பாடல்களை இயற்றியவர் ஆவார்.

40. தேவாரம் என்பது எத்தனை திருமுறைகளை உள்ளடக்கியது?

  1. மூன்று
  2. ஏழு
  3. பன்னிரண்டு
  4. ஐந்து

Answer: மூன்று

Explanation: தேவாரம் முதல் மூன்று திருமுறைகளை உள்ளடக்கிய சைவ பக்தி இலக்கியமாகும்.

41. திருக்குறளில் 'அறத்துப்பால்' எத்தனை அதிகாரங்களைக் கொண்டுள்ளது?

  1. 38
  2. 25
  3. 70
  4. 40

Answer: 38

Explanation: திருக்குறளில் அறத்துப்பால் 38 அதிகாரங்களையும், 380 குறள்களையும் கொண்டுள்ளது.

42. சங்க இலக்கியத்தில் 'புறநானூறு' எத்தனை பாடல்களைக் கொண்டுள்ளது?

  1. 400
  2. 268
  3. 500
  4. 300

Answer: 268

Explanation: புறநானூறு 268 பாடல்களைக் கொண்ட புறப்பொருள் பற்றிய சங்க இலக்கிய நூலாகும்.

43. எழுத்து இலக்கணத்தில் 'உயிர்மெய்' எழுத்துகள் எத்தனை?

  1. 216
  2. 12
  3. 18
  4. 247

Answer: 216

Explanation: உயிர்மெய் எழுத்துகள் 12 உயிர்களும் 18 மெய்களும் சேர்ந்து 216 ஆகும்.

44. திருக்குறளில் 'இனியவை கூறல்' எந்த அதிகாரத்தில் வருகிறது?

  1. இனியவை கூறல்
  2. சொல்வன்மை
  3. அறிவுடைமை
  4. கல்லாமை

Answer: இனியவை கூறல்

Explanation: திருக்குறளில் 10வது அதிகாரமான 'இனியவை கூறல்' இனிமையாகப் பேசுவதன் சிறப்பை விளக்குகிறது.

45. சொல் இலக்கணத்தில் 'வேற்றுமை' எத்தனை வகைப்படும்?

  1. 8
  2. 6
  3. 7
  4. 5

Answer: 8

Explanation: தமிழ் இலக்கணத்தில் வேற்றுமை எட்டு வகைப்படும், அவை பெயருக்கும் வினைக்கும் உறவைக் காட்டுகின்றன.

46. சங்க இலக்கியத்தில் 'ஐங்குறுநூறு' எந்த திணையைச் சார்ந்தது?

  1. அகம்
  2. புறம்
  3. கலம்பகம்
  4. உரைநடை

Answer: அகம்

Explanation: ஐங்குறுநூறு அகப்பொருள் பற்றிய சங்க இலக்கிய நூலாகும், இது 500 பாடல்களைக் கொண்டது.

47. நாலாயிர திவ்ய பிரபந்தத்தில் உள்ள பாசுரங்களின் மொத்த எண்ணிக்கை என்ன?

  1. 4000
  2. 3000
  3. 6000
  4. 1000

Answer: 4000

Explanation: நாலாயிர திவ்ய பிரபந்தம் 4000 பாசுரங்களைக் கொண்ட வைணவ பக்தி இலக்கியத் தொகுப்பாகும்.

48. பக்தி இலக்கியத்தில் சைவ சமயத்தைச் சேர்ந்த நாயன்மார்களின் பாடல்கள் எந்த நூலில் தொகுக்கப்பட்டுள்ளன?

  1. தேவாரம்
  2. திருவாசகம்
  3. திவ்ய பிரபந்தம்
  4. கம்பராமாயணம்

Answer: தேவாரம்

Explanation: சைவ நாயன்மார்கள் அறுபத்து மூவர் பாடிய பதிகங்கள் தேவாரம் எனத் தொகுக்கப்பட்டுள்ளன. திருவாசகம் மாணிக்கவாசகர் பாடியது.

49. வைணவ பக்தி இலக்கியமான நாலாயிர திவ்ய பிரபந்தத்தை தொகுத்தவர் யார்?

  1. நாதமுனி
  2. இராமானுஜர்
  3. மணவாள மாமுனிகள்
  4. வேதாந்த தேசிகர்

Answer: நாதமுனி

Explanation: நாலாயிர திவ்ய பிரபந்தத்தை ஆழ்வார்கள் பாடல்களைத் தொகுத்தவர் நாதமுனி ஆவார். இராமானுஜர் விசிஷ்டாத்வைதத்தை விளக்கியவர்.

50. பன்னிரு திருமுறைகளில் முதல் மூன்று திருமுறைகள் எவ்வாறு அழைக்கப்படுகின்றன?

  1. திருவாசகம்
  2. தேவாரம்
  3. திருப்பாவை
  4. நாலாயிர திவ்ய பிரபந்தம்

Answer: தேவாரம்

Explanation: முதல் மூன்று திருமுறைகளான சம்பந்தர், அப்பர், சுந்தரர் பாடல்கள் தேவாரம் எனப்படும்.
