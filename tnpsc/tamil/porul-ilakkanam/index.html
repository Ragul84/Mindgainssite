Porul Ilakkanam MCQs with answers

Use these 25 worked Porul Ilakkanam questions to revise the TNPSC Tamil syllabus. Each answer includes an explanation; the full practice set contains 80 questions.

1. அகத்திணைகள் எத்தனை?

  1. 5
  2. 7
  3. 8
  4. 10

Answer: 5

Explanation: அகத்திணைகள் 5: குறிஞ்சி (மலை - காதல் ஒருமித்தல்), முல்லை (காடு - இரவு கூட்டல்), மருதம் (வயல் - ஊடல்), நெய்தல் (கடல் - இரங்கல்), பாலை (வழி - பிரிதல்).

2. குறிஞ்சித் திணை எந்த நில/காலத்தை குறிக்கிறது?

  1. கடல் - பகல்
  2. மலை - கூதிர்/முன்பனி
  3. வயல் - முன்பனி
  4. காடு - கார்காலம்

Answer: மலை - கூதிர்/முன்பனி

Explanation: குறிஞ்சித் திணை: நிலம் - மலையும் மலை சார்ந்த இடமும், காலம் - கூதிர் மற்றும் முன்பனிக்காலம், பூ - குறிஞ்சி, உரிப்பொருள் - புணர்தல் (காதல் ஒருமித்தல்).

3. புறநானூறு எந்த வகை இலக்கியம்?

  1. அகப்பொருள்
  2. புறப்பொருள்
  3. பக்தி இலக்கியம்
  4. நீதி இலக்கியம்

Answer: புறப்பொருள்

Explanation: புறநானூறு புறப்பொருள் இலக்கியம். இது போர், வீரம், கொடை, அரசர் புகழ் பற்றிய 400 பாடல்களை கொண்டது.

4. 'ஆடு மேய்த்தவன் ஆனை மேய்க்கலாம்' — இந்த பழமொழியின் கருத்து என்ன?

  1. சிறிய வேலையிலிருந்து பெரிய வேலைக்கு செல்லலாம்
  2. ஆடும் யானையும் சேர்ந்து மேயும்
  3. கால்நடை வளர்ப்பு முக்கியம்
  4. உழைப்பால் எதுவும் செய்யலாம்

Answer: சிறிய வேலையிலிருந்து பெரிய வேலைக்கு செல்லலாம்

Explanation: 'ஆடு மேய்த்தவன் ஆனை மேய்க்கலாம்' — சிறிய அனுபவம் பெற்றவர்கள் பெரிய பொறுப்புகளையும் ஏற்கலாம் என்பது இப்பழமொழியின் பொருள். திறமை வளரும் என்ற நம்பிக்கையை வெளிப்படுத்துகிறது.

5. 'யானை வரும் பின்னே மணி ஓசை வரும் முன்னே' — இதன் கருத்து என்ன?

  1. யானை ஊர்வலம்
  2. பெரியோர் வரும் முன் அவர்களின் புகழ் முன்னரே வரும்
  3. ஒலியின் வேகம் யானையை விட வேகமானது
  4. கோயில் யானை வரும் அறிகுறி

Answer: பெரியோர் வரும் முன் அவர்களின் புகழ் முன்னரே வரும்

Explanation: 'யானை வரும் பின்னே மணி ஓசை வரும் முன்னே' — சிறந்தவர்கள் / பெரியவர்கள் வருவதற்கு முன்பே அவர்களின் புகழ் / செய்தி முன்னரே எட்டும் என்பது இதன் பொருள்.

6. பொருளிலக்கணம் என்பது எதனை விளக்குவது?

  1. இலக்கியங்களின் பொருளை
  2. எழுத்துகளை
  3. சொற்களை
  4. யாப்பை

Answer: இலக்கியங்களின் பொருளை

Explanation: பொருளிலக்கணம் இலக்கியங்களின் உள்ளடக்கத்தையும் பொருளையும் விளக்கும் இலக்கணமாகும்.

7. தொல்காப்பியத்தில் பொருளதிகாரம் எத்தனை இயல்களைக் கொண்டது?

  1. 9
  2. 3
  3. 5
  4. 7

Answer: 9

Explanation: தொல்காப்பிய பொருளதிகாரம் மொத்தம் 9 இயல்களை கொண்டுள்ளது.

8. திருக்குறளின் மூன்று பால்களில் பொருள் பற்றிய பகுதி எது?

  1. அறத்துப்பால்
  2. பொருட்பால்
  3. இன்பத்துப்பால்
  4. காமத்துப்பால்

Answer: பொருட்பால்

Explanation: திருக்குறள் அறம், பொருள், இன்பம் என மூன்று பால்களில் பொருட்பால் பொருள் வளம் பற்றியது.

9. திருவாசகம் இயற்றிய நாயன்மார் யார்?

  1. சுந்தரர்
  2. திருஞானசம்பந்தர்
  3. மாணிக்கவாசகர்
  4. அப்பர்

Answer: மாணிக்கவாசகர்

Explanation: மாணிக்கவாசகர் திருவாசகம் என்னும் சைவத் திருப்பதிகத்தை இயற்றியவர்.

10. சங்க இலக்கியத்தில் அகம் மற்றும் புறம் பாடல்களை உள்ளடக்கிய தொகுப்பு எது?

  1. எட்டுத்தொகை
  2. பத்துப்பாட்டு
  3. பதினெண்கீழ்க்கணக்கு
  4. சிலப்பதிகாரம்

Answer: எட்டுத்தொகை

Explanation: எட்டுத்தொகை அகம் மற்றும் புறம் இருவகைப் பாடல்களையும் கொண்ட தொகுப்பாகும்.

11. தொல்காப்பியத்தின் எந்த அதிகாரம் பொருளை விளக்குகிறது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. யாப்பதிகாரம்

Answer: பொருளதிகாரம்

Explanation: தொல்காப்பியம் மூன்று அதிகாரங்களில் பொருளதிகாரம் இலக்கியப் பொருளை விளக்குகிறது.

12. பத்துப்பாட்டு எதை முதன்மையாகக் கொண்டது?

  1. அகம்
  2. புறம்
  3. அகமும் புறமும்
  4. கற்பனை

Answer: அகமும் புறமும்

Explanation: பத்துப்பாட்டு அகம் மற்றும் புறம் இரண்டையும் உள்ளடக்கிய பாட்டுத் தொகுப்பாகும்.

13. தேவாரம் இயற்றியவர்கள் யார்?

  1. சைவ நாயன்மார்கள்
  2. வைணவ ஆழ்வார்கள்
  3. சமண முனிவர்கள்
  4. பௌத்த துறவிகள்

Answer: சைவ நாயன்மார்கள்

Explanation: தேவாரம் சைவ நாயன்மார்களால் பாடப்பட்ட திருப்பதிகங்கள் ஆகும்.

14. தொல்காப்பிய பொருளதிகாரம் எந்த இலக்கியத்தை அடிப்படையாகக் கொண்டது?

  1. சங்க இலக்கியம்
  2. காப்பியங்கள்
  3. பக்தி இலக்கியம்
  4. நீதி இலக்கியம்

Answer: சங்க இலக்கியம்

Explanation: தொல்காப்பிய பொருளதிகாரம் சங்க இலக்கிய மரபின் அடிப்படையில் அமைந்தது.

15. திருக்குறளில் பொருட்பாலின் முதல் அதிகாரம் எது?

  1. கடவுள் வாழ்த்து
  2. மெய்யுணர்தல்
  3. இல்வாழ்க்கை
  4. அறன்அறிந்தார்

Answer: இல்வாழ்க்கை

Explanation: திருக்குறள் பொருட்பாலின் முதல் அதிகாரம் 'இல்வாழ்க்கை' ஆகும்.

16. தொல்காப்பியத்தின் பொருளதிகாரத்தில் உள்ள இயல்களின் எண்ணிக்கை எவ்வளவு?

  1. 7
  2. 8
  3. 9
  4. 10

Answer: 9

Explanation: தொல்காப்பியத்தின் பொருளதிகாரம் 9 இயல்களைக் கொண்டது.

17. திருக்குறளில் 'அகர முதல எழுத்தெல்லாம் ஆதி பகவன் முதற்றே உலகு' என்ற குறள் எந்த அதிகாரத்தில் உள்ளது?

  1. கடவுள் வாழ்த்து
  2. வான்சிறப்பு
  3. நீத்தல் உடைமை
  4. அருளுடைமை

Answer: கடவுள் வாழ்த்து

Explanation: திருக்குறளின் முதல் அதிகாரம் கடவுள் வாழ்த்து ஆகும்.

18. சங்க இலக்கியமான 'ஐங்குறுநூறு' எத்தனை திணைகளாகப் பிரிக்கப்பட்டுள்ளது?

  1. 3
  2. 5
  3. 7
  4. 9

Answer: 5

Explanation: ஐங்குறுநூறு ஐந்து திணைகளாகப் பிரிக்கப்பட்டுள்ளது.

19. தேவாரம் பாடிய மூவர் யாவர்?

  1. திருஞானசம்பந்தர், அப்பர், சுந்தரர்
  2. மாணிக்கவாசகர், திருஞானசம்பந்தர், அப்பர்
  3. சுந்தரர், அப்பர், மாணிக்கவாசகர்
  4. திருஞானசம்பந்தர், சுந்தரர், கம்பர்

Answer: திருஞானசம்பந்தர், அப்பர், சுந்தரர்

Explanation: தேவாரம் திருஞானசம்பந்தர், அப்பர், சுந்தரர் ஆகிய மூவரால் பாடப்பட்டது.

20. தொல்காப்பியத்தில் 'பொருளதிகாரம்' எத்தனை இயல்களைக் கொண்டுள்ளது?

  1. ஒன்பது
  2. எட்டு
  3. ஏழு
  4. பத்து

Answer: ஒன்பது

Explanation: தொல்காப்பியத்தின் பொருளதிகாரம் ஒன்பது இயல்களை உள்ளடக்கியது.

21. சங்க இலக்கியத்தில் 'புறம்' என்னும் பொருளை விளக்கும் நூல் எது?

  1. புறநானூறு
  2. அகநானூறு
  3. கலித்தொகை
  4. ஐங்குறுநூறு

Answer: புறநானூறு

Explanation: புறநானூறு புறத்திணை பற்றிய பொருள்களை விளக்கும் சங்க இலக்கிய நூலாகும்.

22. திருக்குறளில் 'இல்லறவியல்' எத்தனை அதிகாரங்களைக் கொண்டது?

  1. 20
  2. 25
  3. 30
  4. 15

Answer: 20

Explanation: திருக்குறளின் இல்லறவியல் 20 அதிகாரங்களை (அதிகாரம் 1 முதல் 20 வரை) கொண்டுள்ளது.

23. சிலப்பதிகாரத்தில் 'கானல் வரி' எந்த இலக்கண வகையைச் சேர்ந்தது?

  1. பாடல் வகை
  2. உரை வகை
  3. துறை வகை
  4. யாப்பு வகை

Answer: பாடல் வகை

Explanation: கானல் வரி பாடல் வகையைச் சேர்ந்தது; இது சிலப்பதிகாரத்தின் மதுரைக் காண்டத்தில் வரும் பாடல்கள்.

24. தொல்காப்பியர் கூறும் 'மெய்ப்பாடு' எத்தனை வகைப்படும்?

  1. எட்டு
  2. நான்கு
  3. ஆறு
  4. பத்து

Answer: எட்டு

Explanation: தொல்காப்பியம் மெய்ப்பாடு எட்டு வகைப்படும் எனக் கூறுகிறது (நகை, அழுகை முதலியன).

25. குறுந்தொகையில் இடம்பெறும் பாடல்கள் எந்தத் திணையை முதன்மையாகக் கொண்டவை?

  1. அகம்
  2. புறம்
  3. கைக்கிளை
  4. பெருந்திணை

Answer: அகம்

Explanation: குறுந்தொகை அகத்திணைப் பாடல்களை முதன்மையாகக் கொண்ட சங்க இலக்கிய நூலாகும்.
