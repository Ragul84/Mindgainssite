26. சங்க இலக்கியங்களுள் பதினெண் கீழ்க்கணக்கு நூல்களில் ஒன்றான 'திருக்குறள்' எத்தனை அதிகாரங்களைக் கொண்டது?

  1. 133
  2. 108
  3. 140
  4. 120

Answer: 133

Explanation: திருக்குறள் 133 அதிகாரங்களையும், 1330 குறள்களையும் கொண்டது.

27. சங்க காலத்தில் 'வள்ளல்கள்' என அழைக்கப்பட்டவர்கள் யாவர்?

  1. அரசர்கள்
  2. வணிகர்கள்
  3. கொடையாளிகள்
  4. புலவர்கள்

Answer: கொடையாளிகள்

Explanation: சங்க காலத்தில் புலவர்களுக்கு கொடை வழங்கிய பெருந்தனக்காரர்கள் வள்ளல்கள் எனப்பட்டனர்.

28. பக்தி இலக்கியத்தில் 'தேவாரம்' என்பது யாருடைய பாடல்களைக் கொண்டது?

  1. நாயன்மார்கள்
  2. ஆழ்வார்கள்
  3. சமணர்கள்
  4. பௌத்தர்கள்

Answer: நாயன்மார்கள்

Explanation: தேவாரம் சைவ சமயத்தைச் சேர்ந்த நாயன்மார்கள் பாடிய பாடல்களின் தொகுப்பு.

29. இயற்சொல், திரிசொல், திசைச்சொல், வடசொல் என நான்கு வகைப்படும் இலக்கணக் கூறு எது?

  1. எழுத்து
  2. சொல்
  3. பொருள்
  4. யாப்பு

Answer: சொல்

Explanation: சொல்லதிகாரத்தில் சொற்கள் இயற்சொல், திரிசொல், திசைச்சொல், வடசொல் என நான்கு வகைப்படும்.

30. சங்க இலக்கியத்தில் 'முல்லை' திணைக்கு உரிய பருவம் எது?

  1. கார்
  2. கூதிர்
  3. இளவேனில்
  4. முதுவேனில்

Answer: கார்

Explanation: முல்லை திணை கார் காலத்தை (மழைக்காலம்) சார்ந்தது.

31. திருக்குறளில் 'அறத்துப்பால்' எத்தனை அதிகாரங்களைக் கொண்டுள்ளது?

  1. 38
  2. 40
  3. 70
  4. 25

Answer: 38

Explanation: திருக்குறளின் முதல் பகுதியான அறத்துப்பால் 38 அதிகாரங்களைக் கொண்டுள்ளது.

32. எழுத்து இலக்கணத்தில் 'உயிர்மெய்' எழுத்துகள் எவ்வாறு உருவாக்கப்படுகின்றன?

  1. உயிரும் மெய்யும் சேர்ந்து
  2. மெய்யும் மெய்யும் சேர்ந்து
  3. உயிரும் உயிரும் சேர்ந்து
  4. ஒற்றும் உயிரும் சேர்ந்து

Answer: உயிரும் மெய்யும் சேர்ந்து

Explanation: உயிரெழுத்தும் மெய்யெழுத்தும் சேர்ந்து உயிர்மெய் எழுத்துகள் உருவாகின்றன.

33. சங்க இலக்கியத்தில் 'புறநானூறு' எத்தனை பாடல்களைக் கொண்டுள்ளது?

  1. 400
  2. 300
  3. 500
  4. 200

Answer: 400

Explanation: புறநானூறு 400 பாடல்களைக் கொண்ட ஒரு சங்க இலக்கியத் தொகுப்பு.

34. திருக்குறளில் 'கடவுள் வாழ்த்து' அதிகாரத்தில் எத்தனை குறள்கள் உள்ளன?

  1. 10
  2. 12
  3. 8
  4. 15

Answer: 10

Explanation: திருக்குறளின் முதல் அதிகாரமான கடவுள் வாழ்த்தில் 10 குறள்கள் உள்ளன.

35. சங்க காலத்தில் 'ஐங்குறுநூறு' எத்தனை பாடல்களைக் கொண்ட நூல்?

  1. 500
  2. 400
  3. 600
  4. 300

Answer: 500

Explanation: ஐங்குறுநூறு என்பது 500 பாடல்களைக் கொண்ட சங்க இலக்கிய நூல்.

36. சங்க இலக்கியத் தொகுப்புகளில் மிக நீளமான நூல் எது?

  1. புறநானூறு
  2. அகநானூறு
  3. பத்துப்பாட்டு
  4. கலித்தொகை

Answer: பத்துப்பாட்டு

Explanation: பத்துப்பாட்டு 10 நீண்ட பாடல்களைக் கொண்ட தொகுப்பு; இதுவே சங்கத் தொகுப்புகளில் மிக நீளமானது.

37. திருக்குறள் எத்தனை அதிகாரங்களைக் கொண்டது?

  1. 133
  2. 108
  3. 120
  4. 140

Answer: 133

Explanation: திருக்குறள் 133 அதிகாரங்களைக் கொண்டது; ஒவ்வோர் அதிகாரமும் 10 குறள்களை உள்ளடக்கியது.

38. பின்வருவனவற்றுள் எட்டுத்தொகை நூல்களில் ஒன்று அல்லாதது எது?

  1. பரிபாடல்
  2. குறுந்தொகை
  3. சிலப்பதிகாரம்
  4. ஐங்குறுநூறு

Answer: சிலப்பதிகாரம்

Explanation: சிலப்பதிகாரம் காப்பியம்; எட்டுத்தொகையில் அகநானூறு, புறநானூறு, கலித்தொகை, குறுந்தொகை, நற்றிணை, பரிபாடல், ஐங்குறுநூறு, பதிற்றுப்பத்து ஆகியவை உள்ளன.

39. தொல்காப்பியம் கூறும் மூன்று அதிகாரங்கள் யாவை?

  1. எழுத்து, சொல், பொருள்
  2. இயல், இசை, நாடகம்
  3. அகம், புறம், கலப்பு
  4. நிலம், பொருள், காலம்

Answer: எழுத்து, சொல், பொருள்

Explanation: தொல்காப்பியம் எழுத்து, சொல், பொருள் என மூன்று அதிகாரங்களைக் கொண்ட முதல் தமிழ் இலக்கண நூல்.

40. சங்க காலத்தில் 'முதுமொழிக்காஞ்சி' என்னும் நூலை இயற்றியவர் யார்?

  1. கூடலூர்கிழார்
  2. மதுரைக் கணக்காயனார்
  3. பொய்கையார்
  4. கோவூர்கிழார்

Answer: கூடலூர்கிழார்

Explanation: முதுமொழிக்காஞ்சி நூலை இயற்றியவர் கூடலூர்கிழார்; இது பதினெண்கீழ்க்கணக்கு நூல்களுள் ஒன்று.

41. 'யாதும் ஊரே யாவரும் கேளிர்' என்ற பாடல் அமைந்த சங்க நூல் எது?

  1. புறநானூறு
  2. நற்றிணை
  3. குறுந்தொகை
  4. அகநானூறு

Answer: புறநானூறு

Explanation: இப்பாடல் புறநானூற்றில் (192) கணியன் பூங்குன்றனாரால் பாடப்பட்டுள்ளது.

42. சைவ சமயத்தில் தேவாரம் பாடிய மூவர் அடியார்கள் யாவர்?

  1. திருஞானசம்பந்தர், அப்பர், சுந்தரர்
  2. நம்மாழ்வார், திருமழிசையாழ்வார், பெரியாழ்வார்
  3. திருவள்ளுவர், கபிலர், ஔவையார்
  4. இளங்கோவடிகள், சாத்தனார், சீத்தலைச்சாத்தனார்

Answer: திருஞானசம்பந்தர், அப்பர், சுந்தரர்

Explanation: தேவாரம் பாடிய மூவர் திருஞானசம்பந்தர், அப்பர், சுந்தரர் ஆவர்; இவர்கள் சைவ சமயத்தின் முன்னோடிகள்.

43. பதினெண்கீழ்க்கணக்கு நூல்களில் மிகவும் சிறிய நூல் எது?

  1. ஐந்திணை எழுபது
  2. கைந்நிலை
  3. திருக்குறள்
  4. நாலடியார்

Answer: கைந்நிலை

Explanation: கைந்நிலை 10 பாடல்கள் மட்டுமே கொண்ட மிகச் சிறிய பதினெண்கீழ்க்கணக்கு நூல்.

44. சங்க இலக்கியத்தில் 'குறிஞ்சி' நிலத்தின் தலைவி எவ்வாறு அழைக்கப்படுவாள்?

  1. பறவை
  2. மகள்
  3. தோழி
  4. கிழத்தி

Answer: கிழத்தி

Explanation: குறிஞ்சி நிலத்தில் தலைவி 'கிழத்தி' என அழைக்கப்படுகிறாள்; ஐந்திணை இலக்கணப்படி இது வழங்கப்பட்டது.

45. திருக்குறளில் 'அதிகாரம்' என்ற சொல்லுக்கு இணையான பொருள் எது?

  1. இயல்
  2. பால்
  3. காதை
  4. அதிகரம்

Answer: இயல்

Explanation: திருக்குறளில் 'இயல்' என்பது அதிகாரத்தைக் குறிக்கும்; மூன்று பால்களிலும் பல இயல்கள் உள்ளன.

46. சங்க இலக்கியங்களுள் எட்டுத்தொகையில் அடங்காத நூல் எது?

  1. குறுந்தொகை
  2. புறநானூறு
  3. பத்துப்பாட்டு
  4. நற்றிணை

Answer: பத்துப்பாட்டு

Explanation: எட்டுத்தொகையில் குறுந்தொகை, புறநானூறு, நற்றிணை ஆகியன அடங்கும். பத்துப்பாட்டு எட்டுத்தொகையில் சேராது.

47. புறநானூறு எந்தத் தொகுப்பில் அடங்கும்?

  1. பதினெண்கீழ்கணக்கு
  2. எட்டுத்தொகை
  3. பத்துப்பாட்டு
  4. திருமுறை

Answer: எட்டுத்தொகை

Explanation: புறநானூறு எட்டுத்தொகை நூல்களில் ஒன்றாகும்.

48. திருக்குறளில் அறத்துப்பாலில் எத்தனை அதிகாரங்கள் உள்ளன?

  1. 25
  2. 38
  3. 40
  4. 70

Answer: 38

Explanation: அறத்துப்பாலில் 38 அதிகாரங்கள் உள்ளன. பொருட்பால் 70, இன்பத்துப்பால் 25 அதிகாரங்களைக் கொண்டது.

49. தேவாரம் இயற்றிய மூவர் யாவர்?

  1. அப்பர், சுந்தரர், மாணிக்கவாசகர்
  2. திருஞானசம்பந்தர், திருநாவுக்கரசர், சுந்தரர்
  3. நம்மாழ்வார், திருமங்கையாழ்வார், பெரியாழ்வார்
  4. திருநாவுக்கரசர், கம்பர், பாரதியார்

Answer: திருஞானசம்பந்தர், திருநாவுக்கரசர், சுந்தரர்

Explanation: தேவாரம் திருஞானசம்பந்தர், திருநாவுக்கரசர், சுந்தரர் ஆகிய மூவரால் இயற்றப்பட்டது.

50. தொல்காப்பியம் எத்தனை அதிகாரங்களைக் கொண்டது?

  1. 3
  2. 5
  3. 9
  4. 12

Answer: 3

Explanation: தொல்காப்பியம் எழுத்ததிகாரம், சொல்லதிகாரம், பொருளதிகாரம் என மூன்று அதிகாரங்களை உடையது.
