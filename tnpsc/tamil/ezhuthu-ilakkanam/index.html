1. தமிழ் மொழியில் உயிர் எழுத்துக்கள் எத்தனை?

  1. 10
  2. 12
  3. 16
  4. 18

Answer: 12

Explanation: தமிழ் மொழியில் 12 உயிர் எழுத்துக்கள் உள்ளன: அ, ஆ, இ, ஈ, உ, ஊ, எ, ஏ, ஐ, ஒ, ஓ, ஔ.

2. தமிழ் மொழியில் மெய் எழுத்துக்கள் எத்தனை?

  1. 16
  2. 18
  3. 21
  4. 18

Answer: 21

Explanation: தமிழ் மொழியில் 18 மெய் எழுத்துக்கள் உள்ளன: க், ங், ச், ஞ், ட், ண், த், ந், ப், ம், ய், ர், ல், வ், ழ், ள், ற், ன்.

3. தமிழ் மொழியில் மொத்த எழுத்துக்கள் எத்தனை?

  1. 247
  2. 216
  3. 248
  4. 218

Answer: 247

Explanation: தமிழ் மொழியில் மொத்தம் 247 எழுத்துக்கள் உள்ளன: 12 உயிர் + 18 மெய் + 216 உயிர்மெய் + 1 ஆய்த எழுத்து = 247.

4. நன்னூலை இயற்றியவர் யார்?

  1. தொல்காப்பியர்
  2. பவணந்தி முனிவர்
  3. வீரமாமுனிவர்
  4. உ.வே.சா

Answer: பவணந்தி முனிவர்

Explanation: நன்னூல் பவணந்தி முனிவரால் இயற்றப்பட்ட இலக்கண நூல். இது எழுத்து, சொல் இலக்கணத்தை விளக்குகிறது.

5. தமிழ் எழுத்துக்களில் 'ஆய்த எழுத்து' எது?

  1. அஃகு
  2. ஃ
  3. அக்
  4. ஐ

Answer: ஃ

Explanation: ஆய்த எழுத்து 'ஃ'. இது உயிரும் அல்ல, மெய்யும் அல்ல — தனியொரு வகை எழுத்து. 'தனி நிலை' எழுத்து என்றும் அழைக்கப்படுகிறது.

6. வீரமாமுனிவர் யாரால் தமிழ் இலக்கணம் இயற்றப்பட்டது?

  1. தமிழர்
  2. போர்த்துக்கீசர்
  3. ஆங்கிலேயர்
  4. பிரெஞ்சுக்காரர்

Answer: போர்த்துக்கீசர்

Explanation: வீரமாமுனிவர் (Costanzo Giuseppe Beschi) ஒரு இத்தாலிய ஜேசுயிட் மிஷனரி. அவர் 'தொன்னூல் விளக்கம்' என்ற தமிழ் இலக்கண நூலை இயற்றினார்.

7. தமிழ் இலக்கணத்தில் 'இடையச்சு' என்பது என்ன?

  1. ஒரு வகை மெய் எழுத்து
  2. ய், ர், ல், வ், ழ், ள் ஆகிய ஆறும்
  3. உயிர்மெய் எழுத்துக்கள்
  4. புணர்ச்சி விதிகள்

Answer: ய், ர், ல், வ், ழ், ள் ஆகிய ஆறும்

Explanation: இடையின எழுத்துக்கள் (இடையச்சு): ய், ர், ல், வ், ழ், ள் ஆகிய ஆறு மெய் எழுத்துக்கள். இவை வலிமை குறைவான மெய்கள். மெல்லின் (ங்,ஞ்,ண்,ந்,ம்,ன்), வல்லின (க்,ச்,ட்,த்,ப்,ற்) என்று மூவகை மெய்கள் உண்டு.

8. தமிழ் மொழியில் உயிர்மெய் எழுத்துக்கள் எத்தனை?

  1. 216
  2. 212
  3. 218
  4. 220

Answer: 216

Explanation: தமிழ் மொழியில் உயிர்மெய் எழுத்துக்கள் 216 ஆகும் (18 மெய் × 12 உயிர் = 216). மொத்தம் 247 எழுத்துக்கள் உள்ளன (12 உயிர் + 18 மெய் + 216 உயிர்மெய் + 1 ஆய்தம் = 247).

9. தமிழ் எழுத்துக்களின் மொத்த எண்ணிக்கை எத்தனை?

  1. 247
  2. 246
  3. 248
  4. 250

Answer: 247

Explanation: தமிழ் எழுத்துக்களின் மொத்த எண்ணிக்கை 247 ஆகும்: உயிர் (12) + மெய் (18) + உயிர்மெய் (216) + ஆய்தம் (1) = 247.

10. தமிழ் எழுத்துக்களில் 'ஆய்தம்' எத்தனை உள்ளது?

  1. 1
  2. 2
  3. 3
  4. 0

Answer: 1

Explanation: தமிழ் எழுத்துக்களில் ஆய்தம் 1 மட்டுமே உள்ளது. அது 'ஃ' என குறிக்கப்படும். இது உயிரும் அல்ல, மெய்யும் அல்ல; தனி வகை எழுத்தாகும்.

11. குற்றெழுத்துக்கள் என்பவை எவை?

  1. நீண்ட உயிர் எழுத்துக்கள்
  2. குறுகிய உயிர் எழுத்துக்கள் (அ, இ, உ, எ, ஒ) மற்றும் அவை சேர்ந்த உயிர்மெய்கள்
  3. மெய் எழுத்துக்கள்
  4. ஆய்தம்

Answer: குறுகிய உயிர் எழுத்துக்கள் (அ, இ, உ, எ, ஒ) மற்றும் அவை சேர்ந்த உயிர்மெய்கள்

Explanation: குற்றெழுத்துக்கள் என்பவை ஒரு மாத்திரை அளவு மட்டுமே உள்ள எழுத்துக்கள். அ, இ, உ, எ, ஒ மற்றும் அவை சேர்ந்த உயிர்மெய்கள் குற்றெழுத்துக்கள் ஆகும்.

12. நெட்டெழுத்துக்கள் என்பவை எவை?

  1. இரண்டு மாத்திரை அளவுள்ள எழுத்துக்கள் (ஆ, ஈ, ஊ, ஏ, ஐ, ஓ, ஔ)
  2. ஒரு மாத்திரை அளவுள்ள எழுத்துக்கள்
  3. அரை மாத்திரை அளவுள்ள எழுத்துக்கள்
  4. மூன்று மாத்திரை அளவுள்ள எழுத்துக்கள்

Answer: இரண்டு மாத்திரை அளவுள்ள எழுத்துக்கள் (ஆ, ஈ, ஊ, ஏ, ஐ, ஓ, ஔ)

Explanation: நெட்டெழுத்துக்கள் என்பவை இரண்டு மாத்திரை அளவுள்ள நீண்ட உயிர் எழுத்துக்கள்: ஆ, ஈ, ஊ, ஏ, ஐ, ஓ, ஔ. இவை ஏழு ஆகும்.

13. வல்லின மெய் எழுத்துக்கள் எவை?

  1. ய், ர், ல், வ், ழ், ள்
  2. க், ச், ட், த், ப், ற்
  3. ங், ஞ், ண், ந், ம், ன்
  4. க், ங், ச், ஞ், ட், ண்

Answer: க், ச், ட், த், ப், ற்

Explanation: வல்லின மெய் எழுத்துக்கள்: க், ச், ட், த், ப், ற் — ஆறு எழுத்துக்கள். இவை கடினமான ஒலியுடன் உச்சரிக்கப்படும். தமிழ் அகரவரிசையில் முதல் வரி எழுத்துக்கள் வல்லினம்.

14. மெல்லின மெய் எழுத்துக்கள் எவை?

  1. க், ச், ட், த், ப், ற்
  2. ய், ர், ல், வ், ழ், ள்
  3. ங், ஞ், ண், ந், ம், ன்
  4. எல்லா மெய்யும்

Answer: ங், ஞ், ண், ந், ம், ன்

Explanation: மெல்லின மெய் எழுத்துக்கள்: ங், ஞ், ண், ந், ம், ன் — ஆறு எழுத்துக்கள். இவை மென்மையான ஒலியுடன் உச்சரிக்கப்படும். அனைத்தும் மூக்கோசை ஒலிகள் ஆகும்.

15. இடையின மெய் எழுத்துக்கள் எவை?

  1. க், ச், ட், த், ப், ற்
  2. ங், ஞ், ண், ந், ம், ன்
  3. ய், ர், ல், வ், ழ், ள்
  4. எல்லா இடை எழுத்தும்

Answer: ய், ர், ல், வ், ழ், ள்

Explanation: இடையின மெய் எழுத்துக்கள்: ய், ர், ல், வ், ழ், ள் — ஆறு எழுத்துக்கள். இவை வல்லினத்திற்கும் மெல்லினத்திற்கும் இடையே உள்ளன.

16. 'புணர்ச்சி' என்பது தமிழ் இலக்கணத்தில் என்ன குறிக்கிறது?

  1. வேர்ச்சொல் பகுப்பு
  2. இரண்டு சொற்கள் சேரும்போது நிகழும் மாற்றங்கள்
  3. சொல்லின் பொருள் மாற்றம்
  4. கவிதை இயற்றும் முறை

Answer: இரண்டு சொற்கள் சேரும்போது நிகழும் மாற்றங்கள்

Explanation: புணர்ச்சி என்பது இரண்டு சொற்கள் சேரும்போது (முன்னொட்டு + பின்னொட்டு) ஏற்படும் ஒலி மாற்றங்களையும் எழுத்து மாற்றங்களையும் விளக்கும் இலக்கண விதி.

17. 'அகர முதல எழுத்தெல்லாம் ஆதி பகவன் முதற்றே உலகு' — இக்குறளின் கருத்து என்ன?

  1. எழுத்துக்களில் 'அ' முதன்மையானது போல, உலகுக்கு கடவுள் முதன்மையானவர்
  2. வேதங்களில் 'அ' மிக முக்கியம்
  3. அகர வரிசை கடவுளால் உருவாக்கப்பட்டது
  4. எழுத்துக்கள் 247 உள்ளன

Answer: எழுத்துக்களில் 'அ' முதன்மையானது போல, உலகுக்கு கடவுள் முதன்மையானவர்

Explanation: எழுத்துக்கள் எல்லாம் 'அ' என்ற எழுத்தை முதலாகக் கொண்டுள்ளன; அதுபோலவே உலகில் உள்ள அனைத்தும் ஆதிபகவன் (கடவுள்) என்பவரை முதலாகக் கொண்டுள்ளன என்பது இக்குறளின் பொருள்.

18. தமிழில் 'யாப்பு' என்பது என்ன?

  1. கவிதை எழுதும் முறை / கவிதை இலக்கணம்
  2. உரைநடை எழுதும் முறை
  3. சங்கீத இசை வகை
  4. நாடக வகை

Answer: கவிதை எழுதும் முறை / கவிதை இலக்கணம்

Explanation: யாப்பு — கவிதை இலக்கணம். அசை (syllable unit), சீர் (foot), அடி (line), தொடை (rhyme) ஆகியவற்றை கொண்டது. முக்கிய யாப்பு வகைகள்: வெண்பா, ஆசிரியப்பா, கலிப்பா, வஞ்சிப்பா.

19. 'சந்தி' என்பது தமிழ் இலக்கணத்தில் என்ன?

  1. வழிப்பிரிவு
  2. இரண்டு சொற்கள் அல்லது சொல்லின் பகுதிகள் சேரும்போது ஏற்படும் ஒலி மாற்றம்
  3. ஒரு பாடல் வகை
  4. கவிதை இணைப்பு

Answer: இரண்டு சொற்கள் அல்லது சொல்லின் பகுதிகள் சேரும்போது ஏற்படும் ஒலி மாற்றம்

Explanation: சந்தி (புணர்ச்சி) — இரண்டு சொற்கள் சேரும்போது ஒலி மாற்றம் ஏற்படுகிறது. உதாரணம்: மணி + அரங்கம் = மணியரங்கம் (இடையில் 'ய்' வருகிறது). இது தமிழ் இலக்கணத்தின் முக்கிய அங்கம்.

20. தமிழ் எழுத்துகளின் வகைப்பாட்டில் 'உயிரெழுத்து' என்பது எத்தனை?

  1. 12
  2. 18
  3. 1
  4. 23

Answer: 12

Explanation: தமிழில் 12 உயிரெழுத்துகள் (அ, ஆ, இ, ஈ, முதலியன) உள்ளன.

21. 'இயற்கைப் புணர்ச்சி' என்ற வகையில் பின்வரும் எந்தச் சொல் அமைந்துள்ளது?

  1. கல்+மா=கல்மா
  2. நல்+தீ=நற்றீ
  3. மரம்+வேர்=மரவேர்
  4. பல்+கொல்=பற்கொல்

Answer: நல்+தீ=நற்றீ

Explanation: 'நல்+தீ' இயற்கைப் புணர்ச்சியில் 'ல்' வருமொழி 'த'வுடன் சேர்ந்து 'ற்று' ஆகும்.

22. தொல்காப்பியத்தில் 'எழுத்ததிகாரம்' எத்தனை இயல்களைக் கொண்டது?

  1. 9
  2. 7
  3. 10
  4. 8

Answer: 9

Explanation: எழுத்ததிகாரத்தில் ஒன்பது இயல்கள் (நூன்மரபு முதல் எழுத்திலக்கணம் வரை) உள்ளன.

23. திருக்குறளில் 'அடக்கம் உடைமை' என்னும் குறளின் பொருள்:

  1. அடக்கமே சிறந்த அணி
  2. அடக்கம் அற்றவர் தாழ்வர்
  3. அடக்கமுடையார் மேன்மை பெறுவர்
  4. அடக்கம் இன்பம் தரும்

Answer: அடக்கமே சிறந்த அணி

Explanation: 'அடக்கம் அமரருள் உய்க்கும்' என்பதற்கு 'அடக்கமே சிறந்த அணி' என்பது பொருள்.

24. சங்க இலக்கியத்தில் 'ஐங்குறுநூறு' எத்தனை பாடல்களைக் கொண்டது?

  1. 500
  2. 400
  3. 300
  4. 250

Answer: 500

Explanation: ஐங்குறுநூறு என்பது 500 பாடல்கள் அடங்கிய நூல் (ஐந்து பிரிவுகள், ஒவ்வொன்றும் 100 பாடல்கள்).

25. 'வேற்றுமைத் தொகை' என்ற இலக்கணக் கூறு பின்வரும் எந்த எடுத்துக்காட்டில் உள்ளது?

  1. கோயில்
  2. மலைவாழ்
  3. வீட்டினைக் கண்டேன்
  4. புலியின் வருகை

Answer: புலியின் வருகை

Explanation: 'புலியின் வருகை' - இது 'புலி+இன்+வருகை' என ஆறாம் வேற்றுமைத் தொகையாகும்.
