TNPSC Tamil practice

Post Sangam MCQs with answers

Use these 5 worked Post Sangam questions to revise the TNPSC Tamil syllabus. Each answer includes an explanation; the full practice set contains 60 questions.

1. நாலடியார் என்ற நூல் எந்த மதத்தை சேர்ந்தவர்களால் இயற்றப்பட்டது?

  1. சைவர்கள்
  2. வைணவர்கள்
  3. சமணர்கள்
  4. பௌத்தர்கள்

Answer: சமணர்கள்

Explanation: நாலடியார் 400 நீதி வெண்பாக்களை கொண்டது. இவை 400 சமண முனிவர்களால் இயற்றப்பட்டதாக கூறப்படுகிறது. நாலடி = நான்கு அடி கொண்ட வெண்பா.

2. திருவாசகம் யாரால் பாடப்பட்டது?

  1. அப்பர்
  2. திருஞானசம்பந்தர்
  3. மாணிக்கவாசகர்
  4. சுந்தரர்

Answer: மாணிக்கவாசகர்

Explanation: திருவாசகம் — மாணிக்கவாசகர் பாடிய சிவபக்திப் பாடல்கள். 'திருவாசகத்திற்கு உருகார் ஒரு வாசகத்திற்கும் உருகார்' என்ற பழமொழி புகழ் பெற்றது. எட்டாம் திருமுறை.

3. 'ஊர் ஒற்றுமை வேண்டும், வீட்டில் புத்தி வேண்டும்' — இதன் கருத்து என்ன?

  1. ஊரில் ஒருமித்த செயல்பாடும், வீட்டில் சிந்தனையும் வேண்டும்
  2. ஊரில் சண்டை வேண்டும்
  3. வீட்டில் புத்தி வேண்டாம்
  4. ஒற்றுமை இல்லாமல் வாழலாம்

Answer: ஊரில் ஒருமித்த செயல்பாடும், வீட்டில் சிந்தனையும் வேண்டும்

Explanation: 'ஊர் ஒற்றுமை வேண்டும், வீட்டில் புத்தி வேண்டும்' — சமூகத்தில் ஒற்றுமையும், குடும்பத்தில் ஞானமும் / விவேகமும் வேண்டும் என்று கூறும் பழமொழி.

4. தமிழில் 'நாலடியார்' யாரால் இயற்றப்பட்டது?

  1. ஒரே ஒரு புலவர்
  2. நானூறு (400) சமண முனிவர்களால் இயற்றப்பட்டு, பதுமனார் தொகுத்தது
  3. திருவள்ளுவர்
  4. அவ்வையார்

Answer: நானூறு (400) சமண முனிவர்களால் இயற்றப்பட்டு, பதுமனார் தொகுத்தது

Explanation: நாலடியார் — 400 நான்கடி வெண்பாக்கள் கொண்ட தொகுப்பு. நானூறு சமண முனிவர்களால் இயற்றப்பட்டு, பதுமனார் என்பவர் தொகுத்தார். பதினெண் கீழ்க்கணக்கு நூல்களில் ஒன்று. நீதி கவிதைகள் கொண்டது.

5. பதிற்றுப்பத்து நூல் எந்த இலக்கியப் பகுப்பில் சேர்க்கப்பட்டுள்ளது?

  1. பத்துப்பாட்டு
  2. எட்டுத்தொகை
  3. பதினெண் மேற்கணக்கு
  4. பதினெண் கீழ்க்கணக்கு

Answer: பதினெண் மேற்கணக்கு

Explanation: பதிற்றுப்பத்து பதினெண் மேற்கணக்கு நூல்களில் ஒன்றாகும். இது புறப்பொருள் பற்றிய தொகுப்பு நூல்.
