Class6 MCQs with answers

Use these 25 worked Class6 questions to revise the NCERT Social Science syllabus. Each answer includes an explanation; the full practice set contains 242 questions.

26. What is the main characteristic of the secondary sector?

  1. Extraction of minerals
  2. Provision of services
  3. Processing of raw materials
  4. Agricultural production

Answer: Processing of raw materials

Explanation: The secondary sector focuses on manufacturing and processing raw materials into finished products.

27. Which of these is NOT a primary activity?

  1. Agriculture
  2. Mining
  3. Pottery
  4. Fishing

Answer: Pottery

Explanation: Pottery involves transforming clay into a product, which is a manufacturing (secondary) activity.

28. Which sector supports the primary and secondary sectors by providing necessary services?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. None of the above

Answer: Tertiary Sector

Explanation: The tertiary sector provides essential services like banking, transport, and communication to other sectors.

29. A person working as a software engineer belongs to which sector?

  1. Primary
  2. Secondary
  3. Tertiary
  4. Agricultural

Answer: Tertiary

Explanation: Software engineering is a specialized service, placing it in the tertiary sector.

30. Which of the following is an example of an industrial activity?

  1. Mining
  2. Textile milling
  3. Banking
  4. Fishing

Answer: Textile milling

Explanation: Textile milling is a manufacturing process, which is a key industrial/secondary activity.

31. Which of these is a characteristic of economic activities?

  1. Done for emotional satisfaction
  2. Done for monetary gain
  3. Done for social service
  4. Done without any objective

Answer: Done for monetary gain

Explanation: Economic activities are performed to earn money or a livelihood.

32. Which sector is most dominant in rural areas of India?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Information Technology Sector

Answer: Primary Sector

Explanation: Agriculture, a primary activity, is the main source of livelihood in rural India.

33. Which of the following is a service-based activity?

  1. Mining coal
  2. Making bread
  3. Banking
  4. Growing rice

Answer: Banking

Explanation: Banking is a service provided to customers, making it a tertiary activity.

34. Teaching is an example of a secondary sector activity.

  1. True
  2. False

Answer: False

Explanation: Teaching is a service, therefore it belongs to the tertiary sector.

35. Mining is considered a primary activity because it extracts natural resources.

  1. True
  2. False

Answer: True

Explanation: Extraction of minerals from the earth is the definition of a primary activity.

36. Which sector involves the extraction and production of raw materials from nature?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Quaternary Sector

Answer: Primary Sector

Explanation: The primary sector includes activities like agriculture, mining, and fishing that directly use natural resources.

37. Manufacturing of steel from iron ore is an activity of which sector?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Public Sector

Answer: Secondary Sector

Explanation: The secondary sector processes raw materials into finished goods through manufacturing.

38. Which of the following is an example of a Tertiary Sector activity?

  1. Dairy Farming
  2. Textile Weaving
  3. Banking
  4. Coal Mining

Answer: Banking

Explanation: Banking provides a service rather than producing a physical good, placing it in the tertiary sector.

39. Which of these activities is part of the Primary Sector?

  1. Teaching
  2. Fishing
  3. Car Assembly
  4. Transport

Answer: Fishing

Explanation: Fishing involves extracting a natural resource from the environment.

40. What happens when raw materials are converted into finished products?

  1. Primary production
  2. Secondary production
  3. Tertiary production
  4. Service production

Answer: Secondary production

Explanation: The process of transforming raw materials into finished goods is the core of the secondary sector.

41. Which sector provides support to both the primary and secondary sectors?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Mining Sector

Answer: Tertiary Sector

Explanation: The tertiary sector provides essential services like transport and communication that help other sectors function.

42. Which of the following is NOT a primary sector activity?

  1. Agriculture
  2. Forestry
  3. Bakery
  4. Mining

Answer: Bakery

Explanation: A bakery processes flour into bread, making it a secondary sector activity.

43. Which sector is most dominant in rural areas of developing countries?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Information Sector

Answer: Primary Sector

Explanation: Agriculture and allied activities (primary sector) are the main sources of employment in rural areas.

44. The process of converting sugarcane into sugar is an example of which sector?

  1. Primary
  2. Secondary
  3. Tertiary
  4. None of the above

Answer: Secondary

Explanation: Processing a raw crop into a refined product is a manufacturing activity.

45. Which of these is a service provided by the tertiary sector?

  1. Wheat farming
  2. Pottery making
  3. Healthcare
  4. Logging

Answer: Healthcare

Explanation: Healthcare is a professional service provided to people.

46. Which sector is characterized by the use of factories and machinery?

  1. Primary Sector
  2. Secondary Sector
  3. Tertiary Sector
  4. Natural Sector

Answer: Secondary Sector

Explanation: The secondary sector relies on industrial processes and machinery to manufacture goods.

47. Transportation of goods from a farm to a market is an activity of the ____ sector.

  1. Primary
  2. Secondary
  3. Tertiary
  4. Agricultural

Answer: Tertiary

Explanation: Transport is a service that facilitates the movement of goods.

48. Mining of minerals from the earth is classified as a ____ activity.

  1. Primary
  2. Secondary
  3. Tertiary
  4. Industrial

Answer: Primary

Explanation: Mining extracts natural resources directly from the earth.

49. The secondary sector is also known as the industrial sector.

  1. True
  2. False

Answer: True

Explanation: The secondary sector is called the industrial sector because it involves manufacturing and industry.

50. Banking and Insurance are examples of the Primary Sector.

  1. True
  2. False

Answer: False

Explanation: Banking and Insurance are services and therefore belong to the tertiary sector.
