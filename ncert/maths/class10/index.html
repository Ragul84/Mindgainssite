1. The HCF of two numbers is 27 and their LCM is 162. If one of the numbers is 54, what is the other number?

  1. 81
  2. 36
  3. 27
  4. 18

Answer: 81

Explanation: We know that for any two positive integers 'a' and 'b', HCF(a, b) × LCM(a, b) = a × b. Given HCF = 27, LCM = 162, and one number (a) = 54. Let the other number be 'b'. So, 27 × 162 = 54 × b b = (27 × 162) / 54 b = (27 × 162) / (2 × 27) b = 162 / 2 b = 81. Thus, the other number is 81.

2. If α and β are the zeroes of the quadratic polynomial p(x) = x² - 5x + k such that α - β = 1, then the value of k is:

  1. 4
  2. 6
  3. 2
  4. 3

Answer: 6

Explanation: For the quadratic polynomial p(x) = x² - 5x + k, we have a=1, b=-5, c=k. Sum of zeroes: α + β = -b/a = -(-5)/1 = 5 (Equation 1) Product of zeroes: αβ = c/a = k/1 = k (Equation 2) We are given α - β = 1 (Equation 3) Adding Equation 1 and Equation 3: (α + β) + (α - β) = 5 + 1 2α = 6 α = 3 Substitute α = 3 into Equation 1: 3 + β = 5 β = 5 - 3 β = 2 Now, substitute the values of α and β into Equation 2: k = αβ = 3 × 2 = 6. Therefore, the value of k is 6.

3. For what value of 'k' will the following pair of linear equations have infinitely many solutions? kx + 3y = k - 3 12x + ky = k

  1. 6
  2. -6
  3. 0
  4. 3

Answer: 6

Explanation: For a pair of linear equations a₁x + b₁y + c₁ = 0 and a₂x + b₂y + c₂ = 0 to have infinitely many solutions, the condition is a₁/a₂ = b₁/b₂ = c₁/c₂. Given equations: 1) kx + 3y - (k - 3) = 0 => a₁ = k, b₁ = 3, c₁ = -(k - 3) 2) 12x + ky - k = 0 => a₂ = 12, b₂ = k, c₂ = -k Applying the condition: k/12 = 3/k = -(k - 3)/(-k) First, consider k/12 = 3/k: k² = 36 k = ±6 Next, consider 3/k = -(k - 3)/(-k): 3/k = (k - 3)/k Since k cannot be 0 (as it would make the denominators zero), we can multiply both sides by k: 3 = k - 3 k = 6 Both conditions must be satisfied. The common value for k is 6. Let's check with k = -6: -6/12 = -1/2 3/-6 = -1/2 -(-6-3)/(-6) = -(-9)/(-6) = 9/-6 = -3/2 Here, -1/2 = -1/2 ≠ -3/2, so k = -6 does not give infinitely many solutions. Let's check with k = 6: 6/12 = 1/2 3/6 = 1/2 -(6-3)/(-6) = -3/-6 = 1/2 Since 1/2 = 1/2 = 1/2, k = 6 gives infinitely many solutions.

4. If the roots of the quadratic equation 2x² + kx + 3 = 0 are real and equal, then the value of k is:

  1. ±√6
  2. ±2√6
  3. ±3√2
  4. ±4√3

Answer: ±2√6

Explanation: For a quadratic equation ax² + bx + c = 0, the roots are real and equal if the discriminant (D) is equal to zero, i.e., D = b² - 4ac = 0. Given equation: 2x² + kx + 3 = 0 Here, a = 2, b = k, c = 3. Substitute these values into the discriminant formula: k² - 4(2)(3) = 0 k² - 24 = 0 k² = 24 k = ±√24 k = ±√(4 × 6) k = ±2√6. Therefore, the value of k is ±2√6.

5. The 17th term of an AP exceeds its 10th term by 7. The common difference is:

  1. 1
  2. 2
  3. 3
  4. 4

Answer: 1

Explanation: Let the first term of the AP be 'a' and the common difference be 'd'. The nth term of an AP is given by the formula a_n = a + (n-1)d. According to the problem, the 17th term exceeds its 10th term by 7. So, a₁₇ = a₁₀ + 7 Using the formula: a + (17-1)d = a + (10-1)d + 7 a + 16d = a + 9d + 7 Subtract 'a' from both sides: 16d = 9d + 7 16d - 9d = 7 7d = 7 d = 7/7 d = 1. Thus, the common difference is 1.
