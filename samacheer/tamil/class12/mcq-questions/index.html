26. பருவ மோற்்றத்திற்கோன கோரணங்களை அறிந்து சுற்றுச்சூழளைப் போதுகோக்கும் விழிப்புணர்வு பருத்தல் என்பது என்ன?

  1. இயற்கை
  2. மனிதன்
  3. சுற்றுச்சூழல்
  4. பருவம்

Answer: சுற்றுச்சூழல்

Explanation: சுற்றுச்சூழலைப் போதுகோக்கும் விழிப்புணர்வு.

27. மனிதர்கள் இயற்கை நிகழ்வினோல் உள்பட உணர்ந்து இயற்கைகளை விரும்புவது என்ன?

  1. பருவம்
  2. உள்ளமை
  3. உள்ளமைப்புகள்
  4. உள்ளம்

Answer: உள்ளம்

Explanation: மனிதர்கள் இயற்கையை விரும்புவது.

28. பழந்தமிழர் திளண வோழ்ளவச் சங்கப்புைவர்கள் கவிளதயோக்கிய உணர்தல் என்பது என்ன?

  1. நிலம்
  2. பழம்
  3. பருவம்
  4. சங்கம்

Answer: சங்கம்

Explanation: பழந்தமிழர் சங்கம்.

29. நீர்வழிப் போளதகளைப் பரோமரிப்பதன் நோதளவளய உணர்ந்துபகோள்ளும் தி்றன் என்பது என்ன?

  1. பருவம்
  2. மழை
  3. நீர்
  4. பொதுவாக

Answer: நீர்

Explanation: நீர்வழி போளதகளைப் பரோமரிக்கிறது.

30. திளண, போல், எண், இடம் ஆகியவற்றின் இைக்கணமறிந்து பயன்படுத்தும் தி்றன் என்பது என்ன?

  1. மொழி
  2. அறிவு
  3. கலை
  4. அறிக்கைகள்

Answer: மொழி

Explanation: இயற்கை மற்றும் மொழி தொடர்பானது.

31. பெருமழைக் ககாலம் என்பது எந்த பருவத்தை குறிக்கிறது?

  1. கோடை
  2. மழை
  3. சரத்காலம்
  4. குளிர்காலம்

Answer: மழை

Explanation: பெருமழைக் காலம் மழை பருவம்.

32. பெருமழைக் காலத்தில் மனிதர்கள் என்ன செய்கின்றனர்?

Explanation: சுற்றுச்சூழலை பாதுகாப்பது முக்கியம்.

37. தமிழர் குடும்ப முறை பற்றி எழுதியவர் யார்?

  1. பகதவத்சல பாரதி
  2. ஜலாலுததீன் ரூமி

  4. பூமணி
