26. பழமொழியின் சிறப்பு என்ன?

  1. நீண்ட வாக்கியங்களைக் கொண்டிருத்தல்
  2. குறைந்த சொற்களில் ஆழமான பொருளை உணர்த்துதல்
  3. இலக்கண விதிகளை மீறுதல்
  4. புதிய கருத்துக்களை மட்டும் கூறுதல்

Answer: குறைந்த சொற்களில் ஆழமான பொருளை உணர்த்துதல்

Explanation: பழமொழியின் சிறப்பு, குறைந்த சொற்களில் ஆழமான பொருளை உணர்த்துவதாகும். இது 'சொலவடைகள்' என்ற பாடப்பகுதியில் பழமொழிகளின் தன்மை பற்றி விளக்கப்பட்டுள்ளது.

27. தமிழர்களின் கப்பல் கட்டும் கலையில், கப்பலின் அடிப்பாகத்திற்குப் பயன்படுத்தப்பட்ட மரம் எது?

  1. தேக்கு
  2. இலுப்பை
  3. நாவல்
  4. வேம்பு

Answer: நாவல்

Explanation: தமிழர்களின் கப்பல் கட்டும் கலையில், கப்பலின் அடிப்பாகத்திற்கு நாவல் மரம் பயன்படுத்தப்பட்டது. இது 'தமிழரின் கப்பற்கலை' என்ற பாடப்பகுதியில் குறிப்பிடப்பட்டுள்ளது.

28. தமிழின் இனிமையைப் பற்றிப் பேசும் 'எங்கள் தமிழ்' பாடலின் ஆசிரியர் யார்?

  1. நாமக்கல் கவிஞர் வெ. இராமலிங்கனார்
  2. பாரதியார்
  3. பாரதிதாசன்
  4. கண்ணதாசன்

Answer: நாமக்கல் கவிஞர் வெ. இராமலிங்கனார்

Explanation: 'எங்கள் தமிழ்' என்ற பாடலை இயற்றியவர் நாமக்கல் கவிஞர் வெ. இராமலிங்கனார் ஆவார். இவர் காந்தியக் கவிஞர் என்றும் அழைக்கப்படுகிறார்.

29. தமிழர்களின் வீரத்தைப் போற்றும் 'ஒன்றல்ல இரண்டல்ல' பாடலில் குறிப்பிடப்படும் வள்ளல்கள் யார்?

  1. கம்பர், ஒளவையார்
  2. கடையேழு வள்ளல்கள்
  3. சேர, சோழ, பாண்டிய மன்னர்கள்
  4. கபிலர், பரணர்

Answer: கடையேழு வள்ளல்கள்

Explanation: 'ஒன்றல்ல இரண்டல்ல' பாடலில் தமிழர்களின் கொடைத்திறத்தைப் போற்றும் விதமாக கடையேழு வள்ளல்களின் பெருமைகள் குறிப்பிடப்பட்டுள்ளன. அவர்கள் பேகன், பாரி, காரி, ஆய், அதியமான், நள்ளி, ஓரி ஆவர்.

30. கப்பல் கட்டுவதற்குப் பயன்படும் மரங்களில் இல்லாதது எது?

  1. தேக்கு
  2. பலா
  3. இலுப்பை
  4. வேம்பு

Answer: வேம்பு

Explanation: கப்பல் கட்டுவதற்குத் தேக்கு, பலா, இலுப்பை போன்ற மரங்கள் பயன்படுத்தப்பட்டன. ஆனால் வேம்பு மரம் கப்பல் கட்டுவதற்குப் பயன்படுத்தப்பட்டதாகக் குறிப்புகள் இல்லை. வேம்பு மரம் பொதுவாக மருத்துவ குணங்களுக்காகப் பயன்படுத்தப்படுகிறது.

31. தமிழ்மொழி போல் இனிதாவது எங்கும் காணோம் என்று பாடியவர் யார்?

  1. பாரதியார்
  2. பாரதிதாசன்
  3. கவிமணி
  4. நாமக்கல் கவிஞர்

Answer: பாரதியார்

Explanation: இக்கேள்வி 'எங்கள் தமிழ்' என்ற பாடப்பகுதியிலிருந்து கேட்கப்பட்டுள்ளது. தமிழ்மொழி போல் இனிதாவது எங்கும் காணோம் என்று பாடியவர் மகாகவி பாரதியார் ஆவார். இது தமிழ் மொழியின் சிறப்பைப் போற்றும் ஒரு புகழ்பெற்ற கூற்று.

32. குற்றாலக் குறவஞ்சியின் ஆசிரியர் யார்?

  1. கம்பர்
  2. திருகூடராசப்பக் கவிராயர்
  3. ஒட்டக்கூத்தர்
  4. புகழேந்திப் புலவர்

Answer: திருகூடராசப்பக் கவிராயர்

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்ற பாடப்பகுதியில், தமிழ்நாட்டின் சிறப்புகளையும், இலக்கிய வளங்களையும் குறிப்பிடும்போது குற்றாலக் குறவஞ்சி பற்றிய குறிப்பு வருகிறது. குற்றாலக் குறவஞ்சியை இயற்றியவர் திருகூடராசப்பக் கவிராயர் ஆவார்.

33. தமிழின் இனிமையை 'எங்கள் தமிழ்' பாடலில் எவ்வாறு கவிஞர் நாமக்கள் கவிஞர் வெ. இராமலிங்கனார் குறிப்பிடுகிறார்?

  1. அன்பு வழியானது
  2. அறம் பல கொண்டது
  3. அருள் நெறி கொண்டது
  4. இனிய ஓசையுடையது

Answer: அன்பு வழியானது

Explanation: 'எங்கள் தமிழ்' பாடலில், நாமக்கள் கவிஞர் வெ. இராமலிங்கனார், தமிழ் மொழியின் இனிமையை 'அன்பு வழியானது' என்று குறிப்பிடுகிறார். தமிழ் மொழி அன்பு வழியில் வாழ்வதற்கு வழிகாட்டும் என்பதை இப்பாடல் உணர்த்துகிறது.

34. கீழ்க்கண்டவற்றுள் குற்றியலுகரத்திற்கு எடுத்துக்காட்டு எது?

  1. நாகு
  2. வரகு
  3. பந்து
  4. ஆறு

Answer: பந்து

Explanation: குற்றியலுகரம் என்பது, வல்லின மெய்களின் மேல் ஏறி வரும் உகரம், தனக்குரிய ஒரு மாத்திரை அளவிலிருந்து அரை மாத்திரையாகக் குறைந்து ஒலிப்பது. 'பந்து' என்ற சொல்லில், 'து' (த் + உ) என்ற எழுத்து, வல்லின மெய்யான 'த்' உடன் இணைந்து வந்து, தனக்குரிய ஒரு மாத்திரை அளவிலிருந்து குறைந்து ஒலிப்பதால் இது குற்றியலுகரத்திற்கு எடுத்துக்காட்டாகும். மற்றவை முற்றியலுகரங்கள்.

35. கப்பல் கட்டுவதற்குப் பயன்படும் மரங்களில் மிகவும் வலிமையானது எது?

  1. தேக்கு
  2. பலா
  3. நாவல்
  4. இலுப்பை

Answer: தேக்கு

Explanation: 'தமிழரின் கப்பற்கலை' என்ற பாடப்பகுதியில், கப்பல் கட்டுவதற்குப் பயன்படும் மரங்களில் தேக்கு மரம் மிகவும் வலிமையானது என்றும், அது நீண்ட காலம் உழைக்கும் தன்மை கொண்டது என்றும் குறிப்பிடப்பட்டுள்ளது. தேக்கு மரத்தின் உறுதித்தன்மை கப்பல் கட்டுமானத்திற்கு மிகவும் உகந்தது.
