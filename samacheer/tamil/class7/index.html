1. தமிழின் இனிமையைப் பற்றிக் கூறும் நூல் எது?

  1. எங்கள் தமிழ்
  2. ஒன்றல்ல இரண்டல்ல
  3. பேச்சுமொழியும் எழுத்துமொழியும்
  4. கவின்மிகு கப்பல்

Answer: எங்கள் தமிழ்

Explanation: 'எங்கள் தமிழ்' என்னும் கவிதை, தமிழ் மொழியின் இனிமையையும், அதன் சிறப்புகளையும், அது தரும் இன்பத்தையும் எடுத்துரைக்கிறது. இது நாமக்கல் கவிஞர் வெ. இராமலிங்கனார் எழுதியது.

2. தமிழ்நாட்டின் இயற்கை வளங்களையும், கலைச் சிறப்புகளையும் போற்றிப் பாடும் நூல் எது?

  1. எங்கள் தமிழ்
  2. ஒன்றல்ல இரண்டல்ல
  3. சொல்வடை
  4. கலம் காரி விளக்கம்

Answer: ஒன்றல்ல இரண்டல்ல

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்னும் பாடல், தமிழ்நாட்டின் இயற்கை வளங்கள், கலைச் சிறப்புகள், கொடைத்தன்மை போன்றவற்றை ஒன்றல்ல இரண்டல்ல பல என்று வியந்து போற்றுகிறது. இது உடுமலை நாராயணகவி எழுதியது.

3. பேச்சுமொழிக்கும் எழுத்துமொழிக்கும் இடையே உள்ள வேறுபாடுகளை விளக்கும் பாடம் எது?

  1. சொல்வடைகள்
  2. பேச்சுமொழியும் எழுத்துமொழியும்
  3. குற்றியலுகரம், குற்றியலிகரம்
  4. இலக்கிய வகைச் சொற்கள்

Answer: பேச்சுமொழியும் எழுத்துமொழியும்

Explanation: 'பேச்சுமொழியும் எழுத்துமொழியும்' என்ற பாடம், அன்றாட வாழ்வில் நாம் பயன்படுத்தும் பேச்சுமொழிக்கும், நூல்களில் பயன்படுத்தப்படும் எழுத்துமொழிக்கும் இடையே உள்ள வேறுபாடுகளையும், அவற்றின் சிறப்புகளையும் தெளிவாக விளக்குகிறது.

4. பழமொழிகள் என்பவை எவை?

  1. இலக்கண விதிகள்
  2. நீதி நூல்கள்
  3. முன்னோர்களின் அனுபவ மொழிகள்
  4. கவிதை வரிகள்

Answer: முன்னோர்களின் அனுபவ மொழிகள்

Explanation: 'சொல்வடைகள்' என்ற தலைப்பில் வரும் பழமொழிகள், நம் முன்னோர்கள் தங்கள் அனுபவத்தின் மூலம் கண்டறிந்த உண்மைகளைச் சுருக்கமாகவும், ஆழமாகவும் வெளிப்படுத்தும் மொழிகளாகும். இவை வாழ்க்கைக்கு வழிகாட்டும் கருத்துக்களைக் கொண்டிருக்கும்.

5. குற்றியலுகரம் எத்தனை வகைப்படும்?

  1. இரண்டு
  2. நான்கு
  3. ஆறு
  4. எட்டு

Answer: ஆறு

Explanation: குற்றியலுகரம் ஆறு வகைப்படும். அவை: நெடில்தொடர்க் குற்றியலுகரம், ஆய்தத்தொடர்க் குற்றியலுகரம், உயிர்த்தொடர்க் குற்றியலுகரம், வன்தொடர்க் குற்றியலுகரம், மென்தொடர்க் குற்றியலுகரம், இடைத்தொடர்க் குற்றியலுகரம்.

6. கலம் காரி ஓவியங்கள் எந்த மாநிலத்தில் தோன்றின?

  1. தமிழ்நாடு
  2. கேரளா
  3. ஆந்திரப் பிரதேசம்
  4. கர்நாடகா

Answer: ஆந்திரப் பிரதேசம்

Explanation: 'கலம் காரி விளக்கம்' என்ற பாடம், கலம் காரி ஓவியக்கலையைப் பற்றி விளக்குகிறது. கலம் காரி ஓவியங்கள் ஆந்திரப் பிரதேசத்தில் தோன்றிய பாரம்பரிய ஓவியக்கலையாகும். 'கலம்' என்றால் தூரிகை, 'காரி' என்றால் வேலைப்பாடு என்று பொருள்.

7. தமிழர்கள் கப்பல் கட்டும் கலையில் சிறந்து விளங்கினர் என்பதை உணர்த்தும் பாடம் எது?

  1. எங்கள் தமிழ்
  2. கவின்மிகு கப்பல்
  3. தமிழரின் கப்பற்கலை
  4. இலக்கிய வகைச் சொற்கள்

Answer: தமிழரின் கப்பற்கலை

Explanation: 'தமிழரின் கப்பற்கலை' என்ற பாடம், பண்டைக்காலம் தொட்டே தமிழர்கள் கப்பல் கட்டும் கலையில் சிறந்து விளங்கியதையும், கடற்பயணங்களில் ஈடுபட்டதையும், அதற்கான ஆதாரங்களையும் விரிவாக விளக்குகிறது.

8. இலக்கிய வகைச் சொற்கள் எத்தனை வகைப்படும்?

  1. இரண்டு
  2. மூன்று
  3. நான்கு
  4. ஐந்து

Answer: நான்கு

Explanation: 'இலக்கிய வகைச் சொற்கள்' என்ற இலக்கணப் பாடம், இலக்கியங்களில் பயன்படுத்தப்படும் சொற்களை நான்கு வகைகளாகப் பிரிக்கிறது. அவை: இயற்சொல், திரிசொல், திசைச்சொல், வடசொல்.

9. தமிழர்களின் கப்பற்கலையை உலகறியச் செய்தவர் யார்?

  1. மார்க்கோ போலோ
  2. வாஸ்கோ ட காமா
  3. கொலம்பஸ்
  4. மெகஸ்தனிஸ்

Answer: மார்க்கோ போலோ

Explanation: தமிழர்களின் கப்பற்கலையின் சிறப்பை உலகறியச் செய்தவர் இத்தாலியப் பயணி மார்க்கோ போலோ ஆவார். அவர் தனது பயணக் குறிப்புகளில் தமிழர்களின் கப்பல்களைப் பற்றிப் பெருமையாகக் குறிப்பிட்டுள்ளார்.

10. பேச்சுமொழிக்கும் எழுத்துமொழிக்கும் இடையே உள்ள வேறுபாட்டைக் குறிக்கும் சொல் எது?

  1. வழக்கு
  2. வழக்குத்தமிழ்
  3. இரட்டை வழக்கு
  4. வழக்குச் சொல்

Answer: இரட்டை வழக்கு

Explanation: பேச்சுமொழிக்கும் எழுத்துமொழிக்கும் இடையே உள்ள வேறுபாட்டை 'இரட்டை வழக்கு' என்று கூறுவர். பேச்சுமொழி ஒருவகை வழக்கு, எழுத்துமொழி மற்றொருவகை வழக்கு.

11. 'அகழ்வாரைத் தாங்கும் நிலம்போலத் தம்மை இகழ்வார்ப் பொறுத்தல் தலை' - இக்குறள் உணர்த்தும் கருத்து யாது?

  1. பொறுமை
  2. அன்பு
  3. வீரம்
  4. கல்வி

Answer: பொறுமை

Explanation: இக்குறள், தன்னைத் தோண்டுபவர்களையும் தாங்கும் நிலத்தைப் போல, தன்னை இகழ்பவர்களையும் பொறுத்துக் கொள்வது சிறந்த பண்பு என்று பொறுமையின் சிறப்பை உணர்த்துகிறது.

12. கலம்காரி ஓவியங்கள் எந்த மாநிலத்தைச் சேர்ந்தவை?

  1. தமிழ்நாடு
  2. கேரளா
  3. ஆந்திரப் பிரதேசம்
  4. கர்நாடகா

Answer: ஆந்திரப் பிரதேசம்

Explanation: கலம்காரி ஓவியங்கள் ஆந்திரப் பிரதேச மாநிலத்தைச் சேர்ந்த பாரம்பரிய ஓவியக் கலையாகும். 'கலம்' என்றால் தூரிகை, 'காரி' என்றால் வேலைப்பாடு என்று பொருள்.

13. தமிழர்களின் கப்பற்கலையில் பயன்படுத்தப்பட்ட மரங்களில் இல்லாதது எது?

  1. தேக்கு
  2. பலா
  3. இலுப்பை
  4. வேம்பு

Answer: வேம்பு

Explanation: தமிழர்கள் கப்பல் கட்டப் பயன்படுத்திய மரங்களில் தேக்கு, பலா, இலுப்பை, சந்தனம் போன்ற மரங்கள் இருந்தன. வேம்பு பொதுவாகக் கப்பல் கட்டப் பயன்படுத்தப்படவில்லை.

14. இலக்கிய வகையால் சொற்கள் எத்தனை வகைப்படும்?

  1. இரண்டு
  2. மூன்று
  3. நான்கு
  4. ஐந்து

Answer: நான்கு

Explanation: இலக்கிய வகையால் சொற்கள் நான்கு வகைப்படும். அவை: இயற்சொல், திரிசொல், திசைச்சொல், வடசொல்.

15. 'ஒன்றல்ல இரண்டல்ல' பாடலில் குறிப்பிடப்படும் வள்ளல்கள் யார்?

  1. பாரி, ஓரி
  2. காரி, ஆய்
  3. அதியமான், நள்ளி
  4. மேற்கண்ட அனைவரும்

Answer: மேற்கண்ட அனைவரும்

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்ற பாடலில் பாரி, ஓரி, காரி, ஆய், அதியமான், நள்ளி, பேகன், நல்லியக்கோடன் போன்ற ஏழு வள்ளல்களின் கொடைத்திறன் குறிப்பிடப்பட்டுள்ளது.

16. தமிழின் இனிமையைப் பற்றிக் கூறும் 'எங்கள் தமிழ்' பாடலின் ஆசிரியர் யார்?

  1. நாமக்கல் கவிஞர் வெ. இராமலிங்கனார்
  2. பாரதியார்
  3. பாரதிதாசன்
  4. கண்ணதாசன்

Answer: நாமக்கல் கவிஞர் வெ. இராமலிங்கனார்

Explanation: 'எங்கள் தமிழ்' என்ற பாடலை இயற்றியவர் நாமக்கல் கவிஞர் வெ. இராமலிங்கனார் ஆவார். இவர் காந்தியக் கவிஞர் என்றும் அழைக்கப்படுகிறார்.

17. தமிழர்களின் வீரத்தையும் கொடைத்தன்மையையும் போற்றும் பாடல் எது?

  1. எங்கள் தமிழ்
  2. ஒன்றல்ல இரண்டல்ல
  3. கவின்மிகு கப்பல்
  4. தமிழரின் கப்பற்கலை

Answer: ஒன்றல்ல இரண்டல்ல

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்ற பாடல் தமிழர்களின் வீரத்தையும், கொடைத்தன்மையையும், கலைத்திறனையும் போற்றிப் பாடுகிறது. இப்பாடலை உடுமலை நாராயணகவி இயற்றினார்.

18. பேச்சுமொழிக்கும் எழுத்துமொழிக்கும் இடையே உள்ள வேறுபாடுகளைக் குறிக்கும் சரியான கூற்று எது?

  1. பேச்சுமொழி எழுத்துமொழியை விட எளிமையானது.
  2. எழுத்துமொழி பேச்சுமொழியை விட விரைவானது.
  3. பேச்சுமொழி வட்டார வழக்குகள் கொண்டது, எழுத்துமொழி பொதுவானது.
  4. எழுத்துமொழி பேச்சுமொழியை விட உணர்ச்சிப்பூர்வமானது.

Answer: பேச்சுமொழி வட்டார வழக்குகள் கொண்டது, எழுத்துமொழி பொதுவானது.

Explanation: பேச்சுமொழி என்பது அன்றாட வாழ்வில் நாம் பயன்படுத்தும் மொழி. இது வட்டார வழக்குகள், உடல்மொழி, ஒலிப்பு வேறுபாடுகள் கொண்டது. எழுத்துமொழி என்பது நூல்கள், ஆவணங்கள் போன்றவற்றில் பயன்படுத்தப்படும் மொழி. இது பொதுவான இலக்கண விதிகளைக் கொண்டது மற்றும் வட்டார வழக்குகள் அற்றது.

19. 'காற்றுள்ளபோதே தூற்றிக்கொள்' என்ற பழமொழியின் பொருள் என்ன?

  1. காற்று வீசும் போது தானியங்களைத் தூற்ற வேண்டும்.
  2. வாய்ப்புக் கிடைக்கும்போதே அதைப் பயன்படுத்திக் கொள்ள வேண்டும்.
  3. காற்றின் முக்கியத்துவத்தை உணர்ந்து செயல்பட வேண்டும்.
  4. தூற்றுதல் என்பது ஒரு நல்ல செயல்.

Answer: வாய்ப்புக் கிடைக்கும்போதே அதைப் பயன்படுத்திக் கொள்ள வேண்டும்.

Explanation: 'காற்றுள்ளபோதே தூற்றிக்கொள்' என்ற பழமொழி, ஒரு வாய்ப்பு கிடைக்கும்போது அதைச் சரியாகப் பயன்படுத்திக் கொள்ள வேண்டும் என்பதைக் குறிக்கிறது. இது ஒரு செயலைச் செய்வதற்குச் சரியான நேரம் வரும்போது அதைச் செய்ய வேண்டும் என்ற கருத்தை வலியுறுத்துகிறது.

20. தமிழர்கள் கப்பல் கட்டப் பயன்படுத்திய மரங்களில் ஒன்று எது?

  1. தேக்கு
  2. மாமரம்
  3. பலாமரம்
  4. வேப்பமரம்

Answer: தேக்கு

Explanation: தமிழர்கள் கப்பல் கட்டப் பயன்படுத்திய மரங்களில் தேக்கு, வெண் தேக்கு, பலா, இலுப்பை, புன்னை, நாவல் போன்ற மரங்கள் முக்கியமானவை. இவை நீடித்து உழைக்கும் தன்மை கொண்டவை.

21. தமிழரின் வீரத்தைப் போற்றும் சங்க இலக்கிய நூல் எது?

  1. திருக்குறள்
  2. நாலடியார்
  3. புறநானூறு
  4. சிலப்பதிகாரம்

Answer: புறநானூறு

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்ற பாடலில், தமிழரின் வீரம், கொடைத்தன்மை, கலைத்திறன் ஆகியவை சங்க இலக்கியங்களில் போற்றப்படுவதாகக் கூறப்பட்டுள்ளது. குறிப்பாக, புறநானூறு தமிழரின் வீரத்தைப் பற்றிப் பல பாடல்களைக் கொண்டுள்ளது.

22. பேச்சுமொழிக்கும் எழுத்துமொழிக்கும் உள்ள வேறுபாடுகளில் தவறானது எது?

  1. பேச்சுமொழி உடனடிப் பயன்பாட்டிற்குரியது.
  2. எழுத்துமொழி காலம் கடந்து நிலைத்து நிற்கும்.
  3. பேச்சுமொழிக்கு இலக்கண விதிகள் அதிகம்.
  4. எழுத்துமொழி சிந்தித்து எழுதப்படுவதால் பிழைகள் குறைவு.

Answer: பேச்சுமொழிக்கு இலக்கண விதிகள் அதிகம்.

Explanation: பேச்சுமொழிக்கு இலக்கண விதிகள் அதிகம் இல்லை. அது உணர்ச்சி வெளிப்பாட்டிற்கு முக்கியத்துவம் கொடுக்கும். எழுத்துமொழிக்கு இலக்கண விதிகள் உண்டு, அது சிந்தித்து எழுதப்படுவதால் பிழைகள் குறைவாக இருக்கும்.

23. தமிழர்கள் கப்பல் கட்டப் பயன்படுத்திய மரங்களில் தவறானது எது?

  1. தேக்கு
  2. பலா
  3. இலுப்பை
  4. வேம்பு

Answer: வேம்பு

Explanation: தமிழர்கள் கப்பல் கட்டத் தேக்கு, பலா, இலுப்பை, புன்னை, நாவல் போன்ற மரங்களைப் பயன்படுத்தினர். வேம்பு மரத்தைப் பயன்படுத்தியதாகக் குறிப்புகள் இல்லை.

24. தமிழர்களின் கப்பல் கட்டும் கலையைப் பற்றி கூறும் நூல் எது?

  1. கப்பல் சாத்திரம்
  2. தொல்காப்பியம்
  3. நன்னூல்
  4. சிலப்பதிகாரம்

Answer: கப்பல் சாத்திரம்

Explanation: தமிழர்களின் கப்பல் கட்டும் கலையின் நுட்பங்களை விளக்கும் நூல் 'கப்பல் சாத்திரம்' ஆகும். இது 'தமிழரின் கப்பற்கலை' என்ற பாடப்பகுதியில் குறிப்பிடப்பட்டுள்ளது.

25. 'ஒன்றல்ல இரண்டல்ல' என்ற பாடலின் ஆசிரியர் யார்?

  1. உடுமலை நாராயணகவி
  2. கவிமணி தேசிக விநாயகம் பிள்ளை
  3. நாமக்கல் கவிஞர்
  4. சுரதா

Answer: உடுமலை நாராயணகவி

Explanation: 'ஒன்றல்ல இரண்டல்ல' என்ற பாடலின் ஆசிரியர் உடுமலை நாராயணகவி ஆவார். இது 'ஒன்றல்ல இரண்டல்ல' என்ற செய்யுள் பகுதியில் குறிப்பிடப்பட்டுள்ளது.
