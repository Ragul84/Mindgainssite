26. எழுத்துக்களின் பிறப்பு பற்றி விளக்கும் இலக்கணப் பகுதி எது?

  1. எழுத்ததிகாரம்
  2. சொல்லதிகாரம்
  3. பொருளதிகாரம்
  4. யாப்பருங்கலக்காரிகை

Answer: எழுத்ததிகாரம்

Explanation: எழுத்துக்களின் பிறப்பு பற்றி விளக்கும் இலக்கணப் பகுதி எழுத்ததிகாரம் ஆகும். தொல்காப்பியம், நன்னூல் போன்ற இலக்கண நூல்களில் எழுத்ததிகாரம் எழுத்துக்களின் பிறப்பியல் பற்றிக் கூறுகிறது.

27. 'ஓடை' என்னும் தலைப்பில் உள்ள பாடல் எந்த நூலிலிருந்து எடுக்கப்பட்டது?

  1. கவிதைப்பேழை
  2. கவிதைமலர்
  3. கவிதைத்தொகுப்பு
  4. கவிதைச்சரம்

Answer: கவிதைப்பேழை

Explanation: 'ஓடை' என்னும் தலைப்பில் உள்ள பாடல், வாணிதாசன் இயற்றிய 'கவிதைப்பேழை' என்னும் நூலிலிருந்து எடுக்கப்பட்டது. இது இயற்கையின் அழகை வர்ணிக்கும் ஒரு பாடல்.

28. வினைமுற்று எத்தனை வகைப்படும்?

  1. இரண்டு
  2. மூன்று
  3. நான்கு
  4. ஐந்து

Answer: இரண்டு

Explanation: வினைமுற்று இரண்டு வகைப்படும். அவை தெரிநிலை வினைமுற்று மற்றும் குறிப்பு வினைமுற்று ஆகும். ஒரு செயலைத் தெளிவாகக் காட்டும் வினை தெரிநிலை வினைமுற்று என்றும், பண்பு, தொழில், காலம் ஆகியவற்றைக் குறிப்பாக உணர்த்தும் வினை குறிப்பு வினைமுற்று என்றும் அழைக்கப்படும்.

29. 'சொற்பூங்கா' என்ற தலைப்பில் அமைந்துள்ள பாடப்பகுதி எதைப் பற்றி விளக்குகிறது?

  1. சொற்களின் தோற்றம் மற்றும் வளர்ச்சி
  2. பூங்காக்களின் வகைகள்
  3. கவிதைகளின் அமைப்பு
  4. இலக்கண விதிகள்

Answer: சொற்களின் தோற்றம் மற்றும் வளர்ச்சி

Explanation: 'சொற்பூங்கா' என்ற தலைப்பு, சொற்களின் தோற்றம், வளர்ச்சி, அவற்றின் பயன்பாடு மற்றும் தமிழ் மொழியில் சொற்களின் சிறப்பு ஆகியவற்றை விளக்குகிறது. (சமச்சீர் கல்வி 8 ஆம் வகுப்பு தமிழ், சொற்பூங்கா)

30. உயிரெழுத்துக்களின் பிறப்பு எங்கு நிகழ்கிறது?

  1. கழுத்து
  2. மார்பு
  3. தலை
  4. மூக்கு

Answer: கழுத்து

Explanation: உயிரெழுத்துக்கள் பன்னிரண்டும் கழுத்தை இடமாகக் கொண்டு பிறக்கின்றன. (சமச்சீர் கல்வி 8 ஆம் வகுப்பு தமிழ், எழுத்துக்களின் பிறப்பு)

31. 'ஓடை' என்ற பாடலில் ஓடையின் நீரை எவ்வாறு வர்ணிக்கப்பட்டுள்ளது?

  1. தெளிந்த நீர்
  2. கலங்கிய நீர்
  3. உப்பு நீர்
  4. சூடான நீர்

Answer: தெளிந்த நீர்

Explanation: 'ஓடை' என்ற பாடலில் ஓடையின் நீர் மிகவும் தெளிவானதாகவும், தூய்மையானதாகவும் வர்ணிக்கப்பட்டுள்ளது. (சமச்சீர் கல்வி 8 ஆம் வகுப்பு தமிழ், ஓடை)

32. தமிழின் தொன்மையை உணர்த்தும் சங்க இலக்கிய நூல் எது?

  1. தொல்காப்பியம்
  2. திருக்குறள்
  3. சிலப்பதிகாரம்
  4. மணிமேகலை

Answer: தொல்காப்பியம்

Explanation: தமிழின் மிகத் தொன்மையான இலக்கண நூல் தொல்காப்பியம் ஆகும். இது தமிழின் பழமையையும், அதன் இலக்கணச் செறிவையும் உணர்த்துகிறது. (பாடம்: தமிழ்மொழி மரபு)

33. கீழ்க்கண்டவற்றுள் எது வினையாலணையும் பெயர்?

  1. பாடியவன்
  2. பாடல்
  3. பாடினான்
  4. பாடுதல்

Answer: பாடியவன்

Explanation: ஒரு வினைமுற்று, வினையைக் குறிக்காமல், வினை செய்தவரைக் குறித்தால் அது வினையாலணையும் பெயர் எனப்படும். 'பாடியவன்' என்பது பாடும் தொழிலைச் செய்தவனைக் குறிப்பதால் இது வினையாலணையும் பெயர். (பாடம்: சொற்பூங்கா)

34. கீழ்க்கண்டவற்றுள் எது ஒரு தனிச்சொல்?

  1. வந்தான்
  2. வந்து போனான்
  3. வந்து சென்றான்
  4. வந்து பார்த்தான்

Answer: வந்தான்

Explanation: தனிச்சொல் என்பது ஒரு சொல் தனித்து நின்று பொருள் தருவது. 'வந்தான்' என்பது ஒரு தனிச்சொல். மற்றவை தொடர் சொற்கள். (பாடம்: வினைமுற்று)

35. கீழ்க்கண்டவற்றுள் எது 'வினைமுற்று' வகையைச் சாராதது?

  1. வந்தான்
  2. படித்தான்
  3. ஓடினான்
  4. வந்து

Answer: வந்து

Explanation: வினைமுற்று என்பது ஒரு செயல் முழுமையாக முடிவடைந்ததைக் குறிக்கும் சொல். 'வந்தான்', 'படித்தான்', 'ஓடினான்' ஆகியவை செயலை முடித்துக் காட்டும் வினைமுற்றுகள். ஆனால் 'வந்து' என்பது ஒரு செயல் முடிவடையாமல், மற்றொரு செயலைத் தழுவி வரும் எச்சவினை ஆகும். எனவே, இது வினைமுற்று வகையைச் சாராது.
