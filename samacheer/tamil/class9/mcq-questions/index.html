26. நீரின்றி அமையாது உலகு என்று கூறியவர் யார்?

  1. ஔவையார்
  2. திருவள்ளுவர்
  3. கம்பர்
  4. இளங்கோவடிகள்

Answer: திருவள்ளுவர்

Explanation: திருவள்ளுவர் திருக்குறளில் 'நீரின்றி அமையாது உலகு' என்று நீரின் முக்கியத்துவத்தை வலியுறுத்தியுள்ளார். இது நீரின்றி எந்த உயிரினமும் வாழ முடியாது என்பதை உணர்த்துகிறது.

27. திராவிட மொழிக் குடும்பத்தில், தென் திராவிட மொழிகள் அல்லாதது எது?

  1. தெலுங்கு
  2. கன்னடம்
  3. மலையாளம்
  4. துளு

Answer: தெலுங்கு

Explanation: திராவிட மொழிக் குடும்பம் மூன்று வகையாகப் பிரிக்கப்பட்டுள்ளது: தென் திராவிட மொழிகள், நடு திராவிட மொழிகள், வட திராவிட மொழிகள். தெலுங்கு நடு திராவிட மொழிக் குடும்பத்தைச் சேர்ந்தது. கன்னடம், மலையாளம், துளு ஆகியவை தென் திராவிட மொழிகள் ஆகும்.

28. கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில், 'ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை' என்று எதைக் குறிப்பிடுகிறார்?

  1. காதல் மொழியை
  2. கலை மொழியை
  3. தமிழ் மொழியை
  4. இயற்கை மொழியை

Answer: தமிழ் மொழியை

Explanation: கவிஞர் ஈரோடு தமிழன்பன் தனது 'தமிழோவியம்' நூலில், தமிழ் மொழியின் எளிமையையும் இயல்பான அழகையும் விளக்கும் விதமாக, 'ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை' என்று தமிழ் மொழியைக் குறிப்பிடுகிறார். தமிழ் மொழிக்கு அகராதிகள் தேவையில்லை, அது இயல்பாகவே புரியும் தன்மை கொண்டது என்பதே இதன் பொருள்.

29. தமிழ்விடு தூது நூலில், தூது அனுப்பப்படும் தலைவன் யார்?

  1. முருகன்
  2. சிவன்
  3. திருமால்
  4. குற்றாலநாதர்

Answer: குற்றாலநாதர்

Explanation: தமிழ்விடு தூது என்பது மதுரை சொக்கநாதர் மீது காதல் கொண்ட ஒரு பெண், தன் காதலைத் தெரிவிக்கும்படி தமிழ் மொழியைத் தூது விடுவதாக அமைந்த சிற்றிலக்கியம் ஆகும். இங்கு மதுரை சொக்கநாதர் என்பது குற்றாலநாதரைக் குறிக்கும். எனவே, தூது அனுப்பப்படும் தலைவன் குற்றாலநாதர் ஆவார்.

30. 'வளரும் செல்வம்' என்ற பாடப்பகுதியில், 'கணினி மொழி' என்று எதைக் குறிப்பிடுகிறார்கள்?

  1. பைத்தான்
  2. ஜாவா
  3. தமிழ்
  4. சி++

Answer: தமிழ்

Explanation: 'வளரும் செல்வம்' என்ற பாடப்பகுதியில், தமிழ் மொழியின் கணினி பயன்பாடுகள் மற்றும் அதன் வளர்ச்சி குறித்து பேசப்படுகிறது. தமிழ் மொழியை கணினி மொழியாகவும், இணையத்தில் அதன் பயன்பாடுகளையும் இப்பாடம் விளக்குகிறது.

31. தொடர் இலக்கணத்தில், ஒரு தொடரில் பயனிலை எங்கு வரும்?

  1. தொடரின் முதலில்
  2. தொடரின் இடையில்
  3. தொடரின் இறுதியில்
  4. எங்கு வேண்டுமானாலும்

Answer: தொடரின் இறுதியில்

Explanation: தமிழ் இலக்கணப்படி, ஒரு தொடரில் எழுவாய், செயப்படுபொருள், பயனிலை ஆகிய மூன்றும் இருக்கும். இதில் பயனிலை பொதுவாகத் தொடரின் இறுதியில் வரும். எடுத்துக்காட்டாக, 'கண்ணன் பாடம் படித்தான்' என்பதில் 'படித்தான்' என்பது பயனிலை, அது தொடரின் இறுதியில் வந்துள்ளது.

32. 'நீரின்றி அமையாது உலகு' என்ற திருக்குறள் உணர்த்தும் முக்கியக் கருத்து என்ன?

  1. நீர் சேமிப்பின் அவசியம்
  2. நீரின்றி உலகம் இல்லை
  3. நீரின் பயன்பாடுகள்
  4. நீர் வளத்தின் முக்கியத்துவம்

Answer: நீரின்றி உலகம் இல்லை

Explanation: திருக்குறளின் 'நீரின்றி அமையாது உலகு' என்ற குறள், நீர் இல்லாமல் இவ்வுலகம் இயங்காது என்பதை வலியுறுத்துகிறது. இது நீரின் இன்றியமையாத தன்மையையும், உயிர்களின் வாழ்வாதாரமாக நீர் இருப்பதையும் சுட்டிக்காட்டுகிறது.

33. 'பட்டமரம்' என்ற கவிதையில், பட்டுப்போன மரம் எதைக் குறிக்கிறது?

  1. வாழ்க்கையின் நிலையாமையை
  2. வறட்சியின் கொடுமையை
  3. இழந்துபோன இளமையின் ஏக்கத்தை
  4. இயற்கையின் அழிவை

Answer: இழந்துபோன இளமையின் ஏக்கத்தை

Explanation: கவிஞர் தமிழ் ஒளி எழுதிய 'பட்டமரம்' என்ற கவிதையில், பட்டுப்போன மரம் தனது பசுமையையும், இளமையையும் இழந்த ஏக்கத்தை வெளிப்படுத்துகிறது. இது மனித வாழ்க்கையில் இளமைக்காலத்தை இழந்து முதுமையில் படும் துயரத்தையும், கடந்தகால நினைவுகளையும் குறிப்பதாக அமைகிறது.

34. துணைவினைகள் என்பவை எவை?

  1. வினைச்சொல்லின் பொருளை மாற்றும் சொற்கள்
  2. வினைச்சொல்லின் பொருளைத் தெளிவுபடுத்தும் சொற்கள்
  3. வினைச்சொல்லுடன் இணைந்து புதிய பொருளைத் தரும் சொற்கள்
  4. வினைச்சொல்லின் காலத்தைக் குறிக்கும் சொற்கள்

Answer: வினைச்சொல்லுடன் இணைந்து புதிய பொருளைத் தரும் சொற்கள்

Explanation: துணைவினைகள் என்பவை ஒரு முதன்மை வினையுடன் இணைந்து, அதன் பொருளுக்கு மேலும் வலுவூட்டி, புதிய பொருளைத் தரும் வினைகள் ஆகும். இவை தனித்து இயங்காமல், முதன்மை வினைக்குத் துணையாக வந்து அதன் பொருளைச் செறிவூட்டும். எடுத்துக்காட்டாக, 'படித்துவிட்டான்' என்பதில் 'படித்து' முதன்மை வினை, 'விட்டான்' துணைவினை.

35. திராவிட மொழிக் குடும்பத்தில், தென் திராவிட மொழிக் குழுவில் இடம்பெறாத மொழி எது?

  1. தெலுங்கு
  2. கன்னடம்
  3. மலையாளம்
  4. துளு

Answer: தெலுங்கு

Explanation: திராவிட மொழிக் குடும்பம் தென் திராவிட மொழிகள், நடு திராவிட மொழிகள், வட திராவிட மொழிகள் என மூன்று வகையாகப் பிரிக்கப்பட்டுள்ளது. தென் திராவிட மொழிக் குழுவில் தமிழ், மலையாளம், கன்னடம், குடகு, துளு, கோத்தா, தோடா, கொரகா, இருளா போன்ற மொழிகள் அடங்கும். தெலுங்கு நடு திராவிட மொழிக் குழுவில் இடம்பெறும்.

36. தமிழ் இலக்கியத்தில் சங்க காலத்தை அடுத்து வந்த காலம் எது?

37. திருக்குறளின் சிறப்பு எது?
