Class9 MCQs with answers

1. திராவிட மொழிக் குடும்பத்தின் தென் திராவிட மொழிகளில் பொருந்தாதது எது?

  1. தெலுங்கு
  2. கன்னடம்
  3. மலையாளம்
  4. துளு

Answer: தெலுங்கு

Explanation: திராவிட மொழிக் குடும்பம் தென் திராவிட மொழிகள், நடு திராவிட மொழிகள், வட திராவிட மொழிகள் என மூன்று பிரிவுகளாகப் பிரிக்கப்பட்டுள்ளது. தென் திராவிட மொழிகள் பட்டியலில் தமிழ், மலையாளம், கன்னடம், குடகு, துளு, கோத்தா, தோடா, கொரகா, இருளா ஆகியவை அடங்கும். தெலுங்கு நடு திராவிட மொழிக் குடும்பத்தைச் சேர்ந்தது.

2. கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில் இடம்பெறாத கூற்று எது?

  1. ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை.
  2. இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்.
  3. தமிழ்மொழி ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் போன்றது.
  4. தமிழ்மொழிக்கு ஒரு காலம் இருந்தது; இனி ஒரு காலம் வரும்.

Answer: இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்.

Explanation: கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில், 'ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை. தமிழ்மொழி ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் போன்றது. தமிழ்மொழிக்கு ஒரு காலம் இருந்தது; இனி ஒரு காலம் வரும்' போன்ற கூற்றுகள் இடம்பெற்றுள்ளன. 'இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்' என்பது தமிழோவியம் நூலில் இடம்பெறவில்லை.

3. தமிழ்விடு தூது நூலின் பாட்டுடைத் தலைவன் யார்?

  1. மதுரைச் சொக்கநாதர்
  2. திருக்குற்றாலநாதர்
  3. மீனாட்சி சுந்தரேசுவரர்
  4. சுப்பிரமணியர்

Answer: மதுரைச் சொக்கநாதர்

Explanation: தமிழ்விடு தூது என்பது தூது இலக்கிய வகையைச் சேர்ந்தது. இந்நூலின் பாட்டுடைத் தலைவன் மதுரைச் சொக்கநாதர் ஆவார். இந்நூல் 268 கண்ணிகளைக் கொண்டுள்ளது.

4. பொருத்துக: 1. இடுபொருள் - அ. Output 2. செய்முறை - ஆ. Input 3. வெளியீடு - இ. Process 4. தரவு - ஈ. Data

  1. 1-ஆ, 2-இ, 3-அ, 4-ஈ
  2. 1-அ, 2-இ, 3-ஆ, 4-ஈ
  3. 1-இ, 2-அ, 3-ஆ, 4-ஈ
  4. 1-ஆ, 2-அ, 3-இ, 4-ஈ

Answer: 1-ஆ, 2-இ, 3-அ, 4-ஈ

Explanation: இடுபொருள் - Input, செய்முறை - Process, வெளியீடு - Output, தரவு - Data. இவை கணினி தொடர்பான கலைச்சொற்கள் ஆகும்.

5. ஒரு தொடரில் எழுவாயோ, பயனிலையோ இல்லாமல் அமையும் தொடர் எது?

  1. எழுவாய் தொடர்
  2. பயனிலை தொடர்
  3. வேற்றுமை தொடர்
  4. விளித்தொடர்

Answer: விளித்தொடர்

Explanation: ஒரு தொடரில் எழுவாயோ, பயனிலையோ இல்லாமல், ஒருவரை அழைக்கும் பொருளில் அமையும் தொடர் விளித்தொடர் எனப்படும். எடுத்துக்காட்டு: 'நண்பா! வா'.
