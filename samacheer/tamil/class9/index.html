1. திராவிட மொழிக் குடும்பத்தின் தென் திராவிட மொழிகளில் பொருந்தாதது எது?

  1. தெலுங்கு
  2. கன்னடம்
  3. மலையாளம்
  4. துளு

Answer: தெலுங்கு

Explanation: திராவிட மொழிக் குடும்பம் தென் திராவிட மொழிகள், நடு திராவிட மொழிகள், வட திராவிட மொழிகள் என மூன்று பிரிவுகளாகப் பிரிக்கப்பட்டுள்ளது. தென் திராவிட மொழிகள் பட்டியலில் தமிழ், மலையாளம், கன்னடம், குடகு, துளு, கோத்தா, தோடா, கொரகா, இருளா ஆகியவை அடங்கும். தெலுங்கு நடு திராவிட மொழிக் குடும்பத்தைச் சேர்ந்தது.

2. கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில் இடம்பெறாத கூற்று எது?

  1. ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை.
  2. இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்.
  3. தமிழ்மொழி ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் போன்றது.
  4. தமிழ்மொழிக்கு ஒரு காலம் இருந்தது; இனி ஒரு காலம் வரும்.

Answer: இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்.

Explanation: கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில், 'ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை. தமிழ்மொழி ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் போன்றது. தமிழ்மொழிக்கு ஒரு காலம் இருந்தது; இனி ஒரு காலம் வரும்' போன்ற கூற்றுகள் இடம்பெற்றுள்ளன. 'இனிவரும் காலம் கணியன் பூங்குன்றனாரின் காலம்' என்பது தமிழோவியம் நூலில் இடம்பெறவில்லை.

3. தமிழ்விடு தூது நூலின் பாட்டுடைத் தலைவன் யார்?

  1. மதுரைச் சொக்கநாதர்
  2. திருக்குற்றாலநாதர்
  3. மீனாட்சி சுந்தரேசுவரர்
  4. சுப்பிரமணியர்

Answer: மதுரைச் சொக்கநாதர்

Explanation: தமிழ்விடு தூது என்பது தூது இலக்கிய வகையைச் சேர்ந்தது. இந்நூலின் பாட்டுடைத் தலைவன் மதுரைச் சொக்கநாதர் ஆவார். இந்நூல் 268 கண்ணிகளைக் கொண்டுள்ளது.

4. பொருத்துக: 1. இடுபொருள் - அ. Output 2. செய்முறை - ஆ. Input 3. வெளியீடு - இ. Process 4. தரவு - ஈ. Data

  1. 1-ஆ, 2-இ, 3-அ, 4-ஈ
  2. 1-அ, 2-இ, 3-ஆ, 4-ஈ
  3. 1-இ, 2-அ, 3-ஆ, 4-ஈ
  4. 1-ஆ, 2-அ, 3-இ, 4-ஈ

Answer: 1-ஆ, 2-இ, 3-அ, 4-ஈ

Explanation: இடுபொருள் - Input, செய்முறை - Process, வெளியீடு - Output, தரவு - Data. இவை கணினி தொடர்பான கலைச்சொற்கள் ஆகும்.

5. ஒரு தொடரில் எழுவாயோ, பயனிலையோ இல்லாமல் அமையும் தொடர் எது?

  1. எழுவாய் தொடர்
  2. பயனிலை தொடர்
  3. வேற்றுமை தொடர்
  4. விளித்தொடர்

Answer: விளித்தொடர்

Explanation: ஒரு தொடரில் எழுவாயோ, பயனிலையோ இல்லாமல், ஒருவரை அழைக்கும் பொருளில் அமையும் தொடர் விளித்தொடர் எனப்படும். எடுத்துக்காட்டு: 'நண்பா! வா'.

6. நீரின்றி அமையாது உலகு - இத்தொடரில் இடம்பெற்றுள்ள அணி எது?

  1. உவமை அணி
  2. உருவக அணி
  3. பிறிதுமொழிதல் அணி
  4. எடுத்துக்காட்டு உவமை அணி

Answer: பிறிதுமொழிதல் அணி

Explanation: நீரின்றி அமையாது உலகு - இத்தொடரில் பிறிதுமொழிதல் அணி இடம்பெற்றுள்ளது. பிறிதுமொழிதல் அணி என்பது ஒரு கருத்தை நேரடியாகக் கூறாமல், அதற்குரிய உவமையை மட்டும் கூறி, அதன் மூலம் கருத்தை உணர்த்துவது ஆகும். இங்கு நீரின் முக்கியத்துவத்தை நேரடியாகக் கூறாமல், 'நீரின்றி அமையாது உலகு' என்று கூறி உணர்த்தப்பட்டுள்ளது.

7. பழமொழி நானூறு கூறும் கருத்துக்களில் பொருந்தாதது எது?

  1. கல்வி ஒருவருக்கு அழியாத செல்வம்.
  2. கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான்.
  3. கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான் என்பது இல்லை.
  4. கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான் என்பது இல்லை.

Answer: கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான் என்பது இல்லை.

Explanation: பழமொழி நானூறு, 'கல்வி ஒருவருக்கு அழியாத செல்வம்' என்றும், 'கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான்' என்றும் கூறுகிறது. எனவே, 'கல்வி இல்லாதவன் ஒருவன், பிறருக்குத் துன்பம் தருவான் என்பது இல்லை' என்பது பொருந்தாத கூற்று.

8. துணைவினைகள் எத்தனை வகைப்படும்?

  1. இரண்டு
  2. மூன்று
  3. நான்கு
  4. ஐந்து

Answer: ஐந்து

Explanation: துணைவினைகள் ஐந்து வகைப்படும். அவை: 1. தன்வினைத் துணைவினைகள், 2. பிறவினைத் துணைவினைகள், 3. செய்வினைத் துணைவினைகள், 4. செயப்பாட்டுவினைத் துணைவினைகள், 5. கூட்டுவினைத் துணைவினைகள்.

9. கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலின் சிறப்பு யாது?

  1. புதுக்கவிதை வடிவில் எழுதப்பட்டது
  2. சங்க இலக்கிய மரபில் அமைந்தது
  3. இலக்கணக் கட்டுக்கோப்புடன் எழுதப்பட்டது
  4. பாரம்பரிய யாப்பு வடிவத்தில் அமைந்தது

Answer: புதுக்கவிதை வடிவில் எழுதப்பட்டது

Explanation: கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' என்ற நூல், ஒரு பூவின் மலர்ச்சியையும் ஒரு குழந்தையின் புன்னகையையும் புரிந்துகொள்ள அகராதிகள் தேவைப்படுவதில்லை என்பது போல, தமிழோவியம் என்ற நூலும் புதுக்கவிதை வடிவில் எழுதப்பட்டுள்ளது. இது இலக்கணக் கட்டுக்கோப்புகள் இன்றி, மரபுக்கவிதையின் யாப்பு வடிவத்தில் அமையாமல், புதுக்கவிதை வடிவில் எழுதப்பட்ட ஒரு கவிதை நூல் ஆகும்.

10. தமிழ்விடு தூது நூலில், தமிழ் மொழியின் எந்தச் சுவை குறிப்பிடப்படவில்லை?

  1. வீரம்
  2. அச்சம்
  3. அழகு
  4. உவகை

Answer: அச்சம்

Explanation: தமிழ்விடு தூது நூலில், தமிழ் மொழியின் ஒன்பது சுவைகளில் வீரம், அழகு, உவகை போன்ற சுவைகள் குறிப்பிடப்பட்டுள்ளன. அச்சம் என்ற சுவை நேரடியாகக் குறிப்பிடப்படவில்லை. தமிழ்விடு தூது, தமிழில் உள்ள ஒன்பது சுவைகளையும், அதன் சிறப்புகளையும் எடுத்துரைக்கிறது.

11. 'வளரும் செல்வம்' என்ற பாடப்பகுதியில், 'கணினி மொழி' என எம்மொழி குறிப்பிடப்பட்டுள்ளது?

  1. தமிழ்
  2. ஆங்கிலம்
  3. சமஸ்கிருதம்
  4. சீனம்

Answer: தமிழ்

Explanation: 'வளரும் செல்வம்' என்ற பாடப்பகுதியில், கணினி மொழிக்கு ஏற்ற மொழியாகத் தமிழ் மொழி குறிப்பிடப்பட்டுள்ளது. தமிழ் மொழியின் இலக்கணச் செறிவும், சொற்களின் அமைப்பு முறையும் கணினிக்கு ஏற்றதாக உள்ளதாகக் கூறப்பட்டுள்ளது.

12. தொடர் இலக்கணத்தில், ஒரு தொடரில் எழுவாய், பயனிலை, செயப்படுபொருள் ஆகிய மூன்றும் இடம்பெறும் தொடர் எவ்வாறு அழைக்கப்படுகிறது?

  1. முற்றுத்தொடர்
  2. எழுவாய்த்தொடர்
  3. செயப்படுபொருள் தொடர்
  4. பயனிலைத் தொடர்

Answer: முற்றுத்தொடர்

Explanation: ஒரு தொடரில் எழுவாய், பயனிலை, செயப்படுபொருள் ஆகிய மூன்றும் இடம்பெற்று முழுமையான பொருளைத் தந்தால் அது முற்றுத்தொடர் எனப்படும். எடுத்துக்காட்டு: 'கண்ணன் பாடம் படித்தான்.' இங்கு 'கண்ணன்' எழுவாய், 'பாடம்' செயப்படுபொருள், 'படித்தான்' பயனிலை.

13. 'நீரின்றி அமையாது உலகு' என்ற திருக்குறள் உணர்த்தும் முக்கியக் கருத்து யாது?

  1. நீர் இன்றி உலகம் இயங்காது
  2. நீர் மனித வாழ்வின் ஆதாரம்
  3. நீர் சேமிப்பின் அவசியம்
  4. மேற்கண்ட அனைத்தும்

Answer: மேற்கண்ட அனைத்தும்

Explanation: 'நீரின்றி அமையாது உலகு' என்ற திருக்குறள், நீர் இல்லாமல் உலகம் இயங்காது என்பதையும், நீர் மனித வாழ்வின் ஆதாரம் என்பதையும், நீர் சேமிப்பின் அவசியத்தையும் வலியுறுத்துகிறது. எனவே, மேற்கண்ட அனைத்தும் சரியான கருத்துக்களே.

14. பழமொழி நானூறு கூறும் 'பட்டம் மரம்' பற்றிய கருத்து யாது?

  1. பயனற்றது
  2. நிழல் தராது
  3. கனி தராது
  4. இலைகள் அற்றது

Answer: பயனற்றது

Explanation: பழமொழி நானூறு, 'பட்டம் மரம்' என்பது பயனற்றது என்பதைக் குறிக்கிறது. அதாவது, ஒரு மரம் பட்டுப்போனால் அது எந்தப் பயனும் தராது என்பது போல, பயனற்ற செயல்களைச் செய்யக்கூடாது என்பதை உணர்த்துகிறது.

15. பெரியபுராணம் யாரைப் பற்றிய காப்பியம்?

  1. சைவ சமய அடியார்களைப் பற்றியது
  2. வைணவ சமய அடியார்களைப் பற்றியது
  3. சமண சமய அடியார்களைப் பற்றியது
  4. பௌத்த சமய அடியார்களைப் பற்றியது

Answer: சைவ சமய அடியார்களைப் பற்றியது

Explanation: பெரியபுராணம், சைவ சமய அடியார்களான அறுபத்து மூன்று நாயன்மார்களின் வரலாற்றை விரிவாகக் கூறும் ஒரு காப்பியம். இது சேக்கிழாரால் இயற்றப்பட்டது.

16. திராவிட மொழிக் குடும்பத்தின் எந்தப் பிரிவில் தமிழ் மொழி இடம்பெற்றுள்ளது?

  1. தென் திராவிட மொழிகள்
  2. நடு திராவிட மொழிகள்
  3. வட திராவிட மொழிகள்
  4. மேற்கு திராவிட மொழிகள்

Answer: தென் திராவிட மொழிகள்

Explanation: திராவிட மொழிக் குடும்பம் மூன்று பெரும் பிரிவுகளாகப் பிரிக்கப்பட்டுள்ளது. அவற்றுள் தமிழ், மலையாளம், கன்னடம், துளு போன்ற மொழிகள் தென் திராவிட மொழிகள் பிரிவில் இடம்பெற்றுள்ளன. இது 'திராவிட மொழிக் குடும்பம்' என்ற பாடப்பகுதியில் தெளிவாகக் குறிப்பிடப்பட்டுள்ளது.

17. கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' நூலில் இடம்பெற்றுள்ள கவிதைகள் எதைப் பற்றிப் பேசுகின்றன?

  1. சங்க இலக்கியத்தின் சிறப்புகள்
  2. புதுக்கவிதையின் வளர்ச்சி
  3. தமிழின் தொன்மை மற்றும் புதுமை
  4. நாட்டுப்புறப் பாடல்களின் முக்கியத்துவம்

Answer: தமிழின் தொன்மை மற்றும் புதுமை

Explanation: கவிஞர் ஈரோடு தமிழன்பன் எழுதிய 'தமிழோவியம்' என்ற நூல், தமிழின் தொன்மையையும், அதன் புதுமையையும் ஒருங்கே பேசும் கவிதைகளைக் கொண்டுள்ளது. இது 'தமிழோவியம்' என்ற பாடப்பகுதியில் கவிஞரின் அறிமுகத்திலும், நூலின் சிறப்பம்சத்திலும் குறிப்பிடப்பட்டுள்ளது.

18. பொருளாதாரத்தில் 'வளரும் செல்வம்' என்பது எதைக் குறிக்கிறது?

  1. நிலத்தின் மதிப்பு அதிகரித்தல்
  2. மனிதவள மேம்பாடு
  3. சேமிப்பு மற்றும் முதலீட்டின் பெருக்கம்
  4. இயற்கை வளங்களின் பயன்பாடு

Answer: சேமிப்பு மற்றும் முதலீட்டின் பெருக்கம்

Explanation: 'வளரும் செல்வம்' என்ற பாடப்பகுதி, சேமிப்பின் முக்கியத்துவத்தையும், சேமிக்கப்பட்ட பணம் எவ்வாறு முதலீடாக மாறி மேலும் செல்வத்தை உருவாக்குகிறது என்பதையும் விளக்குகிறது. எனவே, சேமிப்பு மற்றும் முதலீட்டின் பெருக்கமே வளரும் செல்வம் என்பதன் முக்கியக் கருத்தாகும்.

19. ஒரு தொடரில் எழுவாயோ, பயனிலையோ வெளிப்படையாகத் தோன்றாமல், குறிப்பால் உணர்த்தப்படுவது எவ்வாறு அழைக்கப்படுகிறது?

  1. எழுவாய்த் தொடர்
  2. வினைமுற்றுத் தொடர்
  3. குறிப்பு வினைமுற்றுத் தொடர்
  4. வேற்றுமைத் தொடர்

Answer: குறிப்பு வினைமுற்றுத் தொடர்

Explanation: ஒரு தொடரில் எழுவாயோ, பயனிலையோ வெளிப்படையாகத் தோன்றாமல், குறிப்பால் உணர்த்தப்படுவது குறிப்பு வினைமுற்றுத் தொடர் எனப்படும். எடுத்துக்காட்டாக, 'அவன் நல்லவன்' என்பதில் 'அவன்' என்ற எழுவாய் வெளிப்படையாக உள்ளது. ஆனால், 'நல்லவன்' என்பதில் 'அவன்' என்ற எழுவாய் குறிப்பால் உணர்த்தப்படுகிறது. இது 'தொடர் இலக்கணம்' என்ற பாடப்பகுதியில் விளக்கப்பட்டுள்ளது.

20. 'நீரின்றி அமையாது உலகு' என்ற திருக்குறள் உணர்த்தும் முதன்மையான கருத்து யாது?

  1. நீர் சேமிப்பின் அவசியம்
  2. நீரின்றி உலகம் இயங்காது
  3. நீர் வளங்களின் பாதுகாப்பு
  4. நீரின் பல்வேறு பயன்கள்

Answer: நீரின்றி உலகம் இயங்காது

Explanation: 'நீரின்றி அமையாது உலகு' என்ற திருக்குறள், நீர் இல்லாமல் இவ்வுலகம் இயங்காது என்ற அடிப்படை உண்மையையும், நீரின் இன்றியமையாமையையும் முதன்மையாக உணர்த்துகிறது. இது 'நீரின்றி அமையாது உலகு' என்ற பாடப்பகுதியின் மையக்கருத்தாகும்.

21. பெரியபுராணம் யாரால் இயற்றப்பட்டது?

  1. சேக்கிழார்
  2. சுந்தரர்
  3. திருஞானசம்பந்தர்
  4. திருநாவுக்கரசர்

Answer: சேக்கிழார்

Explanation: பெரியபுராணம், அறுபத்து மூன்று நாயன்மார்களின் வரலாற்றை விரிவாகக் கூறும் காப்பியம் ஆகும். இது சேக்கிழார் என்பவரால் இயற்றப்பட்டது. இது 'பெரியபுராணம்' என்ற பாடப்பகுதியின் அறிமுகத்தில் தெளிவாகக் குறிப்பிடப்பட்டுள்ளது.

22. குறுந்தொகை எந்த வகை நூல்களில் ஒன்று?

  1. பத்துப்பாட்டு
  2. எட்டுத்தொகை
  3. பதினெண்கீழ்க்கணக்கு
  4. ஐம்பெருங்காப்பியங்கள்

Answer: எட்டுத்தொகை

Explanation: குறுந்தொகை என்பது சங்க இலக்கியத்தில் எட்டுத்தொகை நூல்களுள் ஒன்றாகும். இது அகப்பொருள் பற்றிய பாடல்களைக் கொண்டது. இது 'குறுந்தொகை' என்ற பாடப்பகுதியின் அறிமுகத்தில் தெளிவாகக் குறிப்பிடப்பட்டுள்ளது.

23. கவிஞர் ஈரோடு தமிழன்பன் எந்தப் புதுக்கவிதை நூலுக்காக சாகித்திய அகாதெமி விருது பெற்றார்?

  1. தமிழோவியம்
  2. வணக்கம் வள்ளுவ
  3. சூரியப் பிறைகள்
  4. ஒரு வானம் ஒரு சிறகு

Answer: வணக்கம் வள்ளுவ

Explanation: கவிஞர் ஈரோடு தமிழன்பன் 'வணக்கம் வள்ளுவ' என்ற புதுக்கவிதை நூலுக்காக 2004 ஆம் ஆண்டு சாகித்திய அகாதெமி விருது பெற்றார். தமிழோவியம் என்பது அவரது மற்றொரு படைப்பு.

24. கலப்பையையும் ஏரையும் பூட்டி உழவர்கள் நிலத்தை உழுவதைக் குறிக்கும் சொல் எது?

  1. ஏர்பிடித்தல்
  2. ஏர்ப்பூட்டு
  3. ஏர் உழுதல்
  4. ஏர் ஓட்டுதல்

Answer: ஏர்ப்பூட்டு

Explanation: ஏர்ப்பூட்டு என்பது கலப்பையையும் ஏரையும் பூட்டி உழவர்கள் நிலத்தை உழுவதைக் குறிக்கும் சொல். இது உழவுத் தொழிலின் ஒரு முக்கியப் பகுதியாகும்.

25. ஒரு தொடரில் எழுவாய், பயனிலை, செயப்படுபொருள் ஆகிய மூன்றும் வரிசையாக அமைவது எவ்வகைத் தொடர்?

  1. தொடர்நிலைத் தொடர்
  2. எழுவாய்த் தொடர்
  3. செயப்படுபொருள் தொடர்
  4. பொதுவான தொடர் அமைப்பு

Answer: பொதுவான தொடர் அமைப்பு

Explanation: ஒரு தொடரில் எழுவாய், பயனிலை, செயப்படுபொருள் ஆகிய மூன்றும் வரிசையாக அமைவது பொதுவான தொடர் அமைப்பு ஆகும். எடுத்துக்காட்டு: 'நான் பாடம் படித்தேன்.' (நான் - எழுவாய், பாடம் - செயப்படுபொருள், படித்தேன் - பயனிலை).
