Class6 MCQs with answers

Use these 5 worked Class6 questions to revise the Samacheer Tamil syllabus. Each answer includes an explanation; the full practice set contains 652 questions.

1. தமிழுக்கு அமுது என்று பெயர் என்று பாடியவர் யார்?

  1. பாரதிதாசன்
  2. பாரதியார்
  3. கண்ணதாசன்
  4. வாலி

Answer: பாரதிதாசன்

Explanation: இன்பத்தமிழ் பாடலில், தமிழுக்கு அமுது என்று பெயர் என்று பாடியவர் பாவேந்தர் பாரதிதாசன் ஆவார். இவர் தமிழைப் பலவாறு போற்றிப் பாடியுள்ளார்.

2. தமிழ்க்கும்மி பாடலில், 'ஊழி' என்பதன் பொருள் யாது?

  1. நீண்டதொரு காலப்பகுதி
  2. உலகம்
  3. காலம்
  4. வானம்

Answer: நீண்டதொரு காலப்பகுதி

Explanation: தமிழ்க்கும்மி பாடலில் வரும் 'ஊழி' என்ற சொல்லின் பொருள் 'நீண்டதொரு காலப்பகுதி' என்பதாகும். இச்சொல் பல நூற்றாண்டுகளைக் குறிக்கும்.

3. தமிழில் உள்ள முதல் எழுத்துகளின் எண்ணிக்கை யாது?

  1. 12
  2. 18
  3. 30
  4. 247

Answer: 30

Explanation: தமிழ் எழுத்துகளில், உயிர் எழுத்துகள் 12, மெய் எழுத்துகள் 18 ஆக மொத்தம் 30 எழுத்துகள் முதல் எழுத்துகள் எனப்படும். இவை பிற எழுத்துகள் தோன்றுவதற்கு அடிப்படையாக அமைகின்றன.

4. சிலப்பதிகாரத்தின் ஆசிரியர் யார்?

  1. திருவள்ளுவர்
  2. கம்பர்
  3. இளங்கோவடிகள்
  4. சேக்கிழார்

Answer: இளங்கோவடிகள்

Explanation: ஐம்பெருங்காப்பியங்களில் ஒன்றான சிலப்பதிகாரத்தை இயற்றியவர் இளங்கோவடிகள் ஆவார். இது தமிழின் முதல் காப்பியம் என்று போற்றப்படுகிறது.

5. 'காணி நிலம் வேண்டும்' என்று பாடியவர் யார்?

  1. பாரதியார்
  2. பாரதிதாசன்
  3. கண்ணதாசன்
  4. வாலி

Answer: பாரதியார்

Explanation: காணி நிலம் வேண்டும் பராசக்தி காணி நிலம் வேண்டும் என்று பாடியவர் மகாகவி பாரதியார் ஆவார். இவர் இயற்கையையும் இறைவனையும் போற்றிப் பல பாடல்களைப் பாடியுள்ளார்.
