26. மங்கை கிராமத்தில் எவற்றைக் கண்டு மகிழ்ச்சி கொள்கிறார்?

  1. சுத்தமான காற்று, கிணற்றுத் தண்ணீர்
  2. பெரிய கட்டிடங்கள்
  3. வாகனங்கள்
  4. தொழிற்சாலைகள்

Answer: சுத்தமான காற்று, கிணற்றுத் தண்ணீர்

Explanation: சுத்தமான காற்று, கிணற்றுத் தண்ணீர் ஆகியவை மங்கைக்கு மகிழ்ச்சி தருகின்றன.

27. மங்கை கிராமத்திற்கு வந்ததைக் கண்ட மல்லிகா முதலில் என்ன கேட்டார்?

  1. எப்படி இருக்கிறாய்?
  2. என்ன ஊரோடு வந்துவிட்டாய்?
  3. எங்கே போகிறாய்?
  4. யார் உன்னுடன் வந்தார்கள்?

Answer: என்ன ஊரோடு வந்துவிட்டாய்?

Explanation: என்ன ஊரோடு வந்துவிட்டாய்? என்று மல்லிகா கேட்கிறார்.

28. மங்கை தனது கணவர் மற்றும் குழந்தைகளின் நலனைப் பற்றி மல்லிகாவிற்குத் தெரிவித்தார்.

  1. True
  2. False

Answer: True

Explanation: மங்கை எல்லாரும் நல்லா இருக்காங்க என்று கூறுகிறார்.

29. மங்கை நகரத்தில் வசிக்க முடிவு செய்துள்ளார்.

  1. True
  2. False

Answer: False

Explanation: மங்கை கிராமத்தில்தான் இருக்கப் போகிறேன் என்று கூறுகிறார்.

30. இயற்கையிலிருந்து விலகி மண்ணுக்கும் உயிர்களுக்கும் ஊறு விளைவிப்பது சரியானது.

  1. True
  2. False

Answer: False

Explanation: இயற்கையிலிருந்து விலகுவது மண்ணுக்கும் உயிர்களுக்கும் ஊறு விளைவிக்கும்.

38. 'சேசான் சமட் டமடர உலகம்' என்று குறிப்பிடுவது எது?

40. மலைப்பகுதிகளின் தெய்வங்கள் எவ்வகை இலக்கியங்களில் குறிப்பிடப்பட்டுள்ளன?

  1. நவீன இலக்கியங்கள்
  2. பழைய தமிழ் இலக்கியங்கள்
  3. வெளிநாட்டு இலக்கியங்கள்
  4. சமகால இலக்கியங்கள்

Answer: பழைய தமிழ் இலக்கியங்கள்

Explanation: பழைய தமிழ் இலக்கியங்கள் மலைப்பகுதிகளின் தெய்வங்களை விவரிக்கின்றன.

41. மலைப்பகுதிகளின் தெய்வங்கள் எத்தகைய தெய்வங்களாகக் காணப்படுகின்றன?

  1. பெரிய தெய்வங்கள்
  2. இடைநிலை தெய்வங்கள்
  3. இடைக்குறுநிலை தெய்வங்கள்
  4. ஆதி தெய்வங்கள்

Answer: இடைக்குறுநிலை தெய்வங்கள்

Explanation: இடைக்குறுநிலை தெய்வங்களாக இவை காணப்படுகின்றன.

42. மலைப்பகுதிகளின் தெய்வங்கள் யாருக்கு வழங்கப்படவில்லை?

  1. மக்களுக்கு
  2. ஆண்டி முடிமன்னர்களுக்கு
  3. இயற்கைக்கு
  4. குலதெய்வங்களுக்கு

Answer: ஆண்டி முடிமன்னர்களுக்கு

Explanation: ஆண்டி முடிமன்னர்களுக்கு இவை வழங்கப்படவில்லை என்று பாடப்பகுதி கூறுகிறது.

43. மலைப்பகுதிகளின் தெய்வங்கள் எதனுடன் தொடர்புபடுத்தப்பட்டுள்ளன?

  1. கடல் மற்றும் நிலம்
  2. கடவுள் மற்றும் மலை
  3. காடு மற்றும் ஆறு
  4. வானம் மற்றும் பூமி

Answer: கடவுள் மற்றும் மலை

Explanation: தமிழ்பெருமை கடவுளையும் மலையையும் தொடர்புபடுத்துகிறது.

44. மலைப்பகுதிகளின் தெய்வங்கள் எங்கு விவரிக்கப்பட்டுள்ளன?

  1. புறநானூறு மட்டும்
  2. பழைய தமிழ் இலக்கியங்கள்
  3. ததால்காப்பியம் மட்டும்
  4. திருக்குறள்

Answer: பழைய தமிழ் இலக்கியங்கள்

45. திராவிடர்களின் மலைப் பெருமிதம் எதன் அடிப்படையில் வெளிப்படுகிறது?

  1. மொழி
  2. மலை வாழ் மானுட புவிச்சூழ்நிலை
  3. சமயம்

46. கீழ்க்கண்டவற்றுள் எது சரியான கூற்று?

  1. 1. கமில் சுவைபில் திராவிடர்களை மலைநிலை மனிதர்கள் என்றார். 2. ததால்காப்பியம் மலைப்பகுதியை விவரிக்கிறது.
  2. 1. திருக்குறள் மலைப்பகுதியை விவரிக்கிறது. 2. கமில் சுவைபில் சமதள மனிதர்கள் என்றார்.
  3. 1. புறநானூறு மட்டும் மலைப்பகுதியை கூறுகிறது. 2. ததால்காப்பியம் மௌனம் காக்கிறது.
  4. 1. மலைப்பகுதிகள் சமதள நிலங்கள். 2. திராவிடர்கள் சமதள மனிதர்கள்.

Answer: 1. கமில் சுவைபில் திராவிடர்களை மலைநிலை மனிதர்கள் என்றார். 2. ததால்காப்பியம் மலைப்பகுதியை விவரிக்கிறது.

Explanation: கமில் சுவைபில் மற்றும் ததால்காப்பியம் ஆகிய இரு கூற்றுகளும் சரியானவை.

47. மலைப்பகுதிகள் குறித்த சரியான கூற்றைத் தேர்ந்தெடு:

  1. 1. மலைப்பகுதிகள் ஆதிநிலை மனிதர்களின் இருப்பிடம். 2. திராவிடர்கள் மலைவாழ் மக்கள்.
  2. 1. மலைப்பகுதிகள் நவீன மனிதர்களின் இருப்பிடம். 2. திராவிடர்கள் சமதள மக்கள்.
  3. 1. மலைப்பகுதிகள் பாலைவனம். 2. திராவிடர்கள் கடலோர மக்கள்.
  4. 1. மலைப்பகுதிகள் காடுகள் அல்ல. 2. திராவிடர்கள் நகர்ப்புற மக்கள்.

Answer: 1. மலைப்பகுதிகள் ஆதிநிலை மனிதர்களின் இருப்பிடம். 2. திராவிடர்கள் மலைவாழ் மக்கள்.

Explanation: மலைப்பகுதிகள் மனித சமூகத்தின் ஆதிநிலை மற்றும் திராவிடர்கள் மலைவாழ் மக்கள் என்பது சரி.

48. திராவிடர்கள் அடிப்படையில் மலைவாழ் மக்கள்.

  1. True
  2. False

Answer: True

Explanation: பாடப்பகுதியின்படி திராவிடர்கள் அடிப்படையில் மலைவாழ் மக்கள்.

49. ததால்காப்பியம் 'விண்த்பாரு தெடுவடர குறிஞ்சி ககிைவ' என்று கூறுகிறது.

  1. True
  2. False

Answer: False

Explanation: இந்த வரி திருமுருகாற்றுப்படையினது, ததால்காப்பியத்தினது அல்ல.

50. மலைப்பகுதிகள் மனித சமூகத்தின் ஆதிநிலை ஆகும்.

  1. True
  2. False

Answer: True

Explanation: மலை, மனித சமூகத்தின் ஆதிநிலை என்று குறிப்பிடப்பட்டுள்ளது.
