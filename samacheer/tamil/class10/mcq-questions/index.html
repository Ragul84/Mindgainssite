26. ஒரு மொழிக்கு அடிப்படையாக அமைவது எது?

  1. எழுத்து
  2. சொல்
  3. வாக்கியம்
  4. பொருள்

Answer: எழுத்து

Explanation: ஒரு மொழிக்கு அடிப்படையாக அமைவது எழுத்து ஆகும். எழுத்துக்களின் சேர்க்கையே சொற்களாகவும், சொற்களின் சேர்க்கையே வாக்கியங்களாகவும் அமைகின்றன. இது 'எழுத்து, சொல்' பாடப்பகுதியின் அடிப்படை இலக்கணக் கருத்து.

27. கேட்கிறதா என் குரல்! என்ற பாடப்பகுதியில், காற்று எதனைத் தழுவிச் செல்கிறது என்று குறிப்பிடப்பட்டுள்ளது?

  1. பூக்கள்
  2. மலைகள்
  3. கடல்
  4. மேகங்கள்

Answer: பூக்கள்

Explanation: கேட்கிறதா என் குரல்! என்ற பாடப்பகுதியில், காற்று பூக்களைத் தழுவிச் செல்கிறது என்று குறிப்பிடப்பட்டுள்ளது. இது காற்றின் மென்மையையும், இயற்கையுடனான அதன் தொடர்பையும் விளக்குகிறது.

28. முல்லைப்பாட்டு எந்த வகை இலக்கியத்தைச் சார்ந்தது?

  1. பத்துப்பாட்டு
  2. எட்டுத்தொகை
  3. பதினெண்கீழ்க்கணக்கு
  4. ஐம்பெருங்காப்பியம்

Answer: பத்துப்பாட்டு

Explanation: முல்லைப்பாட்டு பத்துப்பாட்டு நூல்களில் ஒன்று. இது சங்க இலக்கிய வகையைச் சேர்ந்தது. இது 'முல்லைப்பாட்டு' பாடப்பகுதியின் அறிமுகத்தில் உள்ளது.

29. தமிழ்மொழியின் இலக்கண வரம்புகளைக் கடந்து, காலந்தோறும் தன்னைத்தானே புதுப்பித்துக் கொள்ளும் ஆற்றல் மிக்கது எது?

  1. அன்னையர் மொழி
  2. செம்மொழி
  3. வட்டார மொழி
  4. பழைய மொழி

Answer: செம்மொழி

Explanation: தமிழ்மொழி காலந்தோறும் தன்னைத்தானே புதுப்பித்துக் கொள்ளும் ஆற்றல் மிக்கது. இது செம்மொழியின் தனிச்சிறப்புகளில் ஒன்றாகும். 'அன்னை மொழியே' என்ற பாடப்பகுதி தமிழ்மொழியின் சிறப்புகளைப் பேசுகிறது.

30. ஒரு சொல்லோ சொற்றொடரோ இருபொருள் பட வருவது எவ்வாறு அழைக்கப்படுகிறது?

  1. உவமை அணி
  2. உருவக அணி
  3. இலக்கணை
  4. இரட்டுற மொழிதல்

Answer: இரட்டுற மொழிதல்

Explanation: ஒரு சொல்லோ சொற்றொடரோ இருபொருள் பட வருவது இரட்டுற மொழிதல் அணி எனப்படும். இதனைச் சிலேடை என்றும் கூறுவர். எடுத்துக்காட்டாக, 'காலில் சக்கரம் கட்டியவன்' என்பது வேகமாகச் செல்பவனையும், சக்கரம் பொருத்திய வாகனத்தில் செல்பவனையும் குறிக்கும்.

31. கீழ்க்கண்டவற்றுள் எது ஒரு கூட்டுச்சொல் (தொகைநிலைத் தொடர்) அல்ல?

  1. மலர்விழி
  2. தாமரைக்கண்
  3. கண்ணன் வந்தான்
  4. செங்காந்தள்

Answer: கண்ணன் வந்தான்

Explanation: தொகைநிலைத் தொடர்கள் என்பவை இரண்டு அல்லது அதற்கு மேற்பட்ட சொற்கள் இணைந்து ஒரு சொல்லாகவோ, ஒரு தொடராகவோ நின்று பொருள் தருவதாகும். 'மலர்விழி', 'தாமரைக்கண்', 'செங்காந்தள்' ஆகியவை தொகைநிலைத் தொடர்கள். 'கண்ணன் வந்தான்' என்பது ஒரு வினைமுற்றுத் தொடர், இது தொகைநிலைத் தொடர் அல்ல.

32. நன்னூலின்படி, எழுத்துக்களின் பிறப்பைப் பற்றி விளக்கும் இயல் எது?

  1. எழுத்தியல்
  2. சொல்லியல்
  3. பதவியல்
  4. புணரியல்

Answer: எழுத்தியல்

Explanation: நன்னூல் என்பது தமிழ் இலக்கண நூல். நன்னூலின் ஐந்து இயல்களில் எழுத்தியல், சொல்லியல், பதவியல், புணரியல், பொதுவியல் ஆகியவை அடங்கும். எழுத்தியல் எழுத்துக்களின் வகை, ஒலிப்பு முறை, பிறப்பு போன்றவற்றை விளக்குகிறது.

33. கீழ்க்கண்டவற்றுள் எது உரைநடையின் அணிகலன்களில் ஒன்றாகக் கருதப்படவில்லை?

  1. மோனை
  2. எதுகை
  3. உவமை
  4. சந்தம்

Answer: சந்தம்

Explanation: உரைநடையின் அணிகலன்கள் என்பது உரைநடையை அழகுபடுத்தும் உத்திகளைக் குறிக்கும். மோனை, எதுகை, உவமை, உருவகம், சிலேடை, முரண் போன்ற பல உத்திகள் உரைநடையின் அணிகலன்களாகும். சந்தம் என்பது பெரும்பாலும் செய்யுளுக்கு உரியது.

34. 'காற்றே வா!' என்ற கவிதையை எழுதியவர் யார்?

  1. பாரதியார்
  2. பாரதிதாசன்
  3. கண்ணதாசன்
  4. வாலி

Answer: பாரதியார்

Explanation: 'காற்றே வா!' என்ற கவிதையை எழுதியவர் மகாகவி சுப்பிரமணிய பாரதியார். இக்கவிதை இயற்கையை வாழ்த்திப் பாடும் ஒரு புதுக்கவிதை ஆகும். இது பாரதியாரின் கவிதை நடையின் சிறப்பம்சங்களில் ஒன்றாகும்.

35. கீழ்க்கண்டவற்றுள் 'அன்னையாய்' என்ற சொல்லின் இலக்கணக் குறிப்பு யாது?

  1. உவம உருபு
  2. வினைமுற்று
  3. பெயரெச்சம்
  4. வினையெச்சம்

Answer: உவம உருபு

Explanation: 'அன்னையாய்' என்ற சொல்லில் 'ஆய்' என்பது உவம உருபாகும். இது ஒரு பொருளை மற்றொரு பொருளுடன் ஒப்பிட்டுக் கூறப் பயன்படுகிறது. எடுத்துக்காட்டாக, 'மழைபோல் பொழிந்தான்' என்பதில் 'போல்' உவம உருபு.
