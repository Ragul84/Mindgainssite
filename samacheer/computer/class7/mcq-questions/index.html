26. Transistors replaced vacuum tubes in which generation of computers?

  1. First Generation
  2. Second Generation
  3. Third Generation
  4. Fourth Generation

Answer: Second Generation

Explanation: Transistors were introduced in the second generation of computers, making them smaller, faster, and more reliable.

27. Integrated Circuits (ICs) were a key development in which generation of computers?

  1. Second Generation
  2. Third Generation
  3. Fourth Generation
  4. Fifth Generation

Answer: Third Generation

Explanation: Integrated Circuits (ICs) were developed during the third generation, leading to further miniaturization and increased processing power.

28. Microprocessors, which contain the entire CPU on a single chip, are characteristic of which generation?

  1. Third Generation
  2. Fourth Generation
  3. Fifth Generation
  4. Sixth Generation

Answer: Fourth Generation

Explanation: The fourth generation of computers is defined by the development of the microprocessor.

29. The concept of Artificial Intelligence (AI) is most associated with which generation of computers?

  1. Third Generation
  2. Fourth Generation
  3. Fifth Generation
  4. Sixth Generation

Answer: Fifth Generation

Explanation: The fifth generation aims to develop computers with AI capabilities, including natural language processing and learning.

30. The Abacus is considered one of the earliest calculating tools. True or False?

  1. True
  2. False

Answer: True

Explanation: The Abacus is an ancient calculating tool used for arithmetic operations.

31. Ada Lovelace is credited with writing the first computer program. True or False?

  1. True
  2. False

Answer: True

Explanation: Ada Lovelace wrote an algorithm for Charles Babbage's Analytical Engine, considered the first computer program.

32. UNIVAC was the first commercially successful personal computer. True or False?

  1. True
  2. False

Answer: False

Explanation: UNIVAC (Universal Automatic Computer) was the first commercially produced computer, but not a personal computer.

33. The Jacquard Loom used punched cards to control patterns. True or False?

  1. True
  2. False

Answer: True

Explanation: The Jacquard Loom, invented in 1801, used punched cards to automate the weaving of complex patterns.

34. Match List I with List II: List I (Pioneer) A. Blaise Pascal B. Herman Hollerith C. Charles Babbage D. Ada Lovelace List II (Contribution) 1. Invented the Pascaline 2. Designed the Analytical Engine 3. Wrote the first computer program 4. Developed the tabulating machine for the US Census

  1. A-1, B-4, C-3, D-2
  2. A-1, B-4, C-2, D-3
  3. A-1, B-3, C-2, D-4
  4. A-2, B-4, C-1, D-3

Answer: A-1, B-4, C-2, D-3

Explanation: Pascal invented the Pascaline, Hollerith the census tabulating machine, Babbage designed the Analytical Engine and Ada Lovelace wrote the first computer program.

35. Match List I with List II: List I (Generation) A. Fourth generation B. First generation C. Second generation D. Third generation List II (Technology) 1. Vacuum Tubes 2. Transistors 3. Microprocessors 4. Integrated Circuits (ICs)

  1. A-2, B-1, C-3, D-4
  2. A-3, B-2, C-1, D-4
  3. A-3, B-1, C-2, D-4
  4. A-3, B-4, C-2, D-1

Answer: A-3, B-1, C-2, D-4

Explanation: First: vacuum tubes; second: transistors; third: integrated circuits; fourth: microprocessors.

36. Match List I with List II: List I (Device) A. Difference Engine B. Jacquard loom C. Abacus D. Pascaline List II (Description) 1. Ancient manual calculating tool 2. Mechanical calculator for addition and subtraction 3. Mechanical calculator for polynomial functions 4. Automated weaving using punched cards

  1. A-3, B-1, C-4, D-2
  2. A-2, B-4, C-1, D-3
  3. A-3, B-2, C-1, D-4
  4. A-3, B-4, C-1, D-2

Answer: A-3, B-4, C-1, D-2

Explanation: The Difference Engine computed polynomials, the Jacquard loom wove with punched cards, the abacus is an ancient manual tool and the Pascaline added and subtracted.

37. Which generation of computers is characterized by the widespread use of microprocessors?

  1. Second Generation
  2. Third Generation
  3. Fourth Generation
  4. Fifth Generation

Answer: Fourth Generation

Explanation: The fourth generation of computers is defined by the development and use of microprocessors.

38. The development of the World Wide Web is often associated with which era of computing?

  1. Second Generation
  2. Third Generation
  3. Fourth Generation
  4. Fifth Generation

Answer: Fourth Generation

Explanation: The World Wide Web emerged during the fourth generation of computers, enabled by advancements in networking and processing power.

39. Which of the following was NOT an early mechanical calculating device?

  1. Abacus
  2. Pascaline
  3. ENIAC
  4. Jacquard Loom

Answer: ENIAC

Explanation: ENIAC was an electronic computer, not a mechanical one.

40. The concept of stored programs, where instructions and data are held in the same memory, was a key innovation of which generation?

  1. First Generation
  2. Second Generation
  3. Third Generation
  4. Fourth Generation

Answer: Second Generation

Explanation: The stored-program concept, often attributed to John von Neumann, became prominent in the second generation.

41. What does WWW stand for?

  1. World Wide Web
  2. World Web Wide
  3. Wide World Web
  4. Web World Wide

Answer: World Wide Web

Explanation: WWW is an abbreviation for World Wide Web, a system of interlinked hypertext documents accessed via the Internet.

42. Which of the following is a web browser?

  1. Microsoft Word
  2. Google Chrome
  3. Adobe Photoshop
  4. VLC Media Player

Answer: Google Chrome

Explanation: Google Chrome is a popular web browser used to access websites.

43. What is the primary function of an Internet Service Provider (ISP)?

  1. To create websites
  2. To provide access to the Internet
  3. To develop software
  4. To sell computers

Answer: To provide access to the Internet

Explanation: An ISP connects users to the Internet and provides them with an IP address.

44. Which protocol is used to transfer files over the Internet?

  1. HTTP
  2. FTP
  3. SMTP
  4. POP3

Answer: FTP

Explanation: FTP (File Transfer Protocol) is specifically designed for transferring files between computers on a network.

45. What is an IP address?

  1. A username for websites
  2. A unique numerical label assigned to each device connected to a computer network
  3. A type of web browser
  4. A password for email

Answer: A unique numerical label assigned to each device connected to a computer network

Explanation: An IP address serves as an identifier for devices on a network, similar to a postal address for a house.

46. Which of these is a search engine?

  1. Facebook
  2. Wikipedia
  3. Bing
  4. Gmail

Answer: Bing

Explanation: Bing is a search engine that helps users find information on the World Wide Web.

47. What is email used for?

  1. Playing online games
  2. Sending and receiving messages electronically
  3. Watching videos
  4. Browsing social media

Answer: Sending and receiving messages electronically

Explanation: Email (Electronic Mail) is a method of exchanging messages between people using electronic devices.

48. What does URL stand for?

  1. Uniform Resource Locator
  2. Universal Resource Locator
  3. Uniform Record Locator
  4. Universal Record Locator

Answer: Uniform Resource Locator

Explanation: URL is the address of a resource on the internet, like a webpage.

49. Which of the following is a social networking site?

  1. Microsoft Excel
  2. Twitter
  3. Adobe Reader
  4. Notepad

Answer: Twitter

Explanation: Twitter is a social networking service where users post and interact with messages known as 'tweets'.

50. What is a firewall?

  1. A type of web browser
  2. A security system that monitors and controls incoming and outgoing network traffic
  3. A software for creating documents
  4. A tool for sending emails

Answer: A security system that monitors and controls incoming and outgoing network traffic

Explanation: A firewall acts as a barrier between a trusted internal network and untrusted external networks, such as the Internet.
