Class7 MCQs with answers

Use these 25 worked Class7 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 193 questions.

1. Which of the following is NOT a type of computer memory?

  1. RAM
  2. ROM
  3. CPU
  4. Cache

Answer: CPU

Explanation: CPU stands for Central Processing Unit and is not a type of memory.

2. What is the primary function of a computer's motherboard?

  1. Store data
  2. Process information
  3. Connect all hardware components
  4. Display graphics

Answer: Connect all hardware components

Explanation: The motherboard connects all the hardware components of a computer.

3. Which of the following is NOT a component of a computer system?

  1. CPU
  2. Monitor
  3. Printer
  4. Keyboard

Answer: Printer

Explanation: A printer is an external device and not a core component of a computer system.

4. What does RAM stand for in computer terminology?

  1. Random Access Memory
  2. Read-Only Memory
  3. Rapid Access Memory
  4. Remote Access Memory

Answer: Random Access Memory

Explanation: RAM stands for Random Access Memory, which is used for temporary data storage.

5. Which of the following is a programming language?

  1. JPEG
  2. Python
  3. MP3
  4. PDF

Answer: Python

Explanation: Python is a high-level programming language, while the others are file formats.

6. Which programming language is known for its use in web development?

  1. Java
  2. Python
  3. HTML
  4. C++

Answer: HTML

Explanation: HTML is a markup language used for creating web pages.

7. Which protocol is used for secure communication over a computer network?

  1. HTTP
  2. FTP
  3. HTTPS
  4. SMTP

Answer: HTTPS

Explanation: HTTPS (HyperText Transfer Protocol Secure) is used for secure communication over a computer network, encrypting the data exchanged.

8. What is the primary purpose of strong passwords in cyber safety?

  1. To make them difficult for others to guess or crack.
  2. To allow easy access for friends.
  3. To remember them easily.
  4. To share them with multiple people.

Answer: To make them difficult for others to guess or crack.

Explanation: Strong passwords are a crucial defense against unauthorized access to your accounts.

9. Which of the following is NOT a good practice for online privacy?

  1. Sharing personal information like your full address and phone number on public social media.
  2. Using different passwords for different online accounts.
  3. Being cautious about clicking on suspicious links.
  4. Reviewing privacy settings on social media platforms.

Answer: Sharing personal information like your full address and phone number on public social media.

Explanation: Sharing excessive personal information online can make you vulnerable to identity theft and other cyber threats.

10. What does 'phishing' refer to in cyber safety?

  1. A type of computer virus.
  2. An attempt to trick people into revealing sensitive information.
  3. A method of encrypting data.
  4. A way to securely store passwords.

Answer: An attempt to trick people into revealing sensitive information.

Explanation: Phishing attacks often impersonate legitimate organizations to steal personal and financial information.

11. Which of these is a sign of a potential phishing email?

  1. Generic greetings like 'Dear Customer'.
  2. Requests for urgent action or personal information.
  3. Poor grammar and spelling.
  4. All of the above.

Answer: All of the above.

Explanation: These are common indicators that an email might be a phishing attempt.

12. What is malware?

  1. Software designed to protect your computer.
  2. Software designed to harm or disrupt computer systems.
  3. A type of social media platform.
  4. A method for creating strong passwords.

Answer: Software designed to harm or disrupt computer systems.

Explanation: Malware is a broad term for malicious software, including viruses, worms, and spyware.

13. When downloading files from the internet, it is important to:

  1. Download from trusted and reputable websites.
  2. Download from any website without checking.
  3. Download only large files.
  4. Download files without an antivirus program.

Answer: Download from trusted and reputable websites.

Explanation: Downloading from untrusted sources increases the risk of encountering malware.

14. What is cyberbullying?

  1. Using computers to help others.
  2. Harassing or bullying someone using digital technologies.
  3. Learning about computer programming.
  4. Playing online games with friends.

Answer: Harassing or bullying someone using digital technologies.

Explanation: Cyberbullying can have serious emotional and psychological effects on victims.

15. If you encounter cyberbullying, what is the best course of action?

  1. Respond aggressively to the bully.
  2. Ignore it and hope it stops.
  3. Block the bully and report the behavior to a trusted adult or platform administrator.
  4. Join in with the bullying.

Answer: Block the bully and report the behavior to a trusted adult or platform administrator.

Explanation: Reporting and blocking are effective ways to address cyberbullying.

16. What does 'online footprint' refer to?

  1. The physical path you take online.
  2. The data you leave behind as you use the internet.
  3. The speed of your internet connection.
  4. The number of websites you visit.

Answer: The data you leave behind as you use the internet.

Explanation: Your online footprint includes everything you post, share, and do online.

17. It is important to be mindful of your online footprint because:

  1. It can affect future opportunities like college admissions or job applications.
  2. It helps you remember your passwords.
  3. It makes your internet faster.
  4. It is only visible to you.

Answer: It can affect future opportunities like college admissions or job applications.

Explanation: Employers and educational institutions often review online presence.

18. Using a public Wi-Fi network is generally considered less secure than a private network.

  1. True
  2. False

Answer: True

Explanation: Public Wi-Fi can be more vulnerable to interception of data.

19. It is safe to share your social security number or bank account details in an online chat with someone you just met.

  1. True
  2. False

Answer: False

Explanation: Never share sensitive personal or financial information online with strangers.

20. Keeping your software and operating system updated is a good cyber safety practice.

  1. True
  2. False

Answer: True

Explanation: Updates often include security patches that fix vulnerabilities.

21. Match List I with List II: List I (Term) A. Encryption B. Firewall C. Antivirus List II (Definition) 1. Scrambles data to make it unreadable 2. Monitors and controls network traffic 3. Protects against malware

  1. A-1, B-2, C-3
  2. A-3, B-2, C-1
  3. A-2, B-1, C-3
  4. A-1, B-3, C-2

Answer: A-1, B-2, C-3

Explanation: Encryption scrambles data, a firewall monitors and controls network traffic and antivirus software protects against malware.

22. What was the first mechanical calculating device invented by Blaise Pascal?

  1. Abacus
  2. Pascaline
  3. Difference Engine
  4. Analytical Engine

Answer: Pascaline

Explanation: The Pascaline was a mechanical calculator invented by Blaise Pascal in 1642.

23. Who is considered the 'Father of the Computer' for his work on the Analytical Engine?

  1. Charles Babbage
  2. Alan Turing
  3. John von Neumann
  4. Blaise Pascal

Answer: Charles Babbage

Explanation: Charles Babbage designed the Analytical Engine, a mechanical general-purpose computer, and is thus known as the 'Father of the Computer'.

24. The first electronic digital computer was called:

  1. ENIAC
  2. UNIVAC
  3. Mark I
  4. Colossus

Answer: ENIAC

Explanation: ENIAC (Electronic Numerical Integrator and Computer) was the first general-purpose electronic digital computer.

25. Which generation of computers used vacuum tubes as the primary component?

  1. First Generation
  2. Second Generation
  3. Third Generation
  4. Fourth Generation

Answer: First Generation

Explanation: First-generation computers (1940s-1950s) relied on vacuum tubes for circuitry.
