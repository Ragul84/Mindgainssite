Class11 MCQs with answers

Use these 25 worked Class11 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 506 questions.

1. What is the primary purpose of using indentation in Python?

  1. To reduce code length
  2. To improve code readability
  3. To increase execution speed
  4. To decrease memory usage

Answer: To improve code readability

Explanation: Indentation in Python is used to define the structure of the code, making it more readable and understandable. It helps in distinguishing between different blocks of code, such as loops and conditional statements.

2. Which data structure follows the LIFO principle?

  1. Queue
  2. Stack
  3. Tree
  4. Graph

Answer: Stack

Explanation: A stack is a linear data structure that follows the Last-In-First-Out (LIFO) principle, meaning the last element added to the stack will be the first one to be removed. This principle is used in many algorithms and programming applications.

3. What is the purpose of the SELECT statement in SQL?

  1. To insert data into a table
  2. To update data in a table
  3. To delete data from a table
  4. To retrieve data from a table

Answer: To retrieve data from a table

Explanation: The SELECT statement in SQL is used to retrieve specific data from a database table, allowing users to filter and manipulate the data as needed. It is a fundamental command in SQL and is used extensively in database queries.

4. Which networking protocol is responsible for resolving domain names to IP addresses?

  1. HTTP
  2. FTP
  3. DNS
  4. TCP

Answer: DNS

Explanation: The Domain Name System (DNS) protocol is responsible for resolving domain names to IP addresses, allowing users to access websites and other online resources using easy-to-remember domain names instead of difficult-to-remember IP addresses. This protocol is essential for the proper functioning of the internet.

5. What is the main advantage of using object-oriented programming (OOP) concepts?

  1. Improved code readability
  2. Increased execution speed
  3. Enhanced security features
  4. Better code reusability

Answer: Better code reusability

Explanation: The main advantage of using OOP concepts is better code reusability, as it allows developers to create modular and reusable code that can be easily maintained and extended. This leads to more efficient and effective software development.

6. Which Python data type is used to store a collection of unique values?

  1. List
  2. Tuple
  3. Set
  4. Dictionary

Answer: Set

Explanation: A set in Python is an unordered collection of unique values, meaning it does not allow duplicate values and is used to store a collection of distinct elements. Sets are useful in various applications, such as data analysis and algorithm development.

7. What is the purpose of the COMMIT statement in SQL?

  1. To save changes to a database
  2. To discard changes to a database
  3. To create a new database
  4. To delete a database

Answer: To save changes to a database

Explanation: The COMMIT statement in SQL is used to save changes to a database, making them permanent and visible to other users. This statement is essential in database transactions, as it ensures data consistency and integrity.

8. Which networking device is used to connect multiple devices to a network?

  1. Router
  2. Switch
  3. Hub
  4. Modem

Answer: Switch

Explanation: A switch is a networking device that connects multiple devices to a network, allowing them to communicate with each other and share resources. Switches are commonly used in local area networks (LANs) and are essential for network connectivity.

9. What is the difference between a class and an object in OOP?

  1. A class is an instance of an object
  2. An object is an instance of a class
  3. A class is a collection of objects
  4. An object is a collection of classes

Answer: An object is an instance of a class

Explanation: In OOP, a class is a blueprint or template that defines the properties and behavior of an object, while an object is an instance of a class, representing a specific entity with its own set of attributes and methods. This distinction is fundamental to understanding OOP concepts.

10. Which Python concept is used to hide the implementation details of an object from the outside world?

  1. Encapsulation
  2. Abstraction
  3. Inheritance
  4. Polymorphism

Answer: Encapsulation

Explanation: Encapsulation in Python is the concept of hiding the implementation details of an object from the outside world, making it difficult for other objects to access or modify its internal state directly. This helps in improving code security and reducing coupling between objects.

11. What is the purpose of the ROLLBACK statement in SQL?

  1. To save changes to a database
  2. To discard changes to a database
  3. To create a new database
  4. To delete a database

Answer: To discard changes to a database

Explanation: The ROLLBACK statement in SQL is used to discard changes to a database, restoring it to its previous state. This statement is essential in database transactions, as it allows users to undo changes and maintain data consistency.

12. Which data structure is used to store a collection of key-value pairs?

  1. Array
  2. List
  3. Dictionary
  4. Set

Answer: Dictionary

Explanation: A dictionary in Python is a data structure that stores a collection of key-value pairs, allowing users to access and manipulate data using unique keys. Dictionaries are useful in various applications, such as data analysis and algorithm development.

13. What is the term for a database that stores data in tables with well-defined relationships?

  1. Relational database
  2. Object-oriented database
  3. Hierarchical database
  4. Network database

Answer: Relational database

Explanation: A relational database is a type of database that stores data in tables with well-defined relationships between them, allowing for efficient querying and data retrieval. This is a key concept in database design.

14. Which networking protocol is responsible for assigning IP addresses to devices on a network?

  1. HTTP
  2. FTP
  3. DHCP
  4. TCP

Answer: DHCP

Explanation: The Dynamic Host Configuration Protocol (DHCP) is a networking protocol that assigns IP addresses to devices on a network, allowing them to communicate with each other. This protocol is essential for network configuration and management.

15. What is the concept of encapsulation in object-oriented programming?

  1. Hiding data from external access
  2. Exposing data to external access
  3. Inheriting properties from a parent class
  4. Polymorphic behavior

Answer: Hiding data from external access

Explanation: Encapsulation is the concept of hiding data from external access and only allowing it to be accessed through controlled methods, which helps to protect the data and prevent unauthorized changes. This is a fundamental principle of object-oriented programming.

16. Which Python data type is an unordered collection of unique elements?

  1. List
  2. Tuple
  3. Set
  4. Dictionary

Answer: Set

Explanation: A set is an unordered collection of unique elements in Python, which means that it does not allow duplicate values and does not maintain a specific order. This data type is useful for storing and manipulating collections of distinct elements.

17. What is the purpose of the 'self' parameter in a Python class method?

  1. To refer to the class itself
  2. To refer to the instance of the class
  3. To refer to the parent class
  4. To refer to the current method

Answer: To refer to the instance of the class

Explanation: The 'self' parameter in a Python class method refers to the instance of the class, allowing the method to access and modify the instance's attributes. This is a key concept in object-oriented programming in Python.

18. Which database constraint ensures that a column contains unique values?

  1. Primary key
  2. Foreign key
  3. Unique constraint
  4. Check constraint

Answer: Unique constraint

Explanation: A unique constraint is a database constraint that ensures that a column contains unique values, preventing duplicate values from being inserted. This constraint is essential for maintaining data integrity.

19. What is the term for a network that spans a large geographic area, such as a city or country?

  1. LAN
  2. WAN
  3. MAN
  4. WLAN

Answer: WAN

Explanation: A wide area network (WAN) is a network that spans a large geographic area, such as a city or country, and is typically used to connect multiple local area networks (LANs) together. This type of network is essential for providing internet access and other network services over long distances.

20. Which Python concept allows for multiple inheritance?

  1. Classes
  2. Objects
  3. Inheritance
  4. Polymorphism

Answer: Inheritance

Explanation: Inheritance is the Python concept that allows for multiple inheritance, where a child class can inherit properties and methods from multiple parent classes. This concept is useful for creating complex class hierarchies and promoting code reuse.

21. What is the purpose of the 'finally' block in a Python try-except statement?

  1. To catch exceptions
  2. To handle exceptions
  3. To execute code regardless of exceptions
  4. To skip exceptions

Answer: To execute code regardless of exceptions

Explanation: The 'finally' block in a Python try-except statement is used to execute code regardless of whether an exception was thrown or not, allowing for cleanup and resource release. This block is essential for ensuring that resources are properly released and that the program remains in a consistent state.

22. Which data structure is suitable for implementing a browser's history feature?

  1. Stack
  2. Queue
  3. Tree
  4. Graph

Answer: Stack

Explanation: A stack is a suitable data structure for implementing a browser's history feature, as it allows for efficient addition and removal of pages in the order they were visited. This data structure follows the LIFO principle, which is ideal for implementing a browser's back and forward buttons.

23. Who is considered to be the father of computer?

  1. Alan Turing
  2. Charles Babbage
  3. Blaise Pascal
  4. John von Neumann

Answer: Charles Babbage

Explanation: Charles Babbage is considered the father of computer for his invention of the Analytical Engine.

24. In which year was the concept of the Analytical Engine introduced?

  1. 1827
  2. 1837
  3. 1847
  4. 1857

Answer: 1837

Explanation: The Analytical Engine was introduced in 1837.

25. Which of the following was NOT a component of the Analytical Engine?

  1. Arithmetic Logic Unit (ALU)
  2. Basic flow control
  3. Integrated memory
  4. Vacuum Tubes

Answer: Vacuum Tubes

Explanation: The Analytical Engine contained ALU, basic flow control, and integrated memory; vacuum tubes belong to first generation computers.
