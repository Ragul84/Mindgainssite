26. The Analytical Engine led to the development of which concept?

45. Match the following: List I A. Father of Computer B. First Generation C. First Calculating Device D. Analytical Engine Year List II 1. Abacus 2. Vacuum Tubes 3. Charles Babbage 4. 1837

46. Match List I with List II: List I (Analytical Engine part) A. Punched-card control B. The Mill C. The Store List II (Role) 1. Basic flow control 2. Integrated memory 3. Arithmetic Logic Unit

  2. A-1, B-3, C-2
  3. A-1, B-2, C-3
  4. A-3, B-1, C-2

Answer: A-1, B-3, C-2

Explanation: Babbage's Analytical Engine was controlled by punched cards, did arithmetic in the Mill (like an ALU) and held numbers in the Store (memory).
