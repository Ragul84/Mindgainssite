Class6 MCQs with answers

26. Which of these is an output device?

  1. Mouse
  2. Scanner
  3. Monitor
  4. Microphone

Answer: Monitor

Explanation: A monitor displays information from the computer.

27. What is the primary function of RAM?

  1. Long-term storage
  2. Temporary storage for active programs
  3. Processing data
  4. Displaying graphics

Answer: Temporary storage for active programs

Explanation: RAM (Random Access Memory) holds data that the CPU is actively using.

28. Which component stores data permanently, even when the computer is turned off?

  1. RAM
  2. CPU
  3. Hard Disk Drive
  4. Motherboard

Answer: Hard Disk Drive

Explanation: Hard Disk Drives (HDD) or Solid State Drives (SSD) provide permanent storage.

29. A computer program is a set of instructions that tells the computer what to do.

  1. True
  2. False

Answer: True

Explanation: This is the definition of a computer program.

30. The operating system is a type of software that manages computer hardware and software resources.

  1. True
  2. False

Answer: True

Explanation: Operating systems like Windows or macOS manage the computer's functions.

31. A computer can think and make decisions on its own.

  1. True
  2. False

Answer: False

Explanation: Computers follow instructions and do not possess independent thought or decision-making capabilities.

32. Match the computer component with its function: List I A. Keyboard B. Monitor C. CPU List II 1. Input device 2. Output device 3. Processing unit

  1. A-2, B-1, C-3
  2. A-1, B-3, C-2
  3. A-3, B-2, C-1
  4. A-1, B-2, C-3

Answer: A-1, B-2, C-3

Explanation: Keyboard – Input device; Monitor – Output device; CPU – Processing unit.

33. Match List I with List II: List I (Category) A. System software B. Operating system C. Application software List II (Example) 1. Device Driver 2. Windows 3. Word Processor

  1. A-1, B-2, C-3
  2. A-3, B-2, C-1
  3. A-2, B-1, C-3
  4. A-1, B-3, C-2

Answer: A-1, B-2, C-3

Explanation: A device driver is system software, Windows is an operating system and a word processor is application software.

34. Which of the following is NOT a computer hardware component?

  1. Hard Drive
  2. Operating System
  3. Motherboard
  4. RAM

Answer: Operating System

Explanation: The Operating System is software, not hardware.

35. Which of the following is an example of application software?

  1. Windows
  2. Linux
  3. Microsoft Word
  4. macOS

Answer: Microsoft Word

Explanation: Microsoft Word is an application used for word processing, while the others are operating systems.

36. What is the term for the physical parts of a computer that you can touch?

  1. Software
  2. Hardware
  3. Firmware
  4. Malware

Answer: Hardware

Explanation: Hardware refers to the physical components of a computer.

37. Which of the following is a storage device?

  1. Printer
  2. Scanner
  3. Speaker
  4. Hard Disk

Answer: Hard Disk

Explanation: A Hard Disk is used to store data.

38. Which of the following is a device used to input text and numbers into a computer?

  1. Monitor
  2. Keyboard
  3. Printer
  4. Webcam

Answer: Keyboard

Explanation: A keyboard is the primary device for inputting text and numbers.

39. Which of the following is the default extension for a PowerPoint 2010 presentation file?

  1. .pptx
  2. .docx
  3. .xlsx
  4. .txt

Answer: .pptx

Explanation: .pptx is the standard file extension for PowerPoint presentations.

40. Which view is used to see all slides of a presentation in a miniature form?

  1. Normal View
  2. Slide Sorter View
  3. Reading View
  4. Notes Page View

Answer: Slide Sorter View

Explanation: Slide Sorter view displays all slides as thumbnails for easy reorganization.

41. Which key is used to start a slide show from the first slide?

  1. F1
  2. F2
  3. F5
  4. F7

Answer: F5

Explanation: Pressing F5 starts the presentation from the beginning.

42. What is the basic unit of a PowerPoint presentation called?

  1. Page
  2. Sheet
  3. Slide
  4. Document

Answer: Slide

Explanation: A presentation consists of a series of individual pages called slides.

43. Which tab contains the option to insert a Table or Chart?

  1. Home
  2. Insert
  3. Design
  4. Animations

Answer: Insert

Explanation: The Insert tab allows users to add various objects like tables, images, and charts.

44. Which feature is used to apply a consistent look to all slides in a presentation?

  1. Transitions
  2. Animations
  3. Themes
  4. Layouts

Answer: Themes

Explanation: Themes provide a predefined combination of colors, fonts, and effects.

45. What is the purpose of 'Slide Transition'?

  1. Moving objects on a slide
  2. The visual effect when moving from one slide to another
  3. Changing the font style
  4. Saving the file

Answer: The visual effect when moving from one slide to another

Explanation: Transitions are motion effects that occur when you move from one slide to the next.

46. Which of these is NOT a valid slide layout in PowerPoint?

  1. Title Slide
  2. Comparison
  3. Two Content
  4. Spreadsheet Grid

Answer: Spreadsheet Grid

Explanation: Spreadsheet Grid is not a standard slide layout; it is a feature of Excel.

47. Which option allows you to add motion effects to individual objects on a slide?

  1. Transitions
  2. Animations
  3. Design
  4. Review

Answer: Animations

Explanation: Animations are applied to specific elements like text or images on a slide.

48. Statement 1: PowerPoint is a word processing software. Statement 2: PowerPoint is used for creating visual presentations.

  1. Both are correct
  2. Both are incorrect
  3. Only Statement 1 is correct
  4. Only Statement 2 is correct

Answer: Only Statement 2 is correct

Explanation: PowerPoint is presentation software, not word processing software (which is MS Word).

49. Statement 1: You can insert audio files into a slide. Statement 2: You cannot insert video files into a slide.

  1. Both are correct
  2. Both are incorrect
  3. Only Statement 1 is correct
  4. Only Statement 2 is correct

Answer: Only Statement 1 is correct

Explanation: PowerPoint supports both audio and video insertions.

50. The Slide Master is used to set the default layout and style for all slides.

  1. True
  2. False

Answer: True

Explanation: Slide Master controls the global look of the presentation.
