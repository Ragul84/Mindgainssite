Samacheer Computer Science practice

Class6 MCQs with answers

Use these 25 worked Class6 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 134 questions.

1. Which of the following is a type of computer memory?

  1. RAM
  2. CPU
  3. GPU
  4. USB

Answer: RAM

Explanation: RAM (Random Access Memory) is a type of computer memory that stores data temporarily for quick access.

2. Which of the following is NOT a component of a computer system?

  1. Monitor
  2. Keyboard
  3. Printer
  4. Electricity

Answer: Electricity

Explanation: Electricity is not a component of a computer system; it is a power source required for the system to function.

3. Which device is used to input data into a computer?

  1. Monitor
  2. Printer
  3. Keyboard
  4. Speaker

Answer: Keyboard

Explanation: A keyboard is an input device used to enter data into a computer.

4. True or False: A printer is an input device.

  1. True
  2. False

Answer: False

Explanation: A printer is an output device, not an input device.

5. Which programming language is commonly used for web development?

  1. Python
  2. Java
  3. HTML
  4. C++

Answer: HTML

Explanation: HTML is a markup language specifically designed for creating web pages.

6. Which of the following is an input device?

  1. Monitor
  2. Keyboard
  3. Printer
  4. Speaker

Answer: Keyboard

Explanation: A keyboard is used to enter data into the computer.

7. Which of the following is an output device?

  1. Mouse
  2. Microphone
  3. Printer
  4. Scanner

Answer: Printer

Explanation: A printer produces a hard copy of the output.

8. The main circuit board of a computer is called the:

  1. Hard Drive
  2. RAM
  3. Motherboard
  4. CPU

Answer: Motherboard

Explanation: The motherboard connects all the main components of the computer.

9. Which component performs most of the processing in a computer?

  1. RAM
  2. Hard Drive
  3. CPU
  4. Monitor

Answer: CPU

Explanation: CPU stands for Central Processing Unit, which is the brain of the computer.

10. What is software?

  1. Physical parts of the computer
  2. Instructions that tell the computer what to do
  3. A type of input device
  4. A storage device

Answer: Instructions that tell the computer what to do

Explanation: Software refers to the programs and operating information used by a computer.

11. Which of these is an example of system software?

  1. Microsoft Word
  2. Google Chrome
  3. Windows Operating System
  4. Adobe Photoshop

Answer: Windows Operating System

Explanation: The operating system manages the computer's hardware and software resources.

12. Which of these is an example of application software?

  1. Linux
  2. macOS
  3. Calculator
  4. BIOS

Answer: Calculator

Explanation: Application software is designed to perform specific tasks for the user.

13. What does RAM stand for?

  1. Read Access Memory
  2. Random Access Memory
  3. Real Access Memory
  4. Run Access Memory

Answer: Random Access Memory

Explanation: RAM is a type of computer memory that can be read and changed in any order.

14. Which device is used to store data permanently?

  1. RAM
  2. Monitor
  3. Hard Drive
  4. Keyboard

Answer: Hard Drive

Explanation: A hard drive (or SSD) stores data even when the computer is turned off.

15. A mouse is an input device.

  1. True
  2. False

Answer: True

Explanation: A mouse is used to control the cursor and make selections on the screen.

16. A printer is an input device.

  1. True
  2. False

Answer: False

Explanation: A printer is an output device that produces hard copies.

17. The operating system is a type of application software.

  1. True
  2. False

Answer: False

Explanation: The operating system is system software, not application software.

18. Match List I with List II: List I (Hardware) A. Keyboard B. CPU C. Monitor List II (Function) 1. Output device to display visuals 2. Processes instructions 3. Input device for typing text

  1. A-3, B-1, C-2
  2. A-3, B-2, C-1
  3. A-2, B-3, C-1
  4. A-1, B-2, C-3

Answer: A-3, B-2, C-1

Explanation: The keyboard is an input device for typing, the CPU processes instructions and the monitor displays output.

19. Match List I with List II: List I (Category) A. Application software B. Hardware (input device) C. System software (operating system) List II (Example) 1. Windows 2. Microphone 3. Paint

  1. A-2, B-3, C-1
  2. A-3, B-1, C-2
  3. A-3, B-2, C-1
  4. A-1, B-2, C-3

Answer: A-3, B-2, C-1

Explanation: Paint is application software, a microphone is an input device and Windows is an operating system.

20. Match List I with List II: List I (Storage device) A. Pen drive B. RAM C. Hard disk List II (Characteristic) 1. Temporary storage 2. Portable storage 3. Permanent storage

  1. A-3, B-1, C-2
  2. A-1, B-2, C-3
  3. A-2, B-3, C-1
  4. A-2, B-1, C-3

Answer: A-2, B-1, C-3

Explanation: A pen drive is portable, RAM is temporary and a hard disk stores data permanently.

21. Which of the following are both hardware and software?

  1. Keyboard and Mouse
  2. Operating System and Application Software
  3. CPU and RAM
  4. None of the above

Answer: None of the above

Explanation: Hardware are physical parts, and software are instructions. No single option lists both types.

22. Consider the following statements: 1. A scanner is an output device. 2. A speaker is an output device. Which statement(s) is/are correct?

  1. Only 1
  2. Only 2
  3. Both 1 and 2
  4. Neither 1 nor 2

Answer: Only 2

Explanation: A scanner is an input device. A speaker is an output device.

23. Which of the following is an electronic device that accepts data, processes it, and produces output?

  1. Computer
  2. Calculator
  3. Television
  4. Radio

Answer: Computer

Explanation: A computer is an electronic device that performs these functions.

24. What does CPU stand for?

  1. Central Processing Unit
  2. Computer Personal Unit
  3. Central Personal Unit
  4. Computer Processing Unit

Answer: Central Processing Unit

Explanation: CPU is the abbreviation for Central Processing Unit, the brain of the computer.

25. Which of these is an input device?

  1. Monitor
  2. Keyboard
  3. Printer
  4. Speaker

Answer: Keyboard

Explanation: A keyboard is used to enter data into the computer.
