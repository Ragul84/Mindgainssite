Class10 MCQs with answers

Use these 25 worked Class10 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 254 questions.

1. What is the primary function of the CPU?

  1. To store data
  2. To provide input/output
  3. To perform calculations
  4. To connect hardware

Answer: To perform calculations

Explanation: The CPU, or Central Processing Unit, is responsible for executing instructions and performing calculations. It acts as the brain of the computer, handling all the data processing tasks.

2. Which of the following is a type of software?

  1. Motherboard
  2. Keyboard
  3. MS Office
  4. Mouse

Answer: MS Office

Explanation: MS Office is an example of application software, which is used to perform specific tasks. It provides a set of tools for creating documents, spreadsheets, and presentations.

3. What does HTTP stand for?

  1. Hyper Text Transfer Protocol
  2. Hyper Text Transfer Procedure
  3. High Transfer Text Protocol
  4. High Transfer Text Procedure

Answer: Hyper Text Transfer Protocol

Explanation: HTTP, or Hyper Text Transfer Protocol, is a protocol used for transferring data over the internet. It is the foundation of data communication on the web, allowing devices to communicate with each other.

4. Which algorithm is used for finding the shortest path between two nodes?

  1. Bubble sort
  2. Selection sort
  3. Dijkstra's algorithm
  4. Merge sort

Answer: Dijkstra's algorithm

Explanation: Dijkstra's algorithm is a graph search algorithm that finds the shortest path between two nodes in a graph. It is commonly used in GPS navigation systems and network routing protocols.

5. What is the purpose of a firewall?

  1. To protect against viruses
  2. To block unwanted network traffic
  3. To improve computer performance
  4. To provide backup power

Answer: To block unwanted network traffic

Explanation: A firewall is a network security system that monitors and controls incoming and outgoing network traffic. It helps to prevent unauthorized access to a computer or network, blocking malicious traffic and protecting against cyber threats.

6. Which programming concept is used to repeat a set of instructions?

  1. Conditional statement
  2. Loop
  3. Function
  4. Array

Answer: Loop

Explanation: A loop is a programming concept that allows a set of instructions to be repeated for a specified number of times. It is commonly used to perform tasks that require iteration, such as counting or searching.

7. What is the term for a temporary storage area where data is held while it is being processed?

  1. Register
  2. Cache
  3. Buffer
  4. Memory

Answer: Buffer

Explanation: A buffer is a temporary storage area that holds data while it is being processed or transferred. It acts as a holding area, allowing data to be stored temporarily while it is being processed or transmitted.

8. Which of the following is an example of a database management system?

  1. MS Word
  2. MS Excel
  3. MS Access
  4. MS PowerPoint

Answer: MS Access

Explanation: MS Access is an example of a database management system, which is used to store, manage, and analyze data. It provides a set of tools for creating and managing databases, allowing users to store and retrieve data efficiently.

9. What does ISP stand for?

  1. Internet Service Provider
  2. Internet Security Protocol
  3. Internet Search Protocol
  4. Internet Speed Protocol

Answer: Internet Service Provider

Explanation: ISP, or Internet Service Provider, is a company that provides access to the internet. It offers a range of services, including internet connectivity, email, and web hosting.

10. Which of the following is a type of malware?

  1. Virus
  2. Worm
  3. Trojan
  4. All of the above

Answer: All of the above

Explanation: Malware, or malicious software, includes a range of threats such as viruses, worms, and trojans. These types of malware can cause harm to a computer or network, stealing data, disrupting operations, or causing other types of damage.

11. What is the purpose of an operating system?

  1. To provide a platform for running applications
  2. To manage hardware resources
  3. To provide security and networking capabilities
  4. All of the above

Answer: All of the above

Explanation: An operating system is a software that manages computer hardware resources and provides a platform for running applications. It also provides security and networking capabilities, allowing users to interact with the computer and access network resources.

12. Which of the following is a benefit of using a spreadsheet?

  1. To create documents
  2. To manage databases
  3. To perform calculations and data analysis
  4. To create presentations

Answer: To perform calculations and data analysis

Explanation: A spreadsheet is a software application that allows users to perform calculations and data analysis. It provides a range of tools for managing and analyzing data, making it an essential tool for business and personal use.

13. What is the term for a set of instructions that a computer can execute?

  1. Algorithm
  2. Program
  3. Software
  4. Hardware

Answer: Program

Explanation: A program is a set of instructions that a computer can execute, which is used to perform a specific task. It can be written in a variety of programming languages, such as Java, Python, or C++.

14. Which software is used to create and edit spreadsheets?

  1. MS Word
  2. MS Excel
  3. MS Access
  4. MS PowerPoint

Answer: MS Excel

Explanation: MS Excel is a spreadsheet software that allows users to create, edit, and manipulate data in a tabular format. It provides various tools and functions for data analysis and calculation.

15. Which internet protocol is used to send and receive email?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP/IP

Answer: SMTP

Explanation: SMTP, or Simple Mail Transfer Protocol, is used to send and receive email between email servers. It allows users to send and receive email messages over the internet.

16. What is the purpose of the IF statement in programming?

  1. To repeat a set of instructions
  2. To skip a set of instructions
  3. To make decisions based on conditions
  4. To declare variables

Answer: To make decisions based on conditions

Explanation: The IF statement is used to make decisions based on conditions, allowing the program to execute different blocks of code depending on whether the condition is true or false. It is a fundamental control structure in programming.

17. Which MS Office application is used to create presentations?

  1. MS Word
  2. MS Excel
  3. MS PowerPoint
  4. MS Access

Answer: MS PowerPoint

Explanation: MS PowerPoint is a presentation software that allows users to create, edit, and display slide-based presentations. It provides various tools and features for creating engaging and informative presentations.

18. What is the purpose of a firewall in computer security?

  1. To protect against viruses
  2. To encrypt data
  3. To block unauthorized access
  4. To improve network performance

Answer: To block unauthorized access

Explanation: A firewall is a network security system that monitors and controls incoming and outgoing network traffic, blocking unauthorized access to the computer or network. It acts as a barrier between the computer or network and the internet, protecting against malicious attacks and unauthorized access.

19. Which internet service is used to transfer files between computers?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP/IP

Answer: FTP

Explanation: FTP, or File Transfer Protocol, is an internet service that allows users to transfer files between computers over the internet. It provides a secure and efficient way to upload and download files between remote computers.

20. What is the term for a set of rules that govern the behavior of an algorithm?

  1. Syntax
  2. Semantics
  3. Logic
  4. Protocol

Answer: Semantics

Explanation: Semantics refers to the set of rules that govern the behavior of an algorithm, defining the meaning and interpretation of the instructions and data. It provides a framework for understanding how the algorithm works and how it produces the desired output.

21. Which MS Office application is used to manage and analyze databases?

  1. MS Word
  2. MS Excel
  3. MS Access
  4. MS PowerPoint

Answer: MS Access

Explanation: MS Access is a database management system that allows users to create, edit, and manage databases, providing tools and features for data analysis and reporting. It is commonly used to store and manage large amounts of data, such as customer information or inventory records.

22. Which MS Office application is used for creating presentations?

  1. Word
  2. Excel
  3. Access
  4. PowerPoint

Answer: PowerPoint

Explanation: PowerPoint is a presentation program that allows users to create slides, add text and images, and create presentations. It is widely used for creating interactive and engaging presentations.

23. What is the term for a set of instructions that a computer follows to solve a problem?

  1. Algorithm
  2. Program
  3. Software
  4. Hardware

Answer: Algorithm

Explanation: An algorithm is a well-defined procedure that takes some input and produces a corresponding output, making it a set of instructions that a computer follows to solve a problem. It is a step-by-step procedure for solving a problem or achieving a particular goal.

24. Which internet protocol is used for sending and receiving email?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP/IP

Answer: SMTP

Explanation: SMTP (Simple Mail Transfer Protocol) is a protocol used for sending and receiving email, allowing email clients to communicate with email servers. It is responsible for transferring email messages between email servers and clients.

25. What is the term for a small program that performs a specific task?

  1. Script
  2. Program
  3. Application
  4. Utility

Answer: Script

Explanation: A script is a small program that performs a specific task, such as automating a process or performing a calculation. It is typically written in a scripting language, such as Python or JavaScript.
