26. Which programming concept is used to repeat a set of instructions?

  1. Loop
  2. Conditional statement
  3. Function
  4. Variable

Answer: Loop

Explanation: A loop is a programming concept that allows a set of instructions to be repeated for a specified number of times, or until a certain condition is met. It is a fundamental concept in programming and is used in a wide range of applications.

27. What is the term for a temporary storage area where data is held while it is being processed?

  1. Register
  2. Cache
  3. Buffer
  4. Memory

Answer: Buffer

Explanation: A buffer is a temporary storage area where data is held while it is being processed, and is used to improve the performance and efficiency of a system. It acts as a holding area for data that is being transferred between devices or systems.

28. Which MS Office application is used for creating and editing spreadsheets?

  1. Word
  2. Excel
  3. Access
  4. Publisher

Answer: Excel

Explanation: Excel is a spreadsheet program that allows users to create and edit spreadsheets, and is widely used for data analysis and calculation. It provides a range of tools and features for working with data, including formulas, charts, and pivot tables.

29. Which programming paradigm is based on the concept of objects and classes?

  1. Procedural programming
  2. Object-oriented programming
  3. Functional programming
  4. Event-driven programming

Answer: Object-oriented programming

Explanation: Object-oriented programming is a programming paradigm that is based on the concept of objects and classes, and is used to design and develop software systems that are modular, reusable, and maintainable. It provides a range of features, including encapsulation, inheritance, and polymorphism.

30. What is the term for a program that is used to manage and interact with a database?

  1. Database management system
  2. Word processor
  3. Spreadsheet program
  4. Presentation program

Answer: Database management system

Explanation: A database management system is a program that is used to manage and interact with a database, and provides a range of features for creating, modifying, and querying data. It acts as an interface between the user and the database, and provides a range of tools and features for working with data.

31. Which internet protocol is used for transferring files over the internet?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP/IP

Answer: FTP

Explanation: FTP, or File Transfer Protocol, is a protocol that is used for transferring files over the internet, and provides a range of features for uploading and downloading files. It is widely used for transferring files between computers and servers over the internet.

32. Which of the following is a type of software that manages computer hardware resources?

  1. Application software
  2. System software
  3. Utility software
  4. Malware

Answer: System software

Explanation: System software manages computer hardware resources and provides a platform for running application software. It includes operating systems, device drivers, and utility programs that manage computer resources.

33. What is the purpose of the algorithm in programming?

  1. To write code
  2. To design graphics
  3. To solve problems
  4. To connect to the internet

Answer: To solve problems

Explanation: An algorithm is a set of instructions used to solve a specific problem or perform a particular task in programming. It provides a step-by-step procedure for achieving a desired outcome.

34. Which Microsoft Office application is used for creating presentations?

  1. Microsoft Word
  2. Microsoft Excel
  3. Microsoft PowerPoint
  4. Microsoft Access

Answer: Microsoft PowerPoint

Explanation: Microsoft PowerPoint is a presentation software application used to create slides, add text and images, and create engaging presentations. It is widely used in educational and professional settings.

35. What is the term for a network of interconnected computers that share resources?

  1. Intranet
  2. Internet
  3. Extranet
  4. Local Area Network

Answer: Internet

Explanation: The internet is a global network of interconnected computers that share resources, including websites, email, and file transfer. It is a public network that allows users to access and share information worldwide.

36. Which of the following is a basic programming concept?

  1. Variables
  2. Functions
  3. Loops
  4. All of the above

Answer: All of the above

Explanation: Variables, functions, and loops are all basic programming concepts used to write code and create programs. They provide the building blocks for programming and are used to store data, perform tasks, and control program flow.

37. What is the term for a small program that performs a specific task?

  1. Application
  2. Utility
  3. Script
  4. Applet

Answer: Utility

Explanation: A utility is a small program that performs a specific task, such as formatting a disk or scanning for viruses. It is a type of software that provides a specific function or service.

38. Which of the following is a benefit of using a database?

  1. Improved security
  2. Increased storage
  3. Enhanced data management
  4. All of the above

Answer: All of the above

Explanation: Databases provide several benefits, including improved security, increased storage, and enhanced data management. They allow users to store, organize, and retrieve data efficiently and securely.

39. Which of the following is a type of internet connection?

  1. DSL
  2. Cable
  3. Fiber optic
  4. All of the above

Answer: All of the above

Explanation: DSL, cable, and fiber optic are all types of internet connections that provide access to the internet. They offer different speeds and technologies for connecting to the internet.

40. Which algorithm is used for sorting data in ascending order?

  1. Bubble sort
  2. Selection sort
  3. Insertion sort
  4. All of the above

Answer: All of the above

Explanation: All the mentioned algorithms (Bubble sort, Selection sort, Insertion sort) can be used for sorting data in ascending order. Each algorithm has its own method and efficiency for sorting data.

41. What is the basic unit of information in computing?

  1. Bit
  2. Byte
  3. KB
  4. MB

Answer: Bit

Explanation: A bit (binary digit) is the basic unit of information in computing, representing a single binary value (0 or 1). It is the fundamental building block of all digital information.

42. What is the term for a network that spans a large geographic area?

  1. LAN
  2. WAN
  3. MAN
  4. WLAN

Answer: WAN

Explanation: A WAN (Wide Area Network) is a network that covers a large geographic area, such as a city or country, and is typically used to connect multiple LANs (Local Area Networks) together. It allows data to be transmitted over long distances.

43. Which internet protocol is used for sending email?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP/IP

Answer: SMTP

Explanation: SMTP (Simple Mail Transfer Protocol) is the internet protocol used for sending and receiving email. It allows email messages to be transmitted between email servers and clients.

44. What is the purpose of a variable in programming?

  1. To store a constant value
  2. To perform a calculation
  3. To store a changing value
  4. To display output

Answer: To store a changing value

Explanation: A variable in programming is used to store a value that can change during the execution of the program. It allows the program to store and manipulate data in a flexible and dynamic way.

45. Which MS Office application is used for creating databases?

  3. Access
  4. Publisher

46. What is the term for a type of malware that demands payment in exchange for restoring access to data?

  1. Virus
  2. Worm
  3. Trojan
  4. Ransomware

Answer: Ransomware

Explanation: Ransomware is a type of malware that encrypts a victim's data and demands payment in exchange for the decryption key. It is a form of cyber extortion that can cause significant damage to individuals and organizations.

47. Which programming concept is used to make decisions based on conditions?

  1. Loop
  2. Conditional statement
  3. Function
  4. Array

Answer: Conditional statement

Explanation: A conditional statement is a programming concept that allows a program to make decisions based on conditions or rules. It is used to execute different blocks of code depending on whether a condition is true or false.

48. What is the purpose of the 'Save As' feature in MS Word?

  1. To print a document
  2. To email a document
  3. To save a document with a different name or location
  4. To delete a document

Answer: To save a document with a different name or location

Explanation: The 'Save As' feature in MS Word allows users to save a document with a different name, location, or file format. This is useful for creating multiple versions of a document or for saving a document in a format that is compatible with other software applications.

49. What is an algorithm in computer science?

  1. A set of data
  2. A computer program
  3. A step-by-step procedure for solving a problem
  4. A type of computer hardware

Answer: A step-by-step procedure for solving a problem

Explanation: An algorithm is a well-defined procedure that takes some input and produces a corresponding output. It is a set of instructions that is used to solve a specific problem or perform a particular task.
