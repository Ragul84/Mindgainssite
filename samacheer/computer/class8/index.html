Class8 MCQs with answers

1. What is the primary function of the CPU in a computer system?

  1. A
  2. To store data
  3. To provide input/output
  4. To control all operations

Answer: To control all operations

Explanation: The CPU, or Central Processing Unit, is the brain of the computer and its primary function is to execute instructions and control all operations. It performs calculations, executes instructions, and manages data exchange between different parts of the system.

2. Which of the following is a type of malware that demands payment in exchange for restoring access to data?

  1. Virus
  2. Worm
  3. Trojan
  4. Ransomware

Answer: Ransomware

Explanation: Ransomware is a type of malware that encrypts a victim's files or locks their device and demands a ransom in exchange for the decryption key or unlock code. It is a serious threat to individuals and organizations, as it can result in significant financial losses and data breaches.

3. What is the purpose of the IF statement in programming?

  1. A
  2. To repeat a set of instructions
  3. To skip a set of instructions
  4. To execute a set of instructions if a condition is true

Answer: To skip a set of instructions

Explanation: The IF statement is a fundamental control structure in programming that allows a program to execute a set of instructions if a certain condition is true. It is used to make decisions and control the flow of a program based on different conditions or inputs.

4. Which of the following Microsoft Office applications is used for creating presentations?

  1. Word
  2. Excel
  3. Access
  4. PowerPoint

Answer: PowerPoint

Explanation: Microsoft PowerPoint is a popular presentation software that allows users to create engaging and interactive presentations using text, images, audio, and video. It is widely used in educational, business, and personal settings for communicating ideas and information.

5. What is the term for a set of instructions that a computer can execute?

  1. A
  2. Algorithm
  3. Program
  4. Software

Answer: Algorithm

Explanation: An algorithm is a well-defined procedure that takes some input and produces a corresponding output, and it is a fundamental concept in computer science. Algorithms can be expressed in various forms, such as natural language, flowcharts, or programming languages, and they are used to solve problems and perform tasks efficiently.
