26. Which of the following is NOT one of the three important control structures?

  1. Sequential
  2. Alternative
  3. Iterative
  4. Recursive

Answer: Recursive

Explanation: The three important control structures are Sequential, Alternative/Branching, and Iterative/Looping.

27. What is the process of executing a set of statements multiple times called?

  1. Branching
  2. Sequential execution
  3. Iteration
  4. Alternative

Answer: Iteration

Explanation: Executing a set of statements multiple times is called iteration or looping.

28. Which structure is used to skip a segment of statements and execute another based on a condition?

  1. Sequential
  2. Alternative or Branching
  3. Iterative
  4. Sequential Loop

Answer: Alternative or Branching

Explanation: Alternative or branching allows skipping a segment and executing another based on a condition test.

29. A sequential statement is composed of a sequence of statements which are executed:

  1. Randomly
  2. One after another
  3. Based on a condition
  4. In reverse order

Answer: One after another

Explanation: Sequential statements are executed one after another.

30. Which of these is an example of a sequential statement?

  1. A loop that repeats 10 times
  2. An if-else condition
  3. Printing name, address, and phone number
  4. A while loop

Answer: Printing name, address, and phone number

Explanation: Printing name, address, and phone number is given as an example of a sequential statement.

31. Control statements are described as compound statements used to alter the control flow depending on the state of the:

  1. Hardware
  2. Process
  3. Compiler
  4. Operating System

Answer: Process

Explanation: Control statements alter the control flow of the process or program depending on the state of the process.

32. What is the primary purpose of using conditional constructs in Python?

  1. To increase code length
  2. To improve program efficiency
  3. To remove all loops
  4. To stop the program execution

Answer: To improve program efficiency

Explanation: Conditional constructs are used to improve the efficiency of the program flow.

33. Iteration structures are applied to develop code that repeats a program segment until:

  1. The program crashes
  2. The condition is satisfied
  3. The user stops the computer
  4. The sequential statement ends

Answer: The condition is satisfied

Explanation: Iteration structures repeat a segment for a specific number of times or till the condition is satisfied.

34. In general, how are statements executed in a program if no control structure is used?

  1. Simultaneously
  2. Sequentially
  3. Randomly
  4. Iteratively

Answer: Sequentially

Explanation: In general, statements are executed sequentially, meaning one after another.

35. Which of the following is another term for 'Alternative' control structure?

  1. Looping
  2. Branching
  3. Sequential
  4. Iterative

Answer: Branching

Explanation: Alternative is also known as Branching.

36. Which of the following is another term for 'Iterative' control structure?

  1. Branching
  2. Sequential
  3. Looping
  4. Alternative

Answer: Looping

Explanation: Iterative is also known as Looping.

37. Consider the following: 1. Sequential 2. Branching 3. Looping. Which of these are control structures?

  1. Only 1
  2. Only 1 and 2
  3. Only 2 and 3
  4. 1, 2, and 3

Answer: 1, 2, and 3

Explanation: All three (Sequential, Branching, and Looping) are the important control structures.

38. Regarding control structures: I. They cause a jump of control. II. They are compound statements. III. They depend on the state of the process.

  1. Only I is correct
  2. Only I and II are correct
  3. Only II and III are correct
  4. I, II, and III are correct

Answer: I, II, and III are correct

Explanation: All three statements accurately describe control structures based on the text.

39. Which of the following are goals of studying this lesson? I. Knowledge of flow of control. II. Use of conditional constructs. III. Application of iteration structures.

  1. I and II only
  2. II and III only
  3. I and III only
  4. I, II, and III

Answer: I, II, and III

Explanation: The learning objectives include knowledge of flow of control, conditional constructs, and iteration structures.

40. A sequential statement is executed one after another.

  1. True
  2. False

Answer: True

Explanation: Sequential statements are executed one after another.

41. Branching is the same as looping.

  1. True
  2. False

Answer: False

Explanation: Branching is alternative execution, while looping is iterative execution.

42. Control structures are used to alter the control flow of a program.

  1. True
  2. False

Answer: True

Explanation: Control structures are used to alter the control flow of the process or program.

43. Match List I with List II: List I (Control structure) A. Alternative (branching) B. Sequential C. Iterative (looping) List II (Description) 1. Skip a segment based on a condition 2. Repeat a segment multiple times 3. Executed one after another

  1. A-3, B-1, C-2
  2. A-2, B-3, C-1
  3. A-1, B-3, C-2
  4. A-1, B-2, C-3

Answer: A-1, B-3, C-2

Explanation: Branching skips code depending on a condition, sequential code runs one statement after another and iteration repeats code.

44. Match List I with List II: List I (Structure) A. Iterative B. Alternative C. Sequential List II (Also called) 1. One after another 2. Looping 3. Branching

  1. A-3, B-2, C-1
  2. A-1, B-3, C-2
  3. A-2, B-1, C-3
  4. A-2, B-3, C-1

Answer: A-2, B-3, C-1

Explanation: Iterative means looping, alternative means branching and sequential means one after another.

45. Match the objective to the structure.

  1. Iteration structure
  2. Control structure
  3. Conditional construct

Answer: Iteration structure

Explanation: Conditional constructs improve efficiency, Iteration repeats segments, and Control structures cause jumps.

46. What is the purpose of an iteration structure?

  1. To jump to a random line
  2. To repeat a program segment
  3. To execute statements once
  4. To terminate the program

Answer: To repeat a program segment

Explanation: Iteration structures are used to repeat a program segment for a specific number of times or till a condition is satisfied.

47. What are functions in Python?

  1. Named blocks of code designed to do a specific job
  2. A type of variable used for storage
  3. A way to install Python libraries
  4. A method to delete code

Answer: Named blocks of code designed to do a specific job

Explanation: Functions are named blocks of code designed to do specific jobs.

48. Which of the following is a main advantage of using functions?

  1. It increases the size of the program
  2. It avoids repetition and makes high degree of code reusing
  3. It removes the need for a Python interpreter
  4. It prevents the use of variables

Answer: It avoids repetition and makes high degree of code reusing

Explanation: Functions avoid repetition and allow for high code reuse.

49. What is the primary purpose of calling a function?

  1. To define a new variable
  2. To tell Python to run the code inside the function
  3. To stop the program execution
  4. To import a module

Answer: To tell Python to run the code inside the function

Explanation: Calling a function tells Python to run the code inside that function.

50. Which type of function is defined by the users themselves?

  1. Built-in functions
  2. Lambda functions
  3. User-defined functions
  4. Recursion functions

Answer: User-defined functions

Explanation: User-defined functions are those defined by the users themselves.
