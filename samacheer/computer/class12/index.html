Samacheer Computer Science practice

Class12 MCQs with answers

Use these 25 worked Class12 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 332 questions.

1. Which of the following professions is NOT mentioned in the 'Career Guidance' section?

  1. Software Engineer
  2. Hardware Engineer
  3. Doctor
  4. IT & ITEs

Answer: Doctor

Explanation: The 'Career Guidance' section mentions Software Engineer, Hardware Engineer, and IT & ITEs, but not Doctor.

2. Which term is used to describe visual representations of the unit for better understanding?

  1. Glossary
  2. Infographics
  3. Concept Figures
  4. Activity

Answer: Infographics

Explanation: The textbook uses the term 'Infographics' to describe visual representations of the unit for better understanding.

3. Which of the following is a key feature of the 'Learning Objectives' section?

  1. Lists job opportunities
  2. Provides visual representations
  3. Outlines knowledge gained
  4. Explains computer history

Answer: Outlines knowledge gained

Explanation: The 'Learning Objectives' section outlines the knowledge gained by students from the unit.

4. Which of the following is NOT a career option after completing B.Sc (Computer Science)?

  1. Software Engineer
  2. Hardware Engineer
  3. Travel and Tourism
  4. Software Development

Answer: Travel and Tourism

Explanation: Travel and Tourism is not directly related to Computer Science, unlike the other options.

5. Which era is referred to as the highest peak of human civilization due to the development of computers?

  1. Computer Era
  2. Internet Era
  3. Industrial Era
  4. Digital Era

Answer: Computer Era

Explanation: The textbook explicitly mentions that human civilization achieved its highest peak with the development of computers, known as the 'Computer Era'.

6. Who created the Python programming language?

  1. James Gosling
  2. Guido Van Rossum
  3. Bjarne Stroustrup
  4. Dennis Ritchie

Answer: Guido Van Rossum

Explanation: Python was created by Guido Van Rossum from CWI.

7. In which year was Python released?

  1. 1981
  2. 1991
  3. 2001
  4. 1971

Answer: 1991

Explanation: The language was released in 1991.

8. Python got its name from which BBC comedy series?

  1. Monty Python’s Flying Circus
  2. The Comedy Circus
  3. BBC Python Show
  4. Flying Circus Comedy

Answer: Monty Python’s Flying Circus

Explanation: Python got its name from 'Monty Python’s Flying Circus'.

9. Which of the following programming approaches does Python support?

  1. Procedural only
  2. Object Oriented only
  3. Both Procedural and Object Oriented
  4. Neither Procedural nor Object Oriented

Answer: Both Procedural and Object Oriented

Explanation: Python supports both Procedural and Object Oriented programming approaches.

10. What does IDLE stand for in Python?

  1. Integrated Development Learning Environment
  2. Internal Development Logic Engine
  3. Integrated Data Learning Environment
  4. Interactive Development Learning Engine

Answer: Integrated Development Learning Environment

Explanation: IDLE stands for Integrated Development Learning Environment.

11. Which mode allows us to write codes in the Python command prompt (>>>)?

  1. Script mode
  2. Interactive mode
  3. Debug mode
  4. Edit mode

Answer: Interactive mode

Explanation: Interactive mode allows us to write codes in the Python command prompt (>>>).

12. What is the file extension used for Python source files in script mode?

  1. .pyt
  2. .python
  3. .py
  4. .exe

Answer: .py

Explanation: Programs in script mode are stored as separate files with the extension .py.

13. Which of the following is a key feature of Python?

  1. Platform dependent
  2. Difficult to read
  3. Platform independent
  4. Scientific programming only

Answer: Platform independent

Explanation: Python is a platform independent programming language.

14. Where can Python IDLE be downloaded from?

  1. www.python.org
  2. www.google.com
  3. www.microsoft.com
  4. www.cwi.nl

Answer: www.python.org

Explanation: Python IDLE can be downloaded from www.python.org.

15. Which mode is used to create and edit python source files?

  1. Interactive mode
  2. Script mode
  3. Command mode
  4. Prompt mode

Answer: Script mode

Explanation: Script mode is used to create and edit python source file.

16. Python is described as a ______ programming language.

  1. Specific purpose
  2. General purpose
  3. Low level
  4. Hardware dependent

Answer: General purpose

Explanation: Python is a general purpose programming language.

17. Consider these statements: I. Python is platform independent. II. Python is only for scientific programming. III. Python is easily readable.

  1. I and II are correct
  2. II and III are correct
  3. I and III are correct
  4. All are correct

Answer: I and III are correct

Explanation: Python is platform independent and readable, but it is used for both scientific and non-scientific programming.

18. Consider these statements: I. Script mode uses the >>> prompt. II. Interactive mode stores files as .py. III. Script mode is used to edit source files.

  1. I only
  2. II only
  3. III only
  4. I and II only

Answer: III only

Explanation: Only statement III is correct; Interactive mode uses the prompt and Script mode stores .py files.

19. Consider these statements: I. Python was released in 1991. II. Python was created by Guido Van Rossum. III. Python is a platform independent language.

  1. I and II only
  2. II and III only
  3. I and III only
  4. I, II, and III

Answer: I, II, and III

Explanation: All three statements are correct based on the text.

20. Python programs are easily readable and understandable.

  1. True
  2. False

Answer: True

Explanation: The text states that programs written in Python are easily readable and understandable.

21. Interactive mode is used to store programs as separate files.

  1. True
  2. False

Answer: False

Explanation: Script mode is used to store programs as separate files; Interactive mode is for the command prompt.

22. Python supports only the Object Oriented programming approach.

  1. True
  2. False

Answer: False

Explanation: Python supports both Procedural and Object Oriented programming approaches.

23. Match List I with List II: List I (Term) A. Script mode B. Interactive mode C. IDLE List II (Linked with) 1. Integrated Development Learning Environment 2. .py extension 3. Command prompt (>>>)

  1. A-3, B-2, C-1
  2. A-2, B-1, C-3
  3. A-2, B-3, C-1
  4. A-1, B-3, C-2

Answer: A-2, B-3, C-1

Explanation: Script mode saves code in .py files, interactive mode shows the >>> prompt and IDLE is Python's Integrated Development Learning Environment.

24. What are the two ways programs can be written in Python?

  1. Interactive and Script mode
  2. Procedural and Object Oriented
  3. Scientific and Non-scientific
  4. CWI and IDLE

Answer: Interactive and Script mode

Explanation: Programs can be written in two ways: Interactive mode and Script mode.

25. What is a program statement that causes a jump of control from one part of the program to another called?

  1. Sequential statement
  2. Control structure
  3. Iterative structure
  4. Branching statement

Answer: Control structure

Explanation: A control structure or control statement causes a jump of control from one part of the program to another.
