Class9 MCQs with answers

Use these 25 worked Class9 questions to revise the Samacheer Computer Science syllabus. Each answer includes an explanation; the full practice set contains 231 questions.

1. Which of the following is not a basic function of a computer?

  1. Input
  2. Output
  3. Processing
  4. Destroying

Answer: Destroying

Explanation: The three basic functions of a computer are input, output, and processing. Destroying is not a basic computer function.

2. What does the acronym 'URL' stand for?

  1. Uniform Resource Locator
  2. Universal Resource Link
  3. Uniform Resource Link
  4. Universal Resource Locator

Answer: Uniform Resource Locator

Explanation: URL stands for Uniform Resource Locator, which is the address of a specific webpage or file on the Internet.

3. In Microsoft Word, which key combination is used to save a document?

  1. Ctrl + S
  2. Ctrl + O
  3. Ctrl + W
  4. Ctrl + P

Answer: Ctrl + S

Explanation: Ctrl + S is the keyboard shortcut used to save a document in Microsoft Word.

4. Which of the following is not a valid data type in most programming languages?

  1. Integer
  2. String
  3. Character
  4. Sentence

Answer: Sentence

Explanation: Sentence is not a valid data type in most programming languages. The other options are commonly used data types.

5. What is the term used to describe a set of instructions given to a computer?

  1. Algorithm
  2. Program
  3. Software
  4. Hardware

Answer: Program

Explanation: A program is a set of instructions given to a computer to perform a specific task.

6. In Microsoft Excel, which function is used to find the average of a range of values?

  1. AVERAGE()
  2. SUM()
  3. COUNT()
  4. MAX()

Answer: AVERAGE()

Explanation: The AVERAGE() function is used in Microsoft Excel to calculate the average of a range of values.

7. Which of the following is not a type of network topology?

  1. Bus
  2. Star
  3. Ring
  4. Triangle

Answer: Triangle

Explanation: Triangle is not a type of network topology. The other options are common network topologies.

8. In computer programming, what is the purpose of a loop?

  1. To repeat a set of instructions
  2. To make decisions
  3. To input data
  4. To output data

Answer: To repeat a set of instructions

Explanation: A loop is used in programming to repeat a set of instructions until a certain condition is met.

9. Which of the following is not a common input device?

  1. Keyboard
  2. Mouse
  3. Scanner
  4. Printer

Answer: Printer

Explanation: A printer is an output device, not an input device. The other options are common input devices.

10. In Microsoft PowerPoint, what is the term used for a single page of a presentation?

  1. Slide
  2. Page
  3. Sheet
  4. Frame

Answer: Slide

Explanation: In Microsoft PowerPoint, a single page of a presentation is called a slide.

11. What is the term used to describe the physical components of a computer?

  1. Hardware
  2. Software
  3. Firmware
  4. Middleware

Answer: Hardware

Explanation: Hardware refers to the physical components of a computer, such as the monitor, keyboard, and mouse.

12. In computer programming, what is the purpose of an 'if' statement?

  1. To repeat a set of instructions
  2. To make decisions based on conditions
  3. To input data
  4. To output data

Answer: To make decisions based on conditions

Explanation: An 'if' statement is used in programming to make decisions based on certain conditions.

13. What is the primary function of the CPU?

  1. To store data
  2. To provide input/output
  3. To perform calculations
  4. To connect hardware

Answer: To perform calculations

Explanation: The CPU (Central Processing Unit) is responsible for executing instructions and performing calculations. It acts as the brain of the computer, handling all the data processing tasks.

14. Which MS Office application is used for creating presentations?

  1. Word
  2. Excel
  3. Access
  4. PowerPoint

Answer: PowerPoint

Explanation: PowerPoint is a presentation software that allows users to create slides, add text and images, and create engaging presentations. It is widely used for educational and business purposes.

15. What is the term for a set of instructions that a computer follows to solve a problem?

  1. Algorithm
  2. Program
  3. Software
  4. Hardware

Answer: Algorithm

Explanation: An algorithm is a well-defined procedure that takes some input and produces a corresponding output. It is a step-by-step solution to a problem, and computers follow algorithms to perform tasks.

16. Which internet protocol is used for sending and receiving email?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP

Answer: SMTP

Explanation: SMTP (Simple Mail Transfer Protocol) is a protocol used for sending and receiving email between email servers. It allows users to send and receive emails across the internet.

17. What is the purpose of a flowchart in programming?

  1. To write code
  2. To debug code
  3. To plan and visualize a program
  4. To test code

Answer: To plan and visualize a program

Explanation: A flowchart is a graphical representation of a program's logic, used to plan and visualize the flow of a program. It helps programmers to design and understand the program's structure before writing the code.

18. Which programming concept is used to repeat a set of instructions?

  1. Conditional statement
  2. Loop
  3. Function
  4. Array

Answer: Loop

Explanation: A loop is a programming concept that allows a set of instructions to be repeated for a specified number of times. It is used to perform repetitive tasks, such as iterating over a list of items.

19. What is the term for a temporary storage area where data is held while it is being processed?

  1. Register
  2. Cache
  3. Buffer
  4. Memory

Answer: Buffer

Explanation: A buffer is a temporary storage area that holds data while it is being processed or transferred between devices. It acts as a holding area, allowing data to be processed more efficiently.

20. Which MS Office application is used for creating and editing spreadsheets?

  1. Word
  2. Excel
  3. Access
  4. Publisher

Answer: Excel

Explanation: Excel is a spreadsheet software that allows users to create, edit, and analyze data in a tabular format. It is widely used for financial, statistical, and mathematical calculations.

21. What is the purpose of a variable in programming?

  1. To store a constant value
  2. To perform a calculation
  3. To store a value that can be changed
  4. To display output

Answer: To store a value that can be changed

Explanation: A variable is a named storage location that holds a value that can be changed during the execution of a program. It allows programmers to store and manipulate data in a flexible way.

22. Which internet protocol is used for transferring files between computers?

  1. HTTP
  2. FTP
  3. SMTP
  4. TCP

Answer: FTP

Explanation: FTP (File Transfer Protocol) is a protocol used for transferring files between computers over the internet. It allows users to upload and download files to and from remote servers.

23. What is the term for a program that is designed to harm or exploit a computer system?

  1. Virus
  2. Worm
  3. Trojan
  4. Malware

Answer: Malware

Explanation: Malware is a general term that refers to any type of software that is designed to harm or exploit a computer system. It includes viruses, worms, trojans, and other types of malicious software.

24. Which programming concept is used to make decisions based on conditions?

  1. Loop
  2. Conditional statement
  3. Function
  4. Array

Answer: Conditional statement

Explanation: A conditional statement is a programming concept that allows a program to make decisions based on conditions or rules. It is used to execute different blocks of code depending on whether a condition is true or false.

25. Which software is used for creating presentations?

  1. MS Word
  2. MS Excel
  3. MS Access
  4. MS PowerPoint

Answer: MS PowerPoint

Explanation: MS PowerPoint is a popular presentation software used for creating slideshows and presentations. It offers various features such as templates, animations, and collaboration tools.
