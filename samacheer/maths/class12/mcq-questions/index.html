Class12 MCQs with answers

26. The limit of (sin(x))/x as x approaches 0 is

  1. 0
  2. 1
  3. 2
  4. 3

Answer: 1

Explanation: Limit of (sin(x))/x as x approaches 0 is 1.

27. The matrix [[1, 0], [0, 1]] is

  1. zero matrix
  2. identity matrix
  3. null matrix
  4. diagonal matrix

Answer: identity matrix

Explanation: Matrix [[1, 0], [0, 1]] is the identity matrix.

28. If A is a square matrix, then A + Aᵀ is always a:

  1. Symmetric matrix
  2. Skew-symmetric matrix
  3. Identity matrix
  4. Diagonal matrix

Answer: Symmetric matrix

Explanation: The sum of a matrix and its transpose results in a symmetric matrix.

29. The value of the determinant of an identity matrix of any order is:

  1. 0
  2. 1
  3. -1
  4. Undefined

Answer: 1

Explanation: The determinant of any identity matrix is always 1.

30. If A is a 3x3 matrix and |A| = 5, then |2A| is:

  1. 10
  2. 20
  3. 40
  4. 80

Answer: 40

Explanation: |kA| = kⁿ|A|. Here 2³ * 5 = 8 * 5 = 40.

31. The dot product of two perpendicular vectors is:

  1. 1
  2. -1
  3. 0
  4. Infinity

Answer: 0

Explanation: The dot product of orthogonal vectors is always zero.

32. The unit vector in the direction of vector a is given by:

  1. a / |a|
  2. |a| / a
  3. a * |a|
  4. a + |a|

Answer: a / |a|

Explanation: A unit vector is obtained by dividing a vector by its magnitude.

33. The projection of vector a on vector b is:

  1. (a.b)/|a|
  2. (a.b)/|b|
  3. |a|/|b|
  4. a x b

Answer: (a.b)/|b|

Explanation: Projection of a on b is defined as (a.b) divided by the magnitude of b.

34. The distance between the points (0,0,0) and (1,1,1) is:

  1. 1
  2. 2
  3. √2
  4. √3

Answer: √3

Explanation: Distance = √(1²+1²+1²) = √3.

35. The equation of the x-axis in 3D space is:

  1. x=0, y=0
  2. y=0, z=0
  3. x=0, z=0
  4. x=y=z

Answer: y=0, z=0

Explanation: On the x-axis, both y and z coordinates are zero.

36. The derivative of sin(x) with respect to x is:

  1. cos(x)
  2. -cos(x)
  3. tan(x)
  4. sec(x)

Answer: cos(x)

Explanation: The standard derivative of sin(x) is cos(x).

37. The derivative of eˣ with respect to x is:

  1. xeˣ⁻¹
  2. eˣ
  3. log(x)
  4. 1/eˣ

Answer: eˣ

Explanation: The derivative of the exponential function eˣ is itself.

38. The integral of 1/x dx is:

  1. x
  2. log|x|
  3. eˣ
  4. -1/x²

Answer: log|x|

Explanation: The integral of 1/x is the natural logarithm of x.

39. The value of ∫ cos(x) dx is:

  1. sin(x) + C
  2. -sin(x) + C
  3. tan(x) + C
  4. sec(x) + C

Answer: sin(x) + C

Explanation: Integration of cos(x) is sin(x).

40. If P(A) = 0.6, then P(not A) is:

  1. 0.6
  2. 0.4
  3. 1.0
  4. 0

Answer: 0.4

Explanation: P(not A) = 1 - P(A) = 1 - 0.6 = 0.4.

41. If two events A and B are independent, then P(A ∩ B) equals:

  1. P(A) + P(B)
  2. P(A) - P(B)
  3. P(A) * P(B)
  4. P(A) / P(B)

Answer: P(A) * P(B)

Explanation: For independent events, the probability of intersection is the product of their probabilities.

42. The probability of a sure event is:

  1. 0
  2. 0.5
  3. 1
  4. Infinity

Answer: 1

Explanation: A sure event always occurs, so its probability is 1.

43. The vector equation of a line passing through the point (1, 2, 3) and parallel to the vector 2i + 3j - k is

  1. r = i + 2j + 3k + λ(2i + 3j - k)
  2. r = i + 2j + 3k + λ(i + 2j + 3k)
  3. r = 2i + 3j - k + λ(i + 2j + 3k)
  4. r = i + 2j + 3k + λ(2i - 3j + k)

Answer: r = i + 2j + 3k + λ(2i + 3j - k)

Explanation: The vector equation of a line is given by r = a + λd

44. The equation of the tangent to the curve y = x^2 at (1, 1) is

  1. y - 1 = 2(x - 1)
  2. y - 1 = x - 1
  3. y + 1 = 2(x + 1)
  4. y + 1 = x + 1

Answer: y - 1 = 2(x - 1)

Explanation: The equation of the tangent is y - y1 = m(x - x1)

45. The value of e^ln(x) is

  1. x
  2. 1/x
  3. x^2
  4. 1/x^2

Answer: x

Explanation: e^ln(x) = x

46. The equation of the normal to the curve y = x^2 at (1, 1) is

  1. y - 1 = -1/2(x - 1)
  2. y - 1 = 1/2(x - 1)
  3. y - 1 = -2(x - 1)
  4. y - 1 = 2(x - 1)

Answer: y - 1 = -1/2(x - 1)

Explanation: The equation of the normal is y - y1 = -1/m(x - x1)

47. The area under the curve y = x^2 from x = 0 to x = 2 is

  1. 8/3
  2. 4/3
  3. 2/3
  4. 1/3

Answer: 8/3

Explanation: The area is ∫[0,2] x^2 dx = [x^3 / 3] from 0 to 2 = 8/3

48. The equation of the circle with centre (-2, 3) and radius 2 is

  1. (x + 2)^2 + (y - 3)^2 = 4
  2. (x - 2)^2 + (y + 3)^2 = 4
  3. (x + 2)^2 + (y - 3)^2 = -4
  4. (x - 2)^2 + (y + 3)^2 = -4

Answer: (x + 2)^2 + (y - 3)^2 = 4

Explanation: The equation of a circle is (x - h)^2 + (y - k)^2 = r^2

49. If f(x) = x^3 - 2x^2 + x - 1, then f'(x) is

  1. 3x^2 - 4x + 1
  2. 3x^2 + 4x - 1
  3. -3x^2 + 4x - 1
  4. -3x^2 - 4x + 1

Answer: 3x^2 - 4x + 1

Explanation: f'(x) = d(x^3 - 2x^2 + x - 1)/dx = 3x^2 - 4x + 1

50. The value of ∫(2x + 1) dx is

  1. x^2 + x + c
  2. x^2 - x + c
  3. 2x^2 + x + c
  4. 2x^2 - x + c

Answer: x^2 + x + c

Explanation: ∫(2x + 1) dx = x^2 + x + c
