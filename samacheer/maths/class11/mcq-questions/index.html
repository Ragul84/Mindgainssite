26. If a and b are two events, then the probability of a and b occurring is

  1. P(a) + P(b)
  2. P(a) - P(b)
  3. P(a) * P(b)
  4. P(a) / P(b)

Answer: P(a) * P(b)

Explanation: The probability of two independent events occurring is the product of their probabilities.

27. The derivative of sin(x) with respect to x is

  1. cos(x)
  2. sin(x)
  3. tan(x)
  4. cosec(x)

Answer: cos(x)

Explanation: The derivative of sin(x) is cos(x).

28. The equation of a line passing through a point (x1, y1) with slope m is

  1. y - y1 = m(x - x1)
  2. y + y1 = m(x + x1)
  3. y - y1 = -m(x - x1)
  4. y + y1 = -m(x + x1)

Answer: y - y1 = m(x - x1)

Explanation: The point-slope form of a line is y - y1 = m(x - x1).

29. If X is a continuous random variable, then the probability density function f(x) satisfies

  1. ∫f(x)dx = 0
  2. ∫f(x)dx = 1
  3. ∫f(x)dx = -1
  4. ∫f(x)dx = ∞

Answer: ∫f(x)dx = 1

Explanation: The probability density function satisfies ∫f(x)dx = 1.

30. If A = [1 2], then the transpose of A is

  1. [1 2]
  2. [2 1]
  3. [1, 2]
  4. [2, 1]

Answer: [2 1]

Explanation: Transpose of a matrix is obtained by interchanging its rows into columns.

31. The distance between the points (x1, y1) and (x2, y2) is given by

  1. √((x2-x1)^2 + (y2-y1)^2)
  2. √((x2+x1)^2 + (y2+y1)^2)
  3. √((x2-x1)^2 - (y2-y1)^2)
  4. √((x2+x1)^2 - (y2+y1)^2)

Answer: √((x2-x1)^2 + (y2-y1)^2)

Explanation: Distance formula between two points is √((x2-x1)^2 + (y2-y1)^2).

32. The probability of an impossible event is

  1. 0
  2. 1
  3. 1/2
  4. -1

Answer: 0

Explanation: Impossible event has a probability of 0.

33. The equation of the circle with centre (0, 0) and radius 2 is

  1. x^2 + y^2 = 4
  2. x^2 + y^2 = 2
  3. x^2 - y^2 = 4
  4. x^2 - y^2 = 2

Answer: x^2 + y^2 = 4

Explanation: Equation of a circle with centre (0, 0) and radius r is x^2 + y^2 = r^2.

34. If A and B are two events such that P(A) = 1/2 and P(B) = 1/3, then P(A ∩ B) is

  1. 1/6
  2. 1/2
  3. 1/3
  4. 2/3

Answer: 1/6

Explanation: P(A ∩ B) = P(A) * P(B) for independent events.

35. The area under the curve y = f(x) from x = a to x = b is given by

  1. ∫[a, b] f(x) dx
  2. ∫[a, b] f'(x) dx
  3. ∫[a, b] f''(x) dx
  4. ∫[a, b] f'''(x) dx

Answer: ∫[a, b] f(x) dx

Explanation: Area under a curve is given by the definite integral of the function.

36. If f(x) = 2x, then f'(2) is

  1. 2
  2. 4
  3. 6
  4. 8

Answer: 4

Explanation: Derivative of 2x is 2, so f'(2) = 2*2 = 4.

37. The vector equation of a plane passing through a point with position vector a and parallel to vectors b and c is

  1. r = a + λb + μc
  2. r = a - λb - μc
  3. r = b + λa + μc
  4. r = c + λa + μb

Answer: r = a + λb + μc

Explanation: Vector equation of a plane is given by r = a + λb + μc.

38. The distance between the parallel lines Ax + By + C1 = 0 and Ax + By + C2 = 0 is

  1. |C1 - C2| / √(A^2 + B^2)
  2. |C1 + C2| / √(A^2 + B^2)
  3. |C1 - C2| / √(A^2 - B^2)
  4. |C1 + C2| / √(A^2 - B^2)

Answer: |C1 - C2| / √(A^2 + B^2)

Explanation: Distance between parallel lines is given by |C1 - C2| / √(A^2 + B^2).

39. The derivative of e^x is

  1. e^x
  2. -e^x
  3. e^-x
  4. 1/e^x

Answer: e^x

Explanation: Derivative of e^x is e^x.

40. If P(A) = 1/3 and P(B) = 1/2, then P(A ∪ B) is

  1. 1/6
  2. 2/3
  3. 5/6
  4. 1

Answer: 2/3

Explanation: P(A ∪ B) = P(A) + P(B) - P(A ∩ B) for independent events.

41. If A is a square matrix of order 3, then the number of elements in A is

  1. 6
  2. 9
  3. 12
  4. 8

Answer: 9

Explanation: A square matrix of order 3 has 3 rows and 3 columns, so the total number of elements is 3 * 3 = 9.

42. The distance between the points (x1, y1) and (x2, y2) in a coordinate plane is given by

  1. √((x2 - x1)^2 + (y2 - y1)^2)
  2. √((x2 + x1)^2 + (y2 + y1)^2)
  3. √((x2 - x1)^2 - (y2 - y1)^2)
  4. √((x2 + x1)^2 - (y2 + y1)^2)

Answer: √((x2 - x1)^2 + (y2 - y1)^2)

Explanation: The distance formula between two points is √((x2 - x1)^2 + (y2 - y1)^2).

43. If f(x) = x^2, then the derivative of f(x) is

  1. 2x
  2. x^2
  3. 2/x
  4. x/2

Answer: 2x

Explanation: The derivative of f(x) = x^2 is f'(x) = 2x.

44. A random experiment has two possible outcomes: success or failure. If the probability of success is 0.7, then the probability of failure is

  1. 0.3
  2. 0.7
  3. 0.2
  4. 0.1

Answer: 0.3

Explanation: The probability of failure is 1 - probability of success = 1 - 0.7 = 0.3.

45. The order of a matrix with 6 elements and 3 columns is

  1. 2 x 3
  2. 3 x 2
  3. 2 x 2
  4. 3 x 1

Answer: 2 x 3

Explanation: Since there are 3 columns and 6 elements, the number of rows is 6 / 3 = 2, so the order is 2 x 3.

46. The magnitude of a vector with components 3, 4 is

  1. 3
  2. 4
  3. 5
  4. 6

Answer: 5

Explanation: The magnitude of the vector is √(3^2 + 4^2) = √(9 + 16) = √25 = 5.

47. If two events are mutually exclusive, then the probability of both events occurring is

  1. 0
  2. 1
  3. 0.5
  4. 0.25

Answer: 0

Explanation: Mutually exclusive events cannot occur together, so the probability is 0.

48. The equation of a circle with center (0, 0) and radius 4 is

  1. x^2 + y^2 = 16
  2. x^2 + y^2 = 4
  3. x^2 - y^2 = 16
  4. x^2 - y^2 = 4

Answer: x^2 + y^2 = 16

Explanation: The equation of a circle with center (0, 0) and radius r is x^2 + y^2 = r^2.

49. The derivative of the function f(x) = 3x^2 is

  1. 6x
  2. 3x
  3. 2x
  4. x

Answer: 6x

Explanation: Using the power rule, the derivative is f'(x) = 6x.

50. If a matrix has 4 rows and 5 columns, then the order of the matrix is

  1. 4 x 5
  2. 5 x 4
  3. 4 x 4
  4. 5 x 5

Answer: 4 x 5

Explanation: The order of a matrix is given by the number of rows and columns.
